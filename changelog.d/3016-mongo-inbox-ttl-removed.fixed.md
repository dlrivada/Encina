- MongoDB: the inbox collection no longer gets a TTL index (`IX_Inbox_Expires_TTL`), which deleted unprocessed rows and ignored `InboxOptions.EnableAutomaticPurge = false`. The expired processed rows are removed only by the automatic inbox purge; an ordinary `IX_Inbox_Expires` index on `ExpiresAtUtc` replaces it. A database created earlier must drop the old TTL index by hand. The inbox purge options are now documented in the `Encina.Messaging` README and `docs/messaging/inbox.md` (#3016).
