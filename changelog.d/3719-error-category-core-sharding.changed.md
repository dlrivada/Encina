- The 26 error calls of the routing, shadow and time-based sharding code (`DirectoryShardRouter`, `GeoShardRouter`, `HashShardRouter`, `RangeShardRouter`, `ShadowShardRouterDecorator`, `ShardArchiver`, `TimeBasedShardRouter`) now declare an `ErrorCategory` (#3719, ADR-062). 25 of them (`ShardNotFound`, `PartialKeyRoutingFailed`, `KeyOutsideRange`, `RegionNotFound`, `TimestampOutsideRange`, `NoActiveShards`, `NoTimeBasedShards`, `ShadowRoutingFailed`, `TierTransitionFailed`, `RetentionPolicyFailed`) are `Internal` and keep answering 500; the only HTTP status change is `encina.sharding.shard_read_only` (write to a non-Hot time-based shard), now `ErrorCategory.Conflict` and answering 409 instead of 500.
