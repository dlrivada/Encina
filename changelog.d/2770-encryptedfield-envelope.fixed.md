- **Encina.Audit.Marten: unreadable encrypted audit fields fail typed instead of leaking** (#2770). `EncryptedField` no longer throws raw `ArgumentException`/`InvalidOperationException` out of the audit projections, and no longer returns a raw envelope as plaintext. An unreadable envelope (tampered, wrong key or sizes, malformed, or an unmarked value) now throws `EncryptedFieldDecryptionException` with a fixed message, the code `audit.marten.encrypted_field_unreadable` and an `EncryptedFieldDecryptionFailureReason`. Marten's async daemon pauses that shard until an operator resolves it.
- **Encina.Audit.Marten: `[SHREDDED]` only for lawful erasure** (#2770). The shredded placeholder is shown only when the key destruction carries an `ErasureReference` (request id, request date, actor). A key destroyed without one (retention expiry, an error, tampering, and every marker written before this change) fails the same typed way as above, reason `KeyDestroyedWithoutErasureRecord`.
- **Encina.Audit.Marten: `ITemporalKeyProvider.DestroyKeysBeforeAsync` takes an erasure reference** (#2770). The new optional `ErasureReference? erasureReference = null` parameter sits before the `CancellationToken`. This is a breaking change for callers that pass the cancellation token positionally.
