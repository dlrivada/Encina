- **Crypto-shredding startup fails closed when a registered personal data locator is left out** (#1773). With several `IPersonalDataLocator` registered, the resolved one must be a `CompositePersonalDataLocator` reaching every registered locator type, in either registration order; otherwise startup throws `CryptoShreddingConfigurationException` (`PersonalDataLocatorBypassed`) naming the missing types. The docs show the composite factory registration.
- **Event metadata readers no longer decrypt events** (#1773). `IEventMetadataQuery` reads inside a no-decrypt scope: protected fields keep their stored token, no subject key is fetched and an undecryptable event no longer makes the readers return `Left`.
