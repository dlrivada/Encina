- `IRequestContextScopeFactory.RunAsPrincipalAsync` now refuses a principal whose authenticated identities carry different tenant claim values (across the configured tenant claim types, or several values in one identity) with the new error code `encina.identity.conflicting_tenant_claims` (`RequestIdentityErrorCodes.ConflictingTenantClaims`, `RequestIdentityErrors.ConflictingTenantClaims()`) instead of opening an anonymous scope; the work delegate never runs. (#2836)
- Differing tenant values across the configured claim types (`TenantIdClaimTypes`, for example an application `tenant_id` and an Entra `tid`) are a conflict that is refused, not resolved. (#2836)
