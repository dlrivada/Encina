- **`SagaRunner` no longer leaks the raw exception message of a throwing saga step**: the returned `EncinaError.Message` is a fixed generic text with the exception kept as the inner exception, the persisted saga `ErrorMessage` (and therefore the saga activity tag and `SagaStateSnapshot.ErrorMessage`) holds only the error code, and the logs carry the exception type instead of its message; cancellation persists `saga.handler.cancelled`. The exception handed to the logger is now `ex.ForLogging()`, the new `Encina.Diagnostics.RedactedException` copy that keeps the exception type and the full stack trace (inner exceptions included) but never the message. Compensation failures log the exception type too (#1469, #1483).
- **`SagaOrchestrator.FailAsync` and `StartCompensationAsync` rename their `errorMessage` parameter to `errorCode`**: it is persisted and logged, so it must be an error code, never free text.
