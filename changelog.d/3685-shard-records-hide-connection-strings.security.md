- `ShardInfo` and `ShardTierInfo` (Encina sharding) no longer expose their database connection strings: `ShardInfo.ConnectionString`, `ShardInfo.ReplicaConnectionStrings` and `ShardTierInfo.ConnectionString` are excluded from System.Text.Json serialization, and `ToString()` prints `ConnectionString = ***` and only the number of replicas (`ReplicaConnectionStrings = [N masked]`). Both records can no longer be read back from their own JSON (the constructors reject the missing connection string); configuration binding still reads the connection strings (#3685).
