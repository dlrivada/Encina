- **A per-user cached query never crosses an ended identity scope** (#1931). `QueryCachingPipelineBehavior` reads the request identity once and builds a `VaryByUser` key from that snapshot (custom `ICacheKeyGenerator` implementations receive a context pinned to it); the entry is read, served, refreshed or written only while the request still reports that identity, so a query whose identity scope ends mid-request runs its handler without the cache, and no response is ever stored or served under another caller's key or a user-less key.
