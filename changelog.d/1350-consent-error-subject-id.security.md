- **Consent error messages no longer leak data subject identifiers** (#1350). Error messages from `ConsentErrors` (MissingConsent, ConsentExpired, ConsentWithdrawn, RequiresReconsent, VersionMismatch) previously interpolated raw data subject IDs directly into message text, which reached `ProblemDetails.Detail` and logs. The fix replaces subject IDs with the non-identifying text "the specified data subject", preserving purpose, version IDs, and timestamps. Factory signatures and error codes are unchanged. The `IConsentValidator` example in XML documentation was also corrected to log `error.Code` instead of `error.Message`.
