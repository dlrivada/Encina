- Delayed retries switched on without a delayed retry store no longer leave an unbuildable or silently degraded container: `AddEncinaRecoverability()` and `UseRecoverability` build and run with defaults, and when `RecoverabilityOptions.EnableDelayedRetries` is on without an `IDelayedRetryStore` and an `IDelayedRetryMessageFactory` the application fails at startup (or when the scheduler is resolved, without a host) with a message that names what is missing and how to fix it, in any registration order (#2248).
- `DelayedRetryProcessor` no longer logs and skips a cycle when the delayed retry store is missing (EventId 2848 removed); a missing store is now an error of the cycle (#2248).
