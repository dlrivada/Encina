- Hooks: `git checkout <branch> 2>&1` (and `2>$null`, `*>&1`, `>&2`) no longer counts the redirection as a pathspec, so the read-only reviewers and the orchestrator can switch branches with redirected output; `>&file` and Bash `&>file` are now treated as writes to `file` (#2009).
- Hooks: `guard-orchestrator-writes` resolves a script path built from a variable that the same PowerShell command assigns once, at its top level, to a literal (`$wt = 'D:\path'; pwsh -File "$wt\probe.ps1"`) and judges the script as usual; any other variable path stays denied, and the message now names the workaround (#2009).
- Hooks: `git archive` is allowed for the workers and reviewers; its `-o`/`--output` file is a write target judged by the ownership hooks, and `--remote`, `--exec` and `tar.*` git configuration stay denied (#2009).
