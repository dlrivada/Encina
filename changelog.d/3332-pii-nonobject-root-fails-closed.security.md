- Encina.Security.PII: `PIIMasker` no longer returns an object unmasked when its JSON form is not an object (an array, a scalar or `null`, for example a type derived from `List<T>` or a type with a scalar `JsonConverter`) while it has decorated members that apply to the masking context; `MaskObject`, both `MaskForAudit` overloads and `MaskForLog` throw `InvalidOperationException` naming only the type and members, which surfaces as `pii.masking_failed`, `audit.masking_failed` or `[MASKING FAILED]`. Types without such members are still returned unchanged; real masking of these roots is tracked in #1834 (#3332).
