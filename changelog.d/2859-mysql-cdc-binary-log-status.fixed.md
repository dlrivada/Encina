- MySQL CDC now works on MySQL 8.4 LTS and 9.x: `MySqlCdcConnector.GetCurrentPositionAsync` reads the binlog position with `SHOW BINARY LOG STATUS` (the `SHOW MASTER STATUS` statement was removed in 8.4), `MySqlCdc` moves to 5.0.0-preview2, the release that supports MySQL 8.4 and later, and the advice for a server without binary logging no longer suggests `SET GLOBAL log_bin = ON` (it is a startup-only variable). MySQL 8.0 is no longer supported. (#2859)
