- **DPIA endpoints fail closed** (#3126). `MapDPIAEndpoints` (Encina.AspNetCore) now requires the name of an authorization policy and applies it to all seven DPIA endpoints; it throws at startup when the name is blank or the policy is not registered. This is a breaking signature change: the call now takes `authorizationPolicy` as its second argument. Approve and reject record the authenticated request identity's user id and answer 401 (`encina.authorization.unauthenticated`) without one; the "DPO" fallback approver is removed, and the DPIA approved/rejected log messages (8872, 8873) no longer log the user id.
