- **System.Exception.Message no longer leaks into OpenTelemetry activity tags and status descriptions** (#1488). Extends the fix from #1454 to caught exceptions. Previously, the raw `System.Exception.Message` could be recorded directly in activity tags and status descriptions across `Encina.Compliance.DataSubjectRights`, `Encina.Compliance.DPIA` and `Encina.Compliance.Retention`.

  The affected call sites — `RecordFailed` and `RecordFailure` diagnostics helpers in `DefaultDSRService`, `DPIAReviewReminderService`, `DefaultDPIAAssessmentEngine`, `RetentionValidationPipelineBehavior` and `RetentionEnforcementService` — now record only the exception's type name (`ex.GetType().Name`) instead of the message text, preventing sensitive data from reaching activity exports, logs and observability pipelines.
