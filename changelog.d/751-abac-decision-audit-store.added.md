- **ABAC decision audit through the operation audit store, phase 3** (#751). `AuditStoreABACDecisionRecorder` is the registered `IABACDecisionRecorder`: each enforced decision is written as an `OperationAuditEntry` (`ABACDecisionAuditEntryMapper`) in its own DI scope with ambient transactions suppressed, never linked to the client's token and bounded by `ABACOptions.DecisionAudit.WriteTimeout` (default 5 seconds, validated at start), even for a store that ignores its token. `IABACDecisionAuditReader` queries the decisions by subject, request type, resource, outcome, tenant and correlation id and exports them as JSON Lines (`encina.abac.decision/1`), behind a fail-closed tenant gate: the request's tenant is forced, a different or missing tenant in a multi-tenant application is denied, and `ABACOptions.DecisionAudit.AllowCrossTenantQueries` is the logged opt-out for operator tooling.
- **`MultiTenancyMarker`** (#751). Core `Encina` gains `MultiTenancyMarker`, registered by `AddEncinaTenancy`, so any package can tell through `IServiceProviderIsService` that multi-tenancy is enabled.
