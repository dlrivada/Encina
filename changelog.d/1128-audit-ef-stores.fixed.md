- EF Core security audit stores (`AuditStoreEF`, `ReadAuditStoreEF`) now work on PostgreSQL: the filtered indexes of `AuditEntryEntityConfiguration` and `ReadAuditEntryEntityConfiguration` quote their column (`"UserId" IS NOT NULL`), so creating the schema no longer fails with `column "userid" does not exist`; write failures keep the underlying exception in the returned `EncinaError` and include the root cause in its message (#1128).
