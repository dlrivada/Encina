- **Blazor circuit activities fail closed on an unusable principal** (#2985). The Blazor Server circuit handler (`AddEncinaBlazorAuthorization`) no longer runs an activity anonymously when the scope factory refuses an authenticated principal (missing, malformed, reserved or conflicting subject, or conflicting tenant claims). The activity is refused with an `InvalidOperationException` carrying only the error code, which Blazor reports as an unhandled circuit exception (client notified, circuit terminated) for JavaScript interop calls and the UI events that travel through them; a refusal of the circuit's first activity is not reported to the client and leaves the circuit uninitialized. Host refusals (`ScopeConflict`, `UnsupportedAccessor`) keep the masked anonymous run.
