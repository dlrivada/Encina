- **Blazor circuit activities fail closed on an unusable principal** (#2985). The Blazor Server circuit handler (`AddEncinaBlazorAuthorization`) no longer runs an activity anonymously when the scope factory refuses an authenticated principal (missing, malformed, reserved or conflicting subject, or conflicting tenant claims). The activity is refused with an `InvalidOperationException` carrying only the error code, which Blazor reports as an unhandled circuit exception (client notified, circuit terminated) for JavaScript interop calls and the UI events that travel through them. Two Blazor paths are not reported to the client: the initialization of a circuit in the legacy Blazor Server hosting (the circuit stays uninitialized) and render acknowledgements (the acknowledgement is lost and rendering stalls). Host refusals (`ScopeConflict`, `UnsupportedAccessor`) keep the masked anonymous run.
