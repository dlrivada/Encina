- Breaking (pre-1.0): Encina.Security now emits the encina.authorization.* error family instead of security.*: security.unauthenticated and security.missing_context → encina.authorization.unauthenticated (401); security.insufficient_roles/permission_denied/claim_missing/not_owner → encina.authorization.insufficient_roles/permission_denied/claim_missing/not_owner (403), new EncinaErrorCodes.AuthorizationInsufficientRoles/PermissionDenied/ClaimMissing/NotOwner constants; the SecurityErrors *Code constants are removed (#1918).
- EncinaErrors.Unauthorized() is now a denial ("Access denied.", 403) and new EncinaErrors.Unauthenticated() returns encina.authorization.unauthenticated (401); the permanent-error classifier covers the new codes.
