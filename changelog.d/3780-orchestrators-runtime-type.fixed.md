- **Outbox, scheduler, delayed retry and saga payloads are encrypted by their runtime type** (#3780). `OutboxOrchestrator.AddAsync`, `SchedulerOrchestrator.ScheduleAsync` and `ScheduleRecurringAsync`, `DelayedRetryScheduler.ScheduleRetryAsync` and `SagaOrchestrator.StartAsync` and `AdvanceAsync` now serialize the message through its runtime type, so a concrete type marked `[EncryptedMessage]` passed as an interface or base class is stored encrypted and complete instead of in plaintext. The outbox, scheduler and delayed retry also store the runtime type name, so the message is rebuilt as that concrete type on read. An architecture test forbids direct `IMessageSerializer.Serialize<T>` calls in `Encina.Messaging` outside the serializers.
