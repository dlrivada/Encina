- Encina.MongoDB now registers the hosted outbox processor (`Encina.MongoDB.Outbox.OutboxProcessor`) when `UseOutbox = true`, for both `AddEncinaMongoDB` overloads, matching EF Core, ADO.NET and Dapper. A MongoDB outbox message whose first publish attempt fails is now retried and eventually dead-lettered by the background processor instead of being dispatched only through the request post-processor path.
