- `Encina.Compliance.DataSubjectRights`: a refused data subject request now records a standardised `DSRRejectionReason` code (`ManifestlyUnfounded`, `Excessive`, `IdentityNotVerifiable`, `RestrictedByLaw`, `RightNotApplicable`, `Other`) next to the explanation given to the subject (GDPR Art. 12(4) and 12(5)) (#814).
- `DataSubjectRightsOptions.EnableOmnibusArticle12RefusalGrounds` (default `false`) gates the draft-law ground `DSRRejectionReason.AbusiveIntent` (COM(2025) 837, draft GDPR Art. 12(5)); while it is off, `DenyRequestAsync` returns `dsr.rejection_reason_not_enabled` (#814).
- `dsr.requests.denied.total` is now incremented on every denial with the `dsr.right_type` and `dsr.rejection_reason` tags, and the deny path emits a `DSR.AggregateCommand` activity and log events 8311-8312 (#814).
