- **Breaking: `EncinaHub` clients name types by exact full name from the host allow-list** (#3677). Register every callable type inside `AddEncinaSignalR(options => ...)` with `options.AllowRequest<T>()` or `options.AllowNotification<T>()`; clients send the exact, case-sensitive `Type.FullName`, and simple, case-insensitive or assembly-qualified names no longer resolve. `AllowRequest<T>` accepts only `ICommand<TResponse>` or `IQuery<TResponse>` types, `SendCommand` runs only commands and `SendQuery` only queries, and registering the same full name twice throws. The protected virtual `EncinaHub.ResolveType` is removed. A startup check logs each anonymous entry once and warns when an `EncinaHub` is mapped with an empty allow-list; EventId 4608 is now the Debug-level denial log and 4612-4613 are new.
