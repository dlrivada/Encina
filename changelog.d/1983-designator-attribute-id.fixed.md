- ABAC: XACML target matches and condition attribute designators now select values by category, `AttributeId` and `DataType` (XACML 3.0 §7.3.5), so a value of one attribute no longer satisfies a designator for another (a user whose `subject-id` is `service` no longer matches a target on `identity-kind == "service"`) and `MustBePresent` applies to the named attribute only. `PolicyEvaluationContext` now keeps one `AttributeBag` per attribute id (each category is an `IReadOnlyDictionary<string, AttributeBag>`), `AttributeContextBuilder.ToBag` is replaced by `ToAttributeBags`, and the action category stores the request type name under `name`. A designator no longer receives values of another data type (a `date` designator does not see a `DateTime` value); `DateOnly` values are now inferred as `date`, `TimeSpan` as `time` and every integral type as `integer` (#1983).
