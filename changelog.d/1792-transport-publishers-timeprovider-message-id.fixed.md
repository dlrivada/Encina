- RabbitMQ publisher now reads the timestamp from the injected `TimeProvider` (registered by `AddEncinaRabbitMQ`) and publishes with the caller-supplied message id (for example the outbox id) as the broker `MessageId`, generating a new id only when none is supplied; `IRabbitMQMessagePublisher.PublishAsync` and `SendToQueueAsync` gain an optional `messageId` parameter (#1792).
- Azure Service Bus (`PublishToTopicAsync`, `SendToQueueAsync`, `ScheduleAsync`), Kafka (`ProduceAsync`, `ProduceWithHeadersAsync`, sent in the `MessageId` header) and Redis Pub/Sub (`PublishAsync`, new `MessageId` envelope field) publishers accept the same optional `messageId` so consumers can deduplicate (#1792).
