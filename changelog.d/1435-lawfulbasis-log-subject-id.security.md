- **Encina.Compliance.LawfulBasis no longer leaks the data subject identifier or EncinaError.Message in consent-check logs** (#1435). `LawfulBasisValidationPipelineBehavior`'s consent-check path (`ConsentCheckStarted`, `ConsentCheckPassed`, `ConsentCheckFailed`) and its LIA/enforcement warning paths (`LIACheckFailed`, `EnforcementWarning`) now log only the request type and a non-identifying reason or error code (via `EncinaError.GetCode()`), never the raw subject id or the raw error message. The same unused `subjectId` parameter was removed from the duplicate log templates in `Encina.Compliance.GDPR.Diagnostics.LawfulBasisLogMessages` for consistency.
