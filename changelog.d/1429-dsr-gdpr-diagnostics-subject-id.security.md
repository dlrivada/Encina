- **Encina.Compliance.DataSubjectRights and Encina.Marten.GDPR no longer leak data subject identifiers in logs, traces or metrics** (#1429). DSR request lifecycle/handler operations (submit, access, erasure, rectification, restriction, portability, objection), the processing-restriction pipeline behavior, and Marten.GDPR crypto-shredding operations (PII field encryption/decryption, subject forget, key rotation) now correlate via right type, request type, field name, event type or key version instead of the subject id. This prevents personal data (which may include health data under Article 9) from entering audit logs, distributed-tracing backends and metrics pipelines.
