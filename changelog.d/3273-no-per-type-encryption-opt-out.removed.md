- `[EncryptedMessage]` no longer has an `Enabled` property, so a message type can no longer be excluded from payload encryption per type: a type marked with the attribute, or derived from a marked type, is always encrypted, and `MessageEncryptionOptions.EncryptAllMessages = true` encrypts every type with no per-type exclusion; the global `MessageEncryptionOptions.Enabled` switch is removed separately (#3759) (#3273).
