- **EncinaError.Message no longer leaks into OpenTelemetry activity tags and status descriptions** (#1454). Fixes the same data-exposure pattern as #1426/#1429 and #1430, this time in activity diagnostics across `Encina.Compliance.DataSubjectRights`, `Encina.Compliance.DPIA` and `Encina.Compliance.Retention`.

  The affected call sites — `RecordFailed` and `RecordFailure` diagnostics helpers in `ProcessingRestrictionPipelineBehavior`, `DefaultDataErasureExecutor`, `DefaultDataPortabilityExporter`, `DefaultDSRService`, `DPIAReviewReminderService` and `RetentionEnforcementService` — previously recorded the raw `EncinaError.Message` directly in activity tags and status descriptions. The fix records only the error code (`EncinaError.GetCode()`) instead, preventing sensitive data from reaching activity exports, logs and observability pipelines.
