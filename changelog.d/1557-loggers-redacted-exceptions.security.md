- **Logger calls across the libraries no longer receive raw exceptions or EncinaError/exception messages** (#1557). Every exception reaches a logger through `ForLogging()` (type and stack trace, never the message) and errors are logged by error code or exception type. Covers the compliance, security, messaging, transport, caching, Marten, EF Core, MongoDB, Cdc, AWS Lambda, Polly, resilience and Refit packages. Log templates that printed `{ErrorMessage}` now print `{ErrorCode}` or `{ExceptionType}`.
- **`ReadAuditLog.EntryLogFailed`, `QueryFailed` and `PurgeFailed` take an `errorCode` instead of an `errorMessage`**.
- **A static scan test (`LoggerExceptionLeakStaticScanTests`) fails the build when a logger call under `src/` passes a raw exception, a message or an exception rendered to text**.
