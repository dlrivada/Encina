- **ABAC decision audit cross-cutting integration, phase 5** (#751). `ABACHealthCheck` reports the decision audit when it is enabled, without a write probe: Unhealthy when no `IOperationAuditStore` is registered or, under `FailClosed`, when the last write failed within `ABACOptions.DecisionAudit.HealthFailureWindow` (default 5 minutes); Degraded under `BestEffort`, for an older failure or for `InMemoryOperationAuditStore`; a successful write clears the failure. The state is the new singleton `ABACDecisionAuditHealthState`, which the PEP updates on every audited decision (the `ABACPipelineBehavior` constructor gains an optional `healthState` parameter); the health data carries a state code only, never a subject or tenant identifier.
