- The Dapper `TenantConnectionFactory` of SQL Server, PostgreSQL and MySQL fails closed: an unknown tenant id returns `tenancy.tenant_not_found` (also from `CreateConnectionForTenantAsync`, whose message no longer carries the tenant id) instead of the default database, and a missing tenant id returns `tenancy.tenant_required` while `TenancyOptions.RequireTenant` is true; the default connection string serves a missing tenant only with `RequireTenant = false`, so a scope without a tenant that resolves the `IDbConnection` registered by `AddEncinaDapperWithTenancy` now throws unless `RequireTenant` is false (#3675).
