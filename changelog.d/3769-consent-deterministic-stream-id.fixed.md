- `IConsentService.GrantConsentAsync` (`Encina.Compliance.Consent`) keeps at most one consent record per (tenant, data subject, purpose): the consent id is now derived deterministically from the effective tenant, the data subject and the purpose (an RFC 9562 version 8 UUID), so a repeated or concurrent grant no longer creates a second active record that a withdrawal would leave behind (GDPR Art. 7(3)); until #3771, a grant for a key that already has a record returns the existing consent id unchanged, whatever its status, and records nothing (#3769).
