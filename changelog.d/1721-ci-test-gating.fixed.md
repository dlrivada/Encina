- **CI no longer skips tests for changes that can break them, and CI Full no longer publishes after a red test job** (#1721, #1745). CI now runs the build and every test job when a PR changes shared build or test inputs (`Directory.Packages.props` and other `Directory.Build.*`, `global.json`, `nuget.config`, the solution, `.editorconfig`, `tests/xunit.runner.json`, `tests/appsettings.Testing.json`, `tests/Encina.TestInfrastructure`, `ci.yml`). The CI Full `pack` job requires `build` and all six test jobs to be green. `docs/releases/RELEASE-PROCESS.md` now requires a green CI Full run on the commit to tag (#1747, #1748).
