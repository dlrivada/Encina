- `DeadLetterManager` fails closed under multi-tenancy: when `AddEncinaTenancy` is registered and no tenant is resolved, reads, replays and deletes are denied with `encina.authorization.dlq_tenant_required` (403) unless the caller sets `DeadLetterFilter.AllTenants`, which is logged (#583).
- Dead letter capture rejects, before any store call and identically on all ten providers, a `FirstFailedAtUtc` that is not `DateTimeKind.Utc` and a source message id, source pattern, request type or tenant id with leading or trailing white space; the same rules apply to the manager's filters (#583).
- `ReplayAllAsync` fails the whole operation with the store's error when the store fails for one message (the messages already replayed stay recorded), and a handler's own `OperationCanceledException` is a failed replay instead of propagating; only the caller's cancellation propagates (#583).
