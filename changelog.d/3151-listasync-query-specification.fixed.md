- ADO.NET and Dapper (SqlServer, PostgreSQL, MySQL) and MongoDB repositories: `ListAsync` applies a `QuerySpecification`'s ordering, `Skip`/`Take` paging and keyset, as EF Core already did. A `QuerySpecification` binds to `ListAsync(Specification<T>)`, which built only the `WHERE` clause or filter, so these providers returned every matching row in engine order. `SpecificationSqlBuilder.BuildSelectStatement(tableName, Specification<T>)` now builds the full query statement for a query specification, and on SQL Server paging without an ordering orders by `(SELECT NULL)`, since `OFFSET`/`FETCH` require an `ORDER BY` (#3151).
