- `IDbTransactionAccessor` is now an owner/joiner lease source (`ITransactionLeaseSource`, namespace `Encina.Messaging.Transactions`): `Current` is read-only and only the accessor begins and ends the transaction. `Encina.Messaging.TransactionPipelineBehavior` takes `(IDbTransactionAccessor, ILogger)`; the three `UnitOfWorkADO` take `(IDbTransactionAccessor, IServiceProvider)`; the four ADO.NET messaging stores take an optional accessor and open their connection asynchronously; Recoverability now runs outside the transaction behavior. `TransactionalOutboxPipelineBehavior` is the new outbox write path for ADO.NET (#718).
