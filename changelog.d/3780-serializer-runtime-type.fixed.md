- `EncryptingMessageSerializer.Serialize<T>` now decides whether to encrypt, which key to use and the type name it logs and traces from the message's runtime type instead of `T`, so a message passed as an interface or a base type whose concrete type carries `[EncryptedMessage]` (or derives from a marked type) is encrypted instead of being written as plaintext; a `null` message still uses `T`, and the JSON produced by the inner serializer is unchanged (#3780).
