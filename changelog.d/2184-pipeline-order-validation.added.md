- Pipeline order validation fails closed: a pipeline whose order breaks a rule (an undefined stage, two built-in steps at one declared position, a stage override declared twice with different positions, a post-commit processor that would run before the commit) throws an `InvalidOperationException` that names the rule, the pipeline and the step types, on the first request of that pipeline and before any step or handler runs (#2184).
- `PipelineOrderValidationHostedService` validates every closed request and stream pipeline when the host starts; it is registered together with the built-in stage migration. `EncinaBuiltInPipelineStepsAttribute` marks an assembly whose behaviors and processors must declare their stage (#2184).
