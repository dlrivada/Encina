- Recoverability is configured through the options pattern: `AddEncinaRecoverability` and `UseRecoverability` both configure one `RecoverabilityOptions` read through `IOptions<RecoverabilityOptions>`; `UseRecoverability` overwrites an application `Configure<RecoverabilityOptions>` made before it, and registering both paths in one host is an error (#3263), so the registrations can no longer disagree about delayed retries (`RecoverabilityPipelineBehavior` and `DelayedRetryProcessor` now take `IOptions<RecoverabilityOptions>`) (#3262).
