- **Scoped transport publishers no longer dispose the DI-singleton connection** (#1608). The NATS, RabbitMQ, MQTT, Azure Service Bus and Kafka publishers no longer close, dispose or flush the singleton connection, channel, client or producer when their scope ends, so a transport stays usable after the first request scope; the publishers no longer implement `IDisposable`/`IAsyncDisposable`, and `RabbitMQMessagePublisher` no longer takes the `IConnection`.
- `NATSMessagePublisher` is now resolvable from the container when JetStream is off: it gained a constructor without the optional `INatsJSContext` (#1608).
