- RabbitMQ publisher now reads the timestamp from the injected `TimeProvider` (registered by `AddEncinaRabbitMQ`), and the RabbitMQ, Azure Service Bus, Kafka, Redis Pub/Sub, NATS, MQTT and Amazon SQS publishers accept an optional caller-supplied `messageId` (for example the outbox id) so consumers can deduplicate; a new id is generated only when none is supplied (#1792).
- Public signatures change: `messageId` is added to `IRabbitMQMessagePublisher.PublishAsync`/`SendToQueueAsync`, `IAzureServiceBusMessagePublisher.SendToQueueAsync`/`PublishToTopicAsync`/`ScheduleAsync`, `IKafkaMessagePublisher.ProduceAsync`/`ProduceWithHeadersAsync` (header `MessageId`; `ProduceBatchAsync` items become `(Message, Key, MessageId)`), `IRedisPubSubMessagePublisher.PublishAsync` (envelope field), `INATSMessagePublisher.PublishAsync`/`JetStreamPublishAsync` (`Nats-Msg-Id` header, also the JetStream dedup key), `IMQTTMessagePublisher.PublishAsync` (MQTT 5 user property) and `IAmazonSQSMessagePublisher.SendToQueueAsync`/`PublishToTopicAsync`/`SendToFifoQueueAsync` (`MessageId` attribute; FIFO uses it as the deduplication id when none is given) (#1792).
