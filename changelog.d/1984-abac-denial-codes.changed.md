- **ABAC denials use `encina.authorization.*` error codes** (#1984). Definite authorization denials now use the `encina.authorization.*` prefix, so the ASP.NET Core, Azure Functions and AWS Lambda adapters answer them with HTTP 403 through the shared prefix rule: `abac.access_denied` is now `encina.authorization.abac_access_denied`, `abac.condition_not_met` is now `encina.authorization.abac_condition_not_met`, and `abac.obligation_failed` is now `encina.authorization.abac_obligation_failed`. A request denied because a required policy is missing gets the new `ABACErrors.RequiredPolicyNotFoundCode` (`encina.authorization.abac_policy_not_found`). `abac.policy_not_found` stays for administrative lookups of a missing policy. The old codes are removed with no aliases.
