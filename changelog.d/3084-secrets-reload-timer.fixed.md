- `Encina.Security.Secrets`: the configuration reload timer (`SecretsConfigurationOptions.ReloadInterval`) is created through a `TimeProvider` instead of `System.Threading.Timer`, and a failed reload no longer escapes the timer callback (which can terminate the process): when loading the secrets or a reload listener throws, the error is logged with EventId 5151 (exception type and stack trace, never its message), the previously loaded secrets stay in configuration and the next interval retries (#3084).
