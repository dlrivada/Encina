- `Encina.Security.Secrets`: the configuration reload timer (`SecretsConfigurationOptions.ReloadInterval`) is created through a `TimeProvider` instead of `System.Threading.Timer`, and an exception during a reload no longer escapes the timer callback (which can terminate the process): it is logged with EventId 5151 (exception type and stack trace, never its message) and the next interval retries. When loading the secrets throws, the previously loaded secrets stay in configuration; when a reload listener throws, the secrets have already been reloaded (#3084).
