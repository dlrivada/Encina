- `Encina.Security.Secrets`: the configuration reload timer (`SecretsConfigurationOptions.ReloadInterval`) is created through a `TimeProvider` instead of `System.Threading.Timer`, and an exception during a reload no longer escapes the timer callback (which can terminate the process): it is logged with EventId 5151 (exception type and stack trace, never its message) and the next interval retries. A reload in which any secret cannot be read (the reader returns an error or throws, or no `ISecretReader` is registered) keeps the previous configuration and signals no reload; when a reload listener throws, the secrets have already been reloaded (#3084).
