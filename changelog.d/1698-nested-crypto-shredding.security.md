- **`[CryptoShredded]` personal data is encrypted at any depth** (#1698). Properties on nested objects, collection elements, dictionary values, polymorphic members, records and non-public `[JsonInclude]` properties are now encrypted with the key of the subject named by the `SubjectIdProperty` sibling on the object that declares them; before, only the top-level event type was scanned and nested personal data was stored in plaintext. Every shape that would leak or not round-trip is rejected at startup and on first use with a reason per property.
- **Crypto-shredded reads fail closed** (#1698). Only a forgotten subject reads as the anonymized placeholder; a key-store error, a tampered or foreign token, a malformed value or a missing subject id throws `CryptoShreddingDecryptionException`. The `cs2:erased` tombstone reads as the placeholder only after the key provider confirms the subject is forgotten, and Marten's async daemon no longer skips serialization errors, so a decryption failure pauses the shard instead of dead-lettering the event. The installation of the serializer is verified at startup, in the health check and on the first write.
