- **Recoverability retry jitter is thread-safe** (#2250). `RecoverabilityPipelineBehavior` drew its jitter from a static, non-thread-safe `Random` shared by every concurrent request of the same request type. Concurrent retries therefore often received the same draw (and occasionally zero), collapsing the jitter spread that `UseJitter` and `MaxJitterPercent` promise. Jitter now comes from `Random.Shared`.
