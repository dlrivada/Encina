- `EncinaConfiguration` gains stage-aware overloads: `AddPipelineBehavior`, `AddRequestPreProcessor`, `AddRequestPostProcessor`, `AddRequestErrorProcessor`, `AddRequestPostCommitProcessor` and `AddStreamPipelineBehavior` (type and generic forms) take a `PipelineStage` and an optional order that override the `[PipelineStage]` attribute of the type (processor overloads default to order -100, the order of the kind, behaviors to 0); the declarations reach the pipeline order resolver of every `AddEncina` call (#2184).
- `AddEncina` registers `IEncinaPipelineInspector` (singleton), which reports the resolved step order, stage and source of any request or stream pipeline, and scans `IRequestErrorProcessor<,>` and `IRequestPostCommitProcessor<,>` implementations (#2184).
