- **AES-GCM field decryption rejects wrong-sized nonce and tag** (#2713). `AesGcmFieldEncryptor` now returns `Left(EncryptionErrors.InvalidCiphertext())` for a stored `EncryptedValue` whose nonce is not 12 bytes or whose tag is not 16 bytes, instead of letting `ArgumentException` escape the `Either` API.
- **AES-GCM field decryption failures are indistinguishable** (#2713). Every decryption failure caused by the stored value or the key (a tag that fails verification, a tampered ciphertext, mismatched associated data, a wrong key, as well as a wrong-sized nonce or tag) now returns the same generic `EncryptionErrors.InvalidCiphertext()`, with no key id and no exception, so the error is no oracle for an attacker. `AesGcmFieldEncryptor` no longer returns `encryption.decryption_failed` on the decrypt path; callers that matched that code must match `encryption.invalid_ciphertext`. Key lookup failures (key not found, wrong provider key length) keep their errors.
