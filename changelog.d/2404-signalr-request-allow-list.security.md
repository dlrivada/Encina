- **`EncinaHub` runs only host-registered types** (#3677, #2404). `SendCommand`, `SendQuery` and `PublishNotification` no longer resolve a client-supplied type name through `Type.GetType` and a scan of every loaded assembly: they run only types registered with `SignalROptions.AllowRequest<T>()` or `AllowNotification<T>()` (deny-all by default), look the name up before deserializing the payload, and require an authenticated caller unless the type was registered with `allowAnonymous: true`. Unknown, not exposed, wrong-kind and unauthenticated calls get the same `*.type_not_found` response, which no longer echoes the name, and the client string reaches logs only at Debug level, truncated to 64 characters and stripped of control characters.
