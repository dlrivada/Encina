- **Breaking: PII `MaskingMode.Hash` now computes a keyed HMAC-SHA256 instead of an unkeyed SHA-256** (#858). The key is configured with the new `PIIOptions.HashKey`, `MaskingOptions.HashSalt` is renamed `MaskingOptions.HashKey` (no alias), and hashes change. Using Hash mode without a key now fails at startup (`AddEncinaPII` and `ValidateOnStart`) unless the explicit `PIIOptions.AllowUnkeyedHash` opt-out is set, which logs a warning; a property that selects Hash without a key is redacted instead of hashed. An empty or whitespace key is invalid, as is a key shorter than 32 UTF-8 bytes (`PIIOptions.MinimumHashKeyBytes`, the HMAC-SHA256 output length), and the key is excluded from JSON serialization and `ToString()`.
