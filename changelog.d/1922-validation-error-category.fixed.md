- Validation failures produced by `ValidationOrchestrator` now emit categorized `EncinaErrorCodes.ValidationFailed` errors carrying `ErrorCategory.Validation`, ensuring HTTP hosts answer 400 instead of an uncategorized error (#1922). Canonical validation and not-found error codes (`EncinaErrorCodes.ValidationFailed`, `EncinaErrorCodes.NotFound`) and factory methods (`EncinaErrors.Validation`, `EncinaErrors.NotFound`) are now exposed in the core `Encina` package.
