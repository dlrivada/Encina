- **SignalR broadcasts without targets are refused unless the host opts in** (#3678, #2404). A `[BroadcastToSignalR]` notification that declares no `TargetUsers` or `TargetGroups` (whitespace-only values count as none) is no longer sent to every connected client: it reaches `Clients.All` only when the host registers its type with `SignalROptions.AllowBroadcastToAll<T>()`. Otherwise, and whenever the declared targets resolve to no user or group (even for a registered type), nothing is sent and error 4614 is logged with the notification type name only. The attribute's XML example that broadcast to everyone now names its targets.
