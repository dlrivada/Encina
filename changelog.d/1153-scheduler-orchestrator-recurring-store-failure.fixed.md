- **`SchedulerOrchestrator.ScheduleRecurringAsync` now propagates a store failure as `Left`** (#1153). It used to discard the `Either` returned by `_store.AddAsync` and always return `Right(message.Id)`, so a failed insert still handed back an id for a recurring message that was never persisted. It now checks `addResult.IsLeft` and returns the store's error, matching the non-recurring `ScheduleAsync`.
