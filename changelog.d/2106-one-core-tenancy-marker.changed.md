- One core multi-tenancy marker (#2106): the dead letter manager and the EF Core query cache interceptor now read the core `MultiTenancyMarker`, the same signal the ABAC decision audit reader uses, so `AddEncinaTenancy` registers one marker for every tenant-aware component. `Encina.Messaging.Tenancy.TenancyInUse` is removed, the `DeadLetterManager` constructor takes `MultiTenancyMarker?` instead, and the query cache bypass for requests without a tenant now follows the marker instead of the presence of an `ITenantProvider` (an application with its own tenant provider and no `AddEncinaTenancy` registers `MultiTenancyMarker` itself).
