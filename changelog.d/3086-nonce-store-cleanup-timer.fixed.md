- `Encina.Security.AntiTampering`: the cleanup timer of `InMemoryNonceStore` is created through the injected `TimeProvider` instead of `System.Threading.Timer`, so a fake clock drives the periodic sweep, and a failing sweep no longer escapes the timer callback (which can terminate the process): it is logged as an error with EventId 9108 (exception type and stack trace, never its message) and the next sweep retries. The constructor takes an optional `ILogger<InMemoryNonceStore>` (#3086).
