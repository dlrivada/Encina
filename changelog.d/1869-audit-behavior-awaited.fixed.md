- `AuditPipelineBehavior` now awaits the audit write in its own child scope instead of firing it and forgetting it, so it never touches a disposed scope. A failed write fails a successful request with `audit.write_failed` by default (`OperationAuditOptions.FailureMode = FailClosed`); `BestEffort` is an explicit opt-out that logs every dropped write at Warning. The behavior now takes an `IServiceScopeFactory` instead of an `IOperationAuditStore` (#1869). The audit write now suppresses any ambient `System.Transactions.TransactionScope` (`TransactionScopeOption.Suppress`), so the audit entry is never enlisted in, nor rolled back with, the request's ambient transaction.
