- Query-cache and cache-provider log entries no longer contain the caller's user id or tenant id. Cache keys and key patterns are logged with their `t:` and `u:` segments redacted (`t:***`, `u:***`) through the new `CacheKeyRedactor` in `Encina.Caching`; the real key is still used for the cache itself. Affects EventIds 3500, 3501, 3508-3511 (`Encina.Caching`) and the key logs of the Memory, Hybrid and Redis cache providers (also used by Valkey, Dragonfly, Garnet and KeyDB), and the scatter-gather executor (#1953).
