- **Read/write separation is now registered on ADO.NET and Dapper PostgreSQL and MySQL** (#2029). With `UseReadWriteSeparation` enabled, `AddEncinaADO` and `AddEncinaDapper` of `Encina.ADO.PostgreSQL`, `Encina.ADO.MySQL`, `Encina.Dapper.PostgreSQL` and `Encina.Dapper.MySQL` now register the options, the replica and connection selectors, `IReadWriteConnectionFactory`, `ReadWriteRoutingPipelineBehavior<,>` and the `ReadWriteSeparationHealthCheck`, as the SQL Server, EF Core and MongoDB providers already did. Before, the routing behavior existed in those four packages but was never added to the container, so queries and commands were not routed.
