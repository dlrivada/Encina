- `DefaultTokenizer` and `DefaultPseudonymizer` now return one generic `anonymization.decryption_failed` error for every stored-value or key failure (short blob, bad tag, tampered ciphertext, wrong key, non-Base64 value), with no key id, no exception and no cause text. `AnonymizationErrors.DecryptionFailed` no longer takes a key id or an exception. A non-Base64 value in `DepseudonymizeAsync` is now an error instead of being skipped. (#2770)
- A key that is not 32 bytes now returns `anonymization.key_not_found` from the tokenizer and pseudonymizer AES-GCM paths instead of throwing from `AesGcm`, and error messages no longer contain exception text. (#2770)
