- **DPIAHealthCheck no longer includes sensitive error details in HealthCheckResult** (#1499). The health check previously put raw `EncinaError.Message` and `System.Exception.Message` into its warnings list, exposing potentially sensitive information in health-check dashboards, `/health` endpoints and diagnostics exports. Both are now replaced with only the error code (via `error.GetCode().IfNone("encina.unknown")`) or exception type name (via `ex.GetType().Name`), consistent with the rule that forbids `EncinaError.Message` from reaching logs, activity tags, health-check results or plaintext storage.
