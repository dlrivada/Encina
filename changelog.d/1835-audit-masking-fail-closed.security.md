- The audit module no longer stores raw personal data when PII masking fails: `DefaultOperationAuditEntryFactory` throws `OperationAuditMaskingException`, `AuditPipelineBehavior` returns the `audit.masking_failed` error (fail closed) and nothing is stored; `DefaultSensitiveDataRedactor` throws instead of returning the unmasked request or text (#1835).
- `AddEncinaAudit` no longer registers a default pass-through `IPiiMasker`: the host fails at startup when no masker is registered, unless the application sets `OperationAuditOptions.AllowUnmaskedPayloads = true` (registers `NullPiiMasker` and logs a warning at every start). The payload path now also runs custom maskers (#1835).
