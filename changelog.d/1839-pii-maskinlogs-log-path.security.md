- The log helpers of `Encina.Security.PII` (`LogMasked`, `LogInformationMasked`, `LogWarningMasked`, `LogErrorMasked`) now mask properties marked `[MaskInLogs]`, which were previously written to logs in clear, through the new `IPIIMasker.MaskForLog<T>`. `[PII]` and `[SensitiveData]` stay masked in the log context, `MaskingMode.Tokenize` is treated as `Redact` there, `PIIOptions.MaskInLogs = false` returns the object unmasked, and a masking failure logs the `[MASKING FAILED]` placeholder plus a redacted warning (EventId 8023). Custom `IPIIMasker` implementations must implement `MaskForLog` (#1839).
