- Keyset pagination follows the sort direction of the keyset property on every provider (ADO.NET and Dapper for SqlServer, PostgreSQL and MySQL, EF Core and MongoDB): when the specification orders the keyset property descending, the next page is filtered with `<` instead of `>`, so it holds the smaller keys instead of the wrong rows or none. The direction comes from the new `IsKeysetDescending` extension property on `IQuerySpecification<T>`, which looks the keyset property up in the primary ordering and the ThenBy/ThenByDescending expressions (#3154).
