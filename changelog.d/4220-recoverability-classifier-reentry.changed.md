- **A `RecoverabilityOptions` configure action that injects `IErrorClassifier` now fails on every runtime** (#4220). Resolving `IErrorClassifier` throws an `InvalidOperationException` that names the circular dependency, on .NET 10 as on .NET 11, instead of handing the configure action the classifier registered earlier (or `DefaultErrorClassifier`). Set `RecoverabilityOptions.ErrorClassifier` instead.
