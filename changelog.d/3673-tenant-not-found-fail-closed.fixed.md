- `TenantConnectionFactoryBase<TConnection>` (Encina.Tenancy) fails closed: a tenant id the tenant store does not know returns `TenancyErrors.TenantNotFound()` (code `tenancy.tenant_not_found`) and creates no connection, instead of falling back to `TenantConnectionOptions.DefaultConnectionString`; with no tenant id it returns `TenancyErrors.TenantRequired()` (code `tenancy.tenant_required`) unless `TenancyOptions.RequireTenant` is `false`. Its constructor now also takes `IOptions<TenancyOptions>` (#3673).
- Removed the unread `TenantConnectionOptions.ThrowOnMissingConnectionString` option, whose documentation promised a fallback to the default database for unknown tenants (#3673).
