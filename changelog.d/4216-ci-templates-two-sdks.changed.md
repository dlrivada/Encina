- **Reusable CI templates install two .NET SDKs by default** (#4216). The `encina-test`, `encina-matrix` and `encina-full-ci` reusable workflows and the copyable mutation-tests template now install SDK `10.0.x` and `11.0.x` by default: the `dotnet-version` input default is a two-line value. Without a `global.json` in the calling repository, the newest installed SDK (11) builds the project, so adopters that target .NET 10 should pin a `global.json` or pass `10.0.x` only.
