- **Fixed `AdoMigrationHistoryStore` and `PostgreSqlSchemaIntrospector` to use `TimeProvider` instead of wall-clock time** (#1325). Both classes previously read `DateTime.UtcNow` or `DateTimeOffset.UtcNow` directly; they now accept an optional `TimeProvider` parameter (defaulting to `TimeProvider.System`) and use it for all timestamps, enabling testable time in integration tests and complying with AGENTS.md that production code never reads wall-clock time directly.

- **Replaced synchronous ADO.NET calls with async overloads throughout `Encina.ADO.PostgreSQL`** (#1325). `UnitOfWorkADO`, `BulkOperationsPostgreSQL`, `PolicyStoreADO`, `TokenMappingStoreADO`, `TemporalRepositoryADO`, `ReferenceTableStoreADO`, and the sharding migration helpers (`AdoHelper`, `AdoMigrationExecutor`) now call the async ADO.NET overloads (`OpenAsync`, `BeginTransactionAsync`, `ExecuteNonQueryAsync`, etc.) with a propagated `CancellationToken`. This avoids synchronous blocking calls on the hot unit-of-work path and complies with AGENTS.md that database calls MUST be asynchronous with a `CancellationToken`.
