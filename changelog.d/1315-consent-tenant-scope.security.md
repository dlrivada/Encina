- **All Encina.Compliance.Consent read queries are tenant-scoped** (#1315). `GetConsentAsync`, `GetConsentBySubjectAndPurposeAsync`, `GetAllConsentsAsync` and `HasValidConsentAsync` now respect the current tenant from `IRequestContext.TenantId`, preventing one tenant from querying another tenant's consent records (including cached read-model records). A missing ambient tenant fails closed with `ConsentErrors.TenantRequired` by default in a multi-tenant application (when `Encina.Tenancy` is registered); single-tenant applications, which never register `Encina.Tenancy`, are unaffected. The new `ConsentOptions.RequireTenantContext` option (nullable bool, default `null` = auto-detect) can force either behavior explicitly; an explicit opt-out (`false`) while `Encina.Tenancy` is registered is logged so it is never silent.
