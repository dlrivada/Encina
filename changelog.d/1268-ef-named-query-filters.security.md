- **EF Core named query filters fix cross-tenant data leak (#1268)**. The tenant isolation (`"Encina.Tenancy"`) and soft-delete (`"Encina.SoftDelete"`) query filters applied to EF Core models are now both registered as named filters, ensuring they coexist regardless of configuration order. Previously, unnamed filters could silently overwrite each other on entities implementing both `ITenantEntity` and `ISoftDeletable`, potentially leaking rows across tenant boundaries. Additionally, EF Core 10 operations that read or restore soft-deleted rows now call the keyed `IgnoreQueryFilters()` overload to skip only the soft-delete filter, keeping tenant scoping in place so these operations remain scoped to the current tenant.
