- **EF Core query filters now use named filters (#1268)**. The tenant and soft-delete query filters applied to EF Core models now use named-filter semantics (`"Encina.Tenancy"` and `"Encina.SoftDelete"` keys) instead of unnamed filters, ensuring both filters coexist regardless of application order. This fixes a cross-tenant data leak: entities implementing both `ITenantEntity` and `ISoftDeletable` would silently lose one filter when the other was applied afterward, potentially leaking rows across tenant boundaries.
