- **`SanitizeForSql` no longer returns SQL comment markers or `xp_`** (#922). Removing one dangerous sequence could join the surrounding characters into a new one (`*;/` became `*/`, `-;-` became `--`, `-xp_a-` became `--`), and a bare `xp_` or `axp_b` survived the extended-procedure pattern. The sanitizer now scans the input once and removes each dangerous token (`--`, `/* */`, `;`, `xp_`) from the output tail as it forms, in linear time, so no marker is returned for any input and hostile nested input cannot cause quadratic work; `xp_` is also removed inside identifiers such as `myxp_col`.
