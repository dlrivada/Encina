- **`SanitizeForSql` no longer returns SQL comment markers or `xp_`** (#922). Removing one dangerous sequence could join the surrounding characters into a new one (`*;/` became `*/`, `-;-` became `--`, `-xp_a-` became `--`), and a bare `xp_` or `axp_b` survived the extended-procedure pattern. The sanitizer now repeats the removal of `--`, `/* */`, `;` and `xp_` until the string is stable, so no marker is returned for any input; `xp_` is also removed inside identifiers such as `myxp_col`.
