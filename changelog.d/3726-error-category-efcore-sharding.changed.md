- All 11 `EncinaErrors.Create` calls of `Encina.EntityFrameworkCore` sharding (migration executor, migration history store, schema introspector, reference table store and the sharded read/write context factory) now declare an `ErrorCategory` (#3726, ADR-062); the error codes and messages are unchanged.
- `encina.sharding.all_replicas_unhealthy` (1 call, when `FallbackToPrimaryWhenNoReplicas` is off and every replica is marked unhealthy) is `ErrorCategory.Unavailable` and now answers HTTP 503 instead of 500, with no `Retry-After`; the other 10 calls are `ErrorCategory.Internal` and keep answering 500.
