- **The dead-letter queue no longer stores or logs `EncinaError.Message`** (#1274). `DeadLetterOrchestrator` records the error code in `ErrorMessage`, leaves `ExceptionMessage` empty (the exception type and stack trace are kept) and logs only the code. `AddFromFailedMessageAsync` builds the record itself and serializes the request through `IMessageSerializer`, so encryption applies; `IDeadLetterMessageFactory.CreateFromFailedMessage` was removed and factories implement `Create(DeadLetterData)` only.
