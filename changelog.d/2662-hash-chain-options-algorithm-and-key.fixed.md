- **HashChainOptions rejects unsupported hash algorithms and no longer exposes the HMAC key** (#2662). `HashChainAttestationProvider` throws `ArgumentException` at construction (also when a key is supplied) and `AddEncinaAttestation` validates the algorithm at startup, instead of silently using a 32-byte key size fallback. `HashChainOptions.HmacKey` is now `[JsonIgnore]` and `HashChainOptions.ToString()` prints `HmacKey = [REDACTED]`, so the key cannot be serialized or logged.
