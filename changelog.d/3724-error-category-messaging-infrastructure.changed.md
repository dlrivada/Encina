- Every error of the dead letter queue, inbox, outbox and recoverability producers of `Encina.Messaging` now declares an `ErrorCategory` (ADR-062, #3724); the code strings and messages are unchanged.
- HTTP status changes: `encina.authorization.dlq_tenant_required` answers `InvalidRequest` (400) instead of `Forbidden` (403); `inbox.missing_message_id` answers `InvalidRequest` (400) instead of 500; `dlq.already_replayed` and `dlq.expired` answer `Conflict` (409) instead of 500; `dlq.delete_failed` answers `NotFound` (404) instead of 500. `dlq.not_found` stays `NotFound` (404); every other code of these producers stays `Internal` (500). `dlq.capture_rejected`, `inbox.max_retries_exceeded`, `inbox.cached_error` and `recoverability.retry_after_exceeds_ceiling` are pending a maintainer decision and keep `Internal` (500) for now. The scheduling, transaction pipeline and transactions producers follow in a separate change.
