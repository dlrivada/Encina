- **HttpAttestationProvider no longer throws on a malformed 2xx response** (#2656). An empty body, non-JSON body, unsupported content type, non-object JSON root or a wrongly typed `attestation_id`/`signature` now makes `AttestAsync` return `Left(attestation.provider_unavailable)` (and increment the failed-attestation metric); `VerifyAsync` returns the same `Left` when no verdict can be read (including an `is_valid` that is not a JSON boolean). A non-string `failure_reason` on a negative verdict is ignored in favour of the default reason. The error text never includes the exception message.
