- The ADO.NET, Dapper, EF Core and MongoDB providers now remove the in-memory `ITokenMappingStore` default before registering their own database-backed token mapping store, so the database store wins regardless of the order in which `AddEncinaAnonymization` and the provider's registration method run (mirrors the fix for #1269 read-audit-store ordering). A custom `ITokenMappingStore` the application registers itself is left untouched and keeps winning.
