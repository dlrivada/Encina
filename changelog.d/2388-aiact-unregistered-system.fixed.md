- **AI Act validator denies unregistered AI systems** (#2388). A request whose resolved AI system id is not registered in `IAISystemRegistry` is no longer classified as `MinimalRisk`; it now returns a `HighRisk` result (human oversight and transparency required, not prohibited) with one violation naming the system. The pipeline denies the request in Block mode (the default) and logs a warning in Warn mode, which is the explicit staged path while systems are registered. Requests with no resolvable system id are unchanged.
