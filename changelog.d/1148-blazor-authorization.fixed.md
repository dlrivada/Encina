- Fixed `AuthorizationPipelineBehavior` denying every `[Authorize]` request inside a Blazor Server interactive circuit, where `HttpContext` is unavailable for the lifetime of the circuit. The behavior now resolves the caller's principal through a new `IPrincipalResolver` abstraction (`Encina.AspNetCore`) instead of reading `IHttpContextAccessor` directly; the default `HttpContextPrincipalResolver` preserves today's HTTP-only behavior. A new `Encina.AspNetCore.Blazor` package provides `AuthenticationStatePrincipalResolver` and `AddEncinaBlazorAuthorization()`, which resolves the principal from `AuthenticationStateProvider` when there is no ambient `HttpContext`.
