- EF Core: keyset pagination on a `string` or `Guid` property no longer throws `InvalidOperationException` ("The binary operator GreaterThan is not defined"). The `SpecificationEvaluator` keyset filter and the cursor pagination extensions (`ToCursorPaginatedAsync`, `ToCursorPaginatedDescendingAsync`, `ToCursorPaginatedCompositeAsync`) compare these keys through `string.Compare` and `Guid.CompareTo`, which EF Core translates to the database's own comparison, the one its `ORDER BY` uses (#3201).
