- EF Core: keyset pagination on a `string` property no longer throws `InvalidOperationException` ("The binary operator GreaterThan is not defined for the types 'System.String' and 'System.String'"). The `SpecificationEvaluator` keyset filter and the cursor pagination extensions (`ToCursorPaginatedAsync`, `ToCursorPaginatedDescendingAsync`, `ToCursorPaginatedCompositeAsync`) compare string keys through `string.Compare`, which EF Core translates to the database's own comparison, the one its `ORDER BY` uses. In a composite cursor key, an earlier string member also matches when `string.Compare` is zero, so in-memory paging agrees with the ordering for canonically equivalent strings. A string keyset member declared nullable is rejected with `NotSupportedException`: databases order `NULL` keys differently and a `NULL` key never satisfies the comparison, so pages would skip or repeat rows. `Guid` keysets already worked through `Guid`'s comparison operators; integration tests on SQL Server and PostgreSQL now cover them (#3201).
