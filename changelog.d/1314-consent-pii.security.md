- **Encina.Compliance.Consent no longer leaks subject identifiers in logs, traces or metrics** (#1314). Grant/withdraw/query operations no longer log the data subject's own `SubjectId` identifier, and consent-check traces/activity tags/metric dimensions (OpenTelemetry) now use non-personal correlation keys (consent id, purpose code, request type, error code) instead. This prevents personal data from entering audit logs, distributed-tracing backends, and metrics pipelines.
