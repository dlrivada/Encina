- **Weekly Benchmarks no longer hit the 60-minute job limit** (#2510). `ProcessorAgreementServiceBenchmarks` (13 benchmarks, cancelled at the 60-minute limit) is split into three classes (`ProcessorAgreementServiceBenchmarks`, `ProcessorAgreementLifecycleBenchmarks`, `ProcessorAgreementProcessorBenchmarks`) and `DPIAServiceBenchmarks` (12 benchmarks, 46-minute job) into three (`DPIAServiceBenchmarks`, `DPIAStateTransitionBenchmarks`, `DPIAQueryBenchmarks`), each its own matrix job well under 30 minutes. Benchmark series are keyed by class and method, so the moved benchmarks start new series on the dashboard once, and each class now has its own baseline, so the Ratio column is relative to that class's baseline benchmark.
- **A failed or cancelled benchmark class no longer blocks publishing the dashboard data** (#2510). `Publish Benchmarks Data` now publishes the aggregate snapshot of a run that did not conclude `success` when its `Aggregate all benchmark results` job succeeded, with a warning annotation and step summary naming each matrix job that did not succeed. A run whose aggregate job did not succeed is still refused. Carrying the previous series forward for the missing classes remains #1575.
