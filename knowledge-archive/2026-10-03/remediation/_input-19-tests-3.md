The CRAP gate's self-test does not run when the gate's own files change. The `crap-gate` job runs only when `needs.changes.outputs.src == 'true'` (`ci.yml:499-504`), and the `src` filter lists `src/**`, `Directory.*.props` and `*.slnx` (`ci.yml:39-42`), not `.github/scripts/crap-gate.cs`, `crap-gate-selftest.ps1` or `.github/scripts/testdata/**`. A PR that edits only the gate (the area of #1506 and #1508) merges with its self-test never executed, which is precisely the regression the self-test was written for (#1354: "so a broken gate fails loudly"). Missing: a path trigger for the self-test (a separate small job on `.github/scripts/crap-gate*` and `.github/scripts/testdata/crap-gate/**`, or add those paths to the filter). Deterministic: yes, a workflow-text test can assert the paths are present.
