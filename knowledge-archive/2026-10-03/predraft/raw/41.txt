## Summary

Implement low-ceremony saga syntax inspired by Wolverine for simpler saga definitions.

## Motivation

- **Phase**: 2 - Functionality
- **Priority**: High
- **Complexity**: Medium

Traditional saga definitions require significant boilerplate (state classes, mappers, handler methods). A low-ceremony alternative reduces friction for simple sagas while keeping full saga capabilities available for complex scenarios.

## Proposed Solution

### Features

- Minimal saga boilerplate
- Convention-based message routing
- Inline state management
- Fluent compensation definition

### Proposed API

```csharp
// Traditional approach requires much boilerplate
// Low-ceremony approach:

public class OrderHandler
{
    [Saga]
    public async Task<SagaStep> Handle(StartOrder command)
    {
        return SagaStep
            .Do(new ProcessPayment(command.OrderId))
            .OnSuccess(new ShipOrder(command.OrderId))
            .OnFailure(new RefundPayment(command.OrderId))
            .Timeout(TimeSpan.FromMinutes(5));
    }
}
```
