## Summary

**Create a quickstart guide** that gets users running their first Encina request in under 5 minutes.

## Motivation

- **Fast onboarding**: Minimize time to first success
- **Immediate value**: Users see results quickly
- **Confidence building**: Working code proves library works
- **Gateway to deeper learning**: Success leads to exploration

## Proposed Solution

### Quickstart Flow (5 Minutes)

1. **Install package** (30 seconds)
   ```bash
   dotnet add package Encina
   ```

2. **Configure services** (30 seconds)
   ```csharp
   builder.Services.AddEncina(typeof(Program).Assembly);
   ```

3. **Create a command** (1 minute)
   ```csharp
   public record CreateGreeting(string Name) : ICommand<string>;
   ```

4. **Create a handler** (1.5 minutes)
   ```csharp
   public class CreateGreetingHandler : ICommandHandler<CreateGreeting, string>
   {
       public Task<Either<EncinaError, string>> HandleAsync(
           CreateGreeting command, CancellationToken ct)
           => Task.FromResult<Either<EncinaError, string>>($"Hello, {command.Name}!");
   }
   ```

5. **Send and handle result** (1.5 minutes)
   ```csharp
   var result = await mediator.SendAsync(new CreateGreeting("World"));
   result.Match(
       error => Console.WriteLine($"Error: {error.Message}"),
       message => Console.WriteLine(message)); // "Hello, World!"
   ```
