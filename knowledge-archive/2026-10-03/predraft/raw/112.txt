## Summary

Migrate existing tests to use the new fluent ROP assertion extensions from `Encina.TestInfrastructure`.

## Motivation

- [ ] Code duplication
- [ ] Poor separation of concerns
- [x] Applying a design pattern
- [x] Simplifying complex code
- [ ] Improving testability
- [ ] Performance optimization
- [ ] Preparing for future feature work
- [ ] Other

## Current Structure

Tests currently use verbose patterns like:
```csharp
result.IsRight.Should().BeTrue();
var value = result.Match(Right: v => v, Left: _ => "");
```

## Proposed Structure

Tests should use the new fluent extensions:
```csharp
var value = result.ShouldBeSuccess();
// or
result.ShouldBeErrorWithCode("encina.validation.failed");
```
