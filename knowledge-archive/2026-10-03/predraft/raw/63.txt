## Summary

Implement the Scatter-Gather pattern for parallel request distribution and response aggregation.

## Motivation

- **Phase**: 2 - Functionality
- **Priority**: Low
- **Complexity**: High

The Scatter-Gather pattern (an Enterprise Integration Pattern) broadcasts a request to multiple recipients in parallel and aggregates their responses. This is useful for scenarios like price comparison (scatter to multiple vendors, gather the best quote), parallel search (scatter across multiple data sources), and quorum-based decisions.

## Proposed Solution

- Scatter to multiple recipients in parallel
- Configurable gathering strategies (WaitForAll, WaitForFirst, WaitForQuorum)
- Timeout handling for slow responders
- Partial result support when not all recipients respond

```csharp
var scatterGather = new ScatterGatherBuilder<PriceQuote>()
    .ScatterTo<GetQuoteFromVendorA>()
    .ScatterTo<GetQuoteFromVendorB>()
    .ScatterTo<GetQuoteFromVendorC>()
    .GatherWith(GatherStrategy.WaitForAll, timeout: TimeSpan.FromSeconds(10))
    .Aggregate((quotes) => quotes.MinBy(q => q.Price))
    .Build();

var bestQuote = await _encina.Execute(scatterGather, new QuoteRequest(productId));
```

### Scatter-Gather Pattern Implemented

The Scatter-Gather Enterprise Integration Pattern has been fully implemented with:

**Core Features:**
- `IScatterGatherRunner` interface with `ExecuteAsync` method
- `ScatterGatherBuilder` fluent API for defining scatter-gather operations
- Four gather strategies: WaitForAll, WaitForFirst, WaitForQuorum, WaitForAllAllowPartial
- Aggregation methods: TakeFirst, TakeMin, TakeMax, Aggregate, AggregateSuccessful
- Parallel and sequential execution modes with configurable max parallelism
- Timeout and cancellation support
- High-performance logging with LoggerMessage source generators (EventIds 600-615)
- DI integration via `MessagingConfiguration.UseScatterGather = true`

**Test Coverage (131 tests):**
- Unit tests: 67 tests (builder + runner)
- Property-based tests: 15 invariant tests
- Contract tests: 7 interface contract tests
- Guard clause tests: 8 parameter validation tests
- Load tests: 6 concurrency/performance tests
- Benchmarks: 6 performance scenarios

**Example Usage:**
```csharp
var definition = ScatterGatherBuilder.Create<PriceRequest, decimal>("PriceAggregator")
    .ScatterTo("SupplierA", async (req, ct) => await GetPriceFromA(req, ct))
    .ScatterTo("SupplierB", async (req, ct) => await GetPriceFromB(req, ct))
    .ScatterTo("SupplierC", async (req, ct) => await GetPriceFromC(req, ct))
    .ExecuteInParallel()
    .GatherAll()
    .TakeMin(price => price)
    .Build();

var result = await runner.ExecuteAsync(definition, new PriceRequest("SKU123"));
```
