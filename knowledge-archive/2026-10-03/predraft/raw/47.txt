## Summary

Create a CLI tool for scaffolding Encina-based projects and components.

## Motivation

- **Phase**: 2 - Functionality
- **Priority**: Medium
- **Complexity**: High

Developers need a fast way to scaffold Encina projects and generate handlers, sagas, and package configurations. A CLI tool (like `dotnet ef` or `dotnet aspire`) reduces onboarding friction and enforces project conventions.

## Proposed Solution

### Features

- Project scaffolding
- Handler generation
- Saga generation
- Integration with `dotnet new`

### Proposed Commands

```bash
# Install the tool
dotnet tool install -g Encina.Cli

# Create new project
encina new api MyApi
encina new worker MyWorker

# Generate handlers
encina generate handler CreateOrder --response OrderId
encina generate query GetOrderById --response Order

# Generate sagas
encina generate saga OrderProcessing --steps "Create,Pay,Ship"

# Add packages
encina add caching redis
encina add database dapper-sqlserver
encina add transport rabbitmq
```
