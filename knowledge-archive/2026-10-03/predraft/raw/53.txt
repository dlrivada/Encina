## Summary

Implement bulkhead isolation pattern for parallel execution isolation using Polly.

## Motivation

- **Phase**: 2 - Functionality
- **Priority**: Medium
- **Complexity**: Medium

In distributed systems, a single slow or failing downstream dependency can consume all available threads and cascade failures across the entire application. The bulkhead pattern isolates execution into separate pools, limiting the blast radius of failures and preventing resource exhaustion.

## Proposed Solution

- Limit concurrent executions per handler type
- Prevent cascade failures by isolating execution pools
- Queue excess requests with configurable limits
- Configurable per command/query type

```csharp
services.AddEncinaBulkhead(config =>
{
    // Global bulkhead
    config.MaxConcurrency = 100;
    config.MaxQueuedActions = 50;

    // Per-handler bulkhead
    config.ForHandler<ProcessPaymentHandler>(options =>
    {
        options.MaxConcurrency = 10;  // Limit payment processing
        options.MaxQueuedActions = 20;
    });
});
```
