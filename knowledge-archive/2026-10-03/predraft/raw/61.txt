## Summary

Create Azure Durable Functions integration for orchestration workflows with Encina handlers.

## Motivation

- **Phase**: 2 - Functionality
- **Priority**: Low
- **Complexity**: High

Azure Durable Functions provide stateful orchestration for long-running workflows. Integrating Encina commands as activity functions enables developers to compose complex workflows (saga patterns, fan-out/fan-in) using familiar Encina patterns within the Durable Functions framework, with built-in replay resilience and compensation support.

## Proposed Solution

- Durable orchestration support
- Activity function integration (each activity is an Encina command)
- Saga pattern with Durable Functions compensation
- Fan-out/fan-in patterns

```csharp
public class OrderOrchestration
{
    [Function("OrderOrchestrator")]
    public async Task<OrderResult> RunOrchestrator(
        [OrchestrationTrigger] TaskOrchestrationContext context,
        IEncina encina)
    {
        var orderId = context.GetInput<Guid>();

        // Each activity is an Encina command
        var paymentResult = await context.CallActivityAsync<PaymentResult>(
            "ProcessPayment", new ProcessPayment(orderId));

        if (!paymentResult.Success)
        {
            await context.CallActivityAsync("RefundPayment", new RefundPayment(orderId));
            return OrderResult.Failed("Payment failed");
        }

        await context.CallActivityAsync("ShipOrder", new ShipOrder(orderId));

        return OrderResult.Completed(orderId);
    }

    [Function("ProcessPayment")]
    public async Task<PaymentResult> ProcessPayment(
        [ActivityTrigger] ProcessPayment command,
        IEncina encina)
    {
        var result = await encina.Send(command);
        return result.Match(
            Right: _ => PaymentResult.Success,
            Left: error => PaymentResult.Failed(error.Message)
        );
    }
}
```
