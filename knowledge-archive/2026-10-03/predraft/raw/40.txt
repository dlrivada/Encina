## Summary

Implement automatic rate limiting that detects service outages and automatically throttles message processing.

## Motivation

- **Phase**: 2 - Functionality
- **Priority**: High
- **Complexity**: Medium

When downstream services experience outages, continuing to send messages at full rate wastes resources and can worsen the problem. Automatic rate limiting detects failure patterns, throttles processing, and gradually ramps back up on recovery.

## Proposed Solution

### Features

- Automatic outage detection
- Dynamic rate adjustment
- Circuit breaker integration
- Metrics and alerting
- Recovery detection and ramp-up

### Proposed API

```csharp
services.AddEncinaRateLimiting(config =>
{
    config.MaxConcurrentMessages = 10;
    config.ErrorThreshold = 0.5; // 50% error rate triggers throttling
    config.CooldownPeriod = TimeSpan.FromMinutes(1);
    config.RampUpFactor = 2; // Double capacity on recovery
});
```
