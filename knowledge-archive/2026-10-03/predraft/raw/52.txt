## Summary

Implement snapshotting support for large event-sourced aggregates to improve load performance.

## Motivation

- **Phase**: 2 - Functionality
- **Priority**: Medium
- **Complexity**: Medium

When event-sourced aggregates accumulate a large number of events, replaying all events from the beginning becomes increasingly expensive. Snapshotting captures the aggregate state at a point in time, allowing faster loading by replaying only events after the last snapshot.

## Proposed Solution

- Automatic snapshot creation at configurable intervals
- Configurable snapshot frequency and retention
- Snapshot + events replay (load from snapshot, then apply remaining events)
- Snapshot storage strategies

```csharp
services.AddEncinaMarten(config =>
{
    config.UseSnapshotting<Order>(options =>
    {
        options.SnapshotEvery = 100; // Snapshot every 100 events
        options.KeepSnapshots = 5;   // Keep last 5 snapshots
    });
});

// Aggregate with snapshot support
public class Order : AggregateBase<OrderId>, ISnapshotable<OrderSnapshot>
{
    public OrderSnapshot CreateSnapshot() => new(Id, Status, Items, Total);

    public void RestoreFromSnapshot(OrderSnapshot snapshot)
    {
        Id = snapshot.Id;
        Status = snapshot.Status;
        Items = snapshot.Items;
        Total = snapshot.Total;
    }
}
```

Implemented snapshotting for large aggregates with:

## Implementation
- `ISnapshotable<TAggregate>` marker interface
- `ISnapshot<TAggregate>` / `Snapshot<TAggregate>` for snapshot data
- `SnapshotOptions` with global and per-aggregate configuration
- `ISnapshotStore<TAggregate>` with `MartenSnapshotStore<TAggregate>` implementation
- `SnapshotAwareAggregateRepository<TAggregate>` for optimized loading
- `SnapshotEnvelope<TAggregate>` for Marten document storage
- `SnapshotErrorCodes` for standardized error handling
- High-performance logging with `LoggerMessage` source generators

## Configuration
```csharp
services.AddEncinaMarten(options =>
{
    options.Snapshots.Enabled = true;
    options.Snapshots.SnapshotEvery = 100;
    options.Snapshots.KeepSnapshots = 3;
    options.Snapshots.ConfigureAggregate<Order>(snapshotEvery: 50, keepSnapshots: 5);
});
services.AddSnapshotableAggregate<Order>();
```
