## Summary

Create Azure Functions integration for running Encina handlers in a serverless environment.

## Motivation

- **Phase**: 2 - Functionality
- **Priority**: Medium
- **Complexity**: Medium

Azure Functions is a widely adopted serverless platform. Integrating Encina with Azure Functions triggers (HTTP, Queue, Timer) allows developers to use familiar Encina command/query patterns in serverless workloads, with cold-start-optimized DI registration and result-to-ActionResult mapping.

## Proposed Solution

- Azure Functions trigger integration
- HTTP trigger for commands/queries
- Queue trigger for messages
- Timer trigger for scheduled handlers

```csharp
public class OrderFunctions
{
    private readonly IEncina _encina;

    public OrderFunctions(IEncina encina) => _encina = encina;

    [Function("CreateOrder")]
    public async Task<IActionResult> CreateOrder(
        [HttpTrigger(AuthorizationLevel.Function, "post")] CreateOrder command)
    {
        var result = await _encina.Send(command);
        return result.ToActionResult();
    }

    [Function("ProcessPayment")]
    public async Task ProcessPayment(
        [QueueTrigger("payments")] ProcessPayment command)
    {
        await _encina.Send(command);
    }
}

// Startup
services.AddEncina(typeof(Program).Assembly);
services.AddEncinaAzureFunctions();
```
