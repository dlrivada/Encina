## Summary

Create AWS Lambda integration for running Encina handlers in a serverless environment.

## Motivation

- **Phase**: 2 - Functionality
- **Priority**: Medium
- **Complexity**: Medium

AWS Lambda is a major serverless platform. Integrating Encina with AWS Lambda triggers (API Gateway, SQS, EventBridge) allows developers to use Encina command/query patterns in AWS serverless workloads, with cold-start-optimized DI registration and result-to-response mapping for API Gateway.

## Proposed Solution

- Lambda handler integration
- API Gateway integration with response mapping
- SQS trigger support (batch processing)
- EventBridge trigger support

```csharp
public class OrderFunctions
{
    private readonly IEncina _encina;

    public OrderFunctions(IEncina encina) => _encina = encina;

    [LambdaSerializer(typeof(DefaultLambdaJsonSerializer))]
    public async Task<APIGatewayProxyResponse> CreateOrder(
        APIGatewayProxyRequest request, ILambdaContext context)
    {
        var command = JsonSerializer.Deserialize<CreateOrder>(request.Body);
        var result = await _encina.Send(command);
        return result.ToApiGatewayResponse();
    }

    public async Task ProcessPayment(SQSEvent sqsEvent, ILambdaContext context)
    {
        foreach (var record in sqsEvent.Records)
        {
            var command = JsonSerializer.Deserialize<ProcessPayment>(record.Body);
            await _encina.Send(command);
        }
    }
}
```
