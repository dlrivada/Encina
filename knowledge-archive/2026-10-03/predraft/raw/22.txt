## Summary

Implement event versioning support for schema evolution in event-sourced systems.

## Motivation

## Proposed Solution

- Event upcasting (transform old events to new format)
- Schema versioning in event metadata
- Integration with Marten event versioning
- Migration tools for event stream evolution
