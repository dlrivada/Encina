## Summary

Integrate **Respawn library** into `Encina.Testing` for intelligent database cleanup between integration tests, providing fast and reliable database reset.

## Motivation

- **Fast reset**: Respawn is 3x faster than truncate/FK disable approach
- **Intelligent deletion**: Analyzes foreign key relationships for correct deletion order
- **Schema preservation**: Only deletes data, doesn't recreate schema
- **Multi-database support**: SQL Server, PostgreSQL, MySQL, Oracle

## Proposed Solution

### EncinaRespawner Factory

```csharp
public static class EncinaRespawner
{
    public static async Task<Respawner> CreateAsync(DbConnection connection)
    {
        return await Respawner.CreateAsync(connection, new RespawnerOptions
        {
            TablesToIgnore = new Table[]
            {
                "__EFMigrationsHistory",
                "SchemaVersions"
            },
            SchemasToExclude = new[]
            {
                "sys",
                "information_schema",
                "pg_catalog"
            }
        });
    }

    public static async Task<Respawner> CreateForEncinaMessagingAsync(
        DbConnection connection,
        bool preserveOutbox = false,
        bool preserveInbox = false)
    {
        var tablesToIgnore = new List<Table>();
        if (preserveOutbox) tablesToIgnore.Add("OutboxMessages");
        if (preserveInbox) tablesToIgnore.Add("InboxMessages");

        return await Respawner.CreateAsync(connection, new RespawnerOptions
        {
            TablesToIgnore = tablesToIgnore.ToArray()
        });
    }
}
```

### DatabaseIntegrationTestBase

```csharp
public abstract class DatabaseIntegrationTestBase : IAsyncLifetime
{
    protected Respawner Respawner { get; private set; }
    protected abstract DbConnection Connection { get; }

    public virtual async Task InitializeAsync()
    {
        Respawner = await EncinaRespawner.CreateAsync(Connection);
    }

    public virtual async Task DisposeAsync()
    {
        await Respawner.ResetAsync(Connection);
    }
}
```

### Usage Example

```csharp
public class OrderSagaIntegrationTests : DatabaseIntegrationTestBase
{
    private readonly SqlServerContainerFixture _container;
    protected override DbConnection Connection => _container.Connection;

    [Fact]
    public async Task CompleteSaga_ShouldPersistAllSteps()
    {
        // Test runs with clean database
        // Respawner resets after each test
    }
}
```

## Alternatives Considered

1. **Truncate with FK disable**: Disabling foreign keys and truncating. Slower, requires FK re-enable, can cause constraint issues.

2. **Database recreate per test**: Dropping and recreating database. Very slow, especially with migrations.

3. **Transaction rollback**: Wrapping tests in transactions. Doesn't work for all scenarios, can hide bugs.
