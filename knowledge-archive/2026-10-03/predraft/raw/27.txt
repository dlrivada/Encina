## Summary

Implement source generators for compile-time handler registration and NativeAOT support.

## Motivation

Current implementation uses reflection for handler discovery. Source generators would:
- Enable NativeAOT compilation
- Improve startup time
- Reduce memory allocation

## Proposed Solution

- `[EncinaHandler]` attribute for source generation
- Switch-based dispatch (no dictionary lookup)
- Compile-time handler registration
- Full NativeAOT compatibility
