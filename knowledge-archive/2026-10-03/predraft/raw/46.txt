## Summary

Create a test base class for testing event-sourced aggregates using Given/When/Then pattern.

## Motivation

- **Phase**: 2 - Functionality
- **Priority**: High
- **Complexity**: Medium

Testing event-sourced aggregates requires setting up event history, executing commands, and verifying produced events and state. A `Given/When/Then` base class standardizes this pattern and reduces test boilerplate.

## Proposed Solution

### Features

- Given/When/Then test structure
- Event history setup
- Command execution
- Event verification
- State verification

### Proposed API

```csharp
public class OrderAggregateTests : AggregateTestBase<Order, OrderId>
{
    [Fact]
    public void SubmitOrder_WhenCreated_ShouldProduceOrderSubmittedEvent()
    {
        Given(
            new OrderCreated(OrderId, CustomerId, Items),
            new PaymentReceived(OrderId, Amount)
        );

        When(order => order.Submit());

        Then<OrderSubmitted>(e =>
        {
            e.OrderId.Should().Be(OrderId);
            e.SubmittedAt.Should().BeCloseTo(DateTime.UtcNow, TimeSpan.FromSeconds(1));
        });

        ThenState(order =>
        {
            order.Status.Should().Be(OrderStatus.Submitted);
        });
    }

    [Fact]
    public void Cancel_WhenAlreadyShipped_ShouldFail()
    {
        Given(
            new OrderCreated(OrderId, CustomerId, Items),
            new OrderShipped(OrderId)
        );

        When(order => order.Cancel());

        ThenError<InvalidOperationException>(e =>
            e.Message.Should().Contain("Cannot cancel shipped order"));
    }
}
```
