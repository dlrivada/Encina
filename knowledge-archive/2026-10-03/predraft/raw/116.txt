## Description

The file `tests/Encina.EntityFrameworkCore.PropertyTests/Generators.cs` has broken references to messaging types that no longer exist in the current namespace.

## Location

- **File(s)**: `tests/Encina.EntityFrameworkCore.PropertyTests/Generators.cs`

The file fails to compile with the following errors:


## Expected Behavior

`Generators.cs` should compile successfully with correct references to the current type locations, or obsolete generators should be removed if the types no longer exist.

## Root Cause

The types `OutboxMessage`, `InboxMessage`, `SagaState`, `ScheduledMessage`, and `SagaStatus` were moved or removed from the `Encina.Messaging` namespace, but `Generators.cs` still references them.

## Proposed Fix

1. Investigate where these types currently reside (if they still exist)
2. Update the `using` statements accordingly
3. If the types were removed, delete the corresponding generators

### 1. Tipos en namespace incorrecto
Los tipos `OutboxMessage`, `InboxMessage`, `SagaState`, `ScheduledMessage` y `SagaStatus` estaban siendo importados desde `Encina.Messaging.*` pero ahora residen en `Encina.EntityFrameworkCore.*`.
