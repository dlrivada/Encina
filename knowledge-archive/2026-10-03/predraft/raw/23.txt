## Summary

Create a testing package with fluent assertions and test fixtures for Encina-based applications.

## Motivation

Make it easier to test handlers, pipelines, and ROP code. High priority - improves developer experience significantly.

## Proposed Solution

- `EncinaFixture` fluent API for test setup
- ROP assertion extensions: `ShouldBeSuccess()`, `ShouldBeError()`
- `AggregateTestBase` for Given/When/Then event sourcing tests
- Mock helpers for common Encina interfaces

### Example Usage

```csharp
result.ShouldBeSuccess()
      .And.Value.Should().Be(expected);

result.ShouldBeError()
      .And.ErrorCode.Should().Be("VALIDATION_FAILED");
```
