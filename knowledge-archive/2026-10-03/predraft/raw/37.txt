## Summary

Implement event versioning with upcasting and schema evolution support for event sourcing providers.

## Motivation

- **Phase**: 2 - Functionality
- **Priority**: High
- **Complexity**: High

Event-sourced systems accumulate events over time and event schemas inevitably evolve. Without proper versioning and upcasting, older events become incompatible with newer code, making event store maintenance difficult.

## Proposed Solution

### Features

- Event upcasting (v1 -> v2 -> v3)
- Schema evolution strategies
- Version metadata on events
- Migration tooling

### Implementation Tasks

- [ ] Design event versioning abstractions
- [ ] Implement `IEventUpcaster<TFrom, TTo>` interface
- [ ] Add version metadata to events
- [ ] Create upcasting pipeline
- [ ] Integrate with Marten's existing versioning
- [ ] Add migration tooling
- [ ] Add documentation
- [ ] Add unit tests
