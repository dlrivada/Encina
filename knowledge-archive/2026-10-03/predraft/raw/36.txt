## Summary

Create abstractions for CQRS read side (projections/read models) that work with all event sourcing providers.

## Motivation

- **Phase**: 2 - Functionality
- **Priority**: High
- **Complexity**: High

Event sourcing applications need a well-defined read side to project events into queryable read models. Without standardized projection abstractions, each application reinvents this pattern, leading to inconsistency and boilerplate.

## Proposed Solution

### Features

- Projection base classes
- Read model repositories
- Projection rebuild capabilities
- Multi-provider support (Marten, EventStoreDB)

### Implementation Tasks

- [ ] Design projection abstractions
- [ ] Create `IProjection<TEvent, TReadModel>` interface
- [ ] Implement `IReadModelRepository<T>`
- [ ] Add projection rebuild functionality
- [ ] Integrate with Encina.Marten
- [ ] Add documentation
- [ ] Add unit tests
