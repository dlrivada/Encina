## Summary

Implement abstractions for CQRS read side (projections/read models).

## Motivation

This is a core feature for Event-Driven Architecture that enables:
- Materialized views from event streams
- Optimized read models for queries
- Event replay for projection rebuilding

High priority - enables full CQRS implementation.

## Proposed Solution

- Create `IProjection<TEvent>` interface
- Create `IProjectionStore` abstraction
- Integration with Marten projections
- Support for inline and async projections
