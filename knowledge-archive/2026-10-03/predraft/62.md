## Decisions
- Implement the Routing Slip pattern for dynamic message routing in `Encina.Messaging` (Source: Issue body)
- Use `RoutingSlipBuilder` for dynamic route definition (Source: Issue body)
- Implement step execution with compensation logic (Source: Issue body)
- Allow route modification mid-flight (add/remove steps dynamically) (Source: Issue body)
- Implement completion tracking and notification (Source: Issue body)
- Add `RoutingSlipBuilder` fluent API for inline step definition (Source: Comment by dlrivada)
- Implement dynamic route modification via `RoutingSlipContext` with methods `AddStep()`, `AddStepNext()`, `InsertStep()`, `RemoveStepAt()`, `ClearRemainingSteps()` (Source: Comment by dlrivada)
- Implement automatic compensation in reverse order on failure (Source: Comment by dlrivada)
- Make the pattern configurable via `RoutingSlipOptions` (Source: Comment by dlrivada)
- Use ROP error handling with `Either<EncinaError, TData>` (Source: Comment by dlrivada)
- Use high-performance logging with `LoggerMessage` (EventIds 400-415) (Source: Comment by dlrivada)
- Distinguish Routing Slip from Saga Pattern: Routing Slip allows dynamic route modification during execution, whereas Saga defines routes at build time (Source: Comment by dlrivada)
- Implement 137 tests covering unit, property, and guard scenarios (Source: Comment by dlrivada)
- No integration or load tests required as execution is in-memory only (Source: Comment by dlrivada)

## Rules and lessons
- Routing Slip steps must implement `Compensate` to support rollback on failure (Source: Issue body code example)
- Routing Slip routes are dynamic and can be modified at runtime via `RoutingSlipContext` (Source: Comment by dlrivada)
- Compensation must run in reverse order of executed steps on failure (Source: Comment by dlrivada)
- Public API must include guard tests for null checks (Source: Issue body test matrix)
- Contract tests are required for `IRoutingSlipStep` public API (Source: Issue body test matrix)
- Target 85%+ test coverage (Source: Issue body acceptance criteria)
