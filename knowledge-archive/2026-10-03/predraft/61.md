## Decisions
- Implement Azure Durable Functions integration for orchestration workflows with Encina handlers. (Source: Issue body)
- Use `OrchestrationContextExtensions` to call activities with Either results. (Source: Comment by dlrivada)
- Use `ActivityResult<T>` as a serializable wrapper for Durable Functions JSON serialization. (Source: Comment by dlrivada)
- Implement `DurableSagaBuilder` fluent API with automatic compensation. (Source: Comment by dlrivada)
- Implement Fan-out/fan-in extensions for parallel execution. (Source: Comment by dlrivada)
- Add `DurableFunctionsHealthCheck` and configuration options. (Source: Comment by dlrivada)
- Implement ROP (Result of Operations) support. (Source: Comment by dlrivada)

## Rules and lessons
- Durable Functions require JSON serialization for state, necessitating specific serializable wrappers like `ActivityResult<T>` for Encina's functional types. (Source: Comment by dlrivada)
- Saga patterns require automatic compensation mechanisms within the orchestration context. (Source: Comment by dlrivada)

## Candidate destinations
- docs: Integration guide for Azure Durable Functions with Encina (OrchestrationContextExtensions, Saga, Fan-out/in).
- spec-invariant: Activity functions must return serializable results compatible with Durable Functions JSON constraints.
