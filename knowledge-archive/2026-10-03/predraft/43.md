## Decisions
- Implement `IHandleSagaNotFound<TMessage>` interface and `SagaNotFoundContext` to handle saga correlation failures (source: issue body).
- Provide a `SagaNotFoundContext` with methods `Ignore()` and `MoveToDeadLetterAsync` (source: comment by dlrivada).
- Introduce `SagaNotFoundAction` enum with values `None`, `Ignored`, `MovedToDeadLetter` (source: comment by dlrivada).
- Create `ISagaNotFoundDispatcher` for internal invocation of handlers (source: comment by dlrivada).
- Define error codes `SagaErrorCodes.HandlerCancelled` and `SagaErrorCodes.HandlerFailed` (source: comment by dlrivada).
- Automatically register `ISagaNotFoundDispatcher` in DI when `UseSagas = true` (source: comment by dlrivada).
- Method signature in implementation is `HandleAsync` with `CancellationToken`, differing from the proposed `Handle` in the issue (source: issue body vs comment by dlrivada).
- 19 unit tests were added covering `SagaNotFoundContext` and `SagaNotFoundDispatcher` (source: comment by dlrivada).

## Rejected alternatives
- The issue body listed `StartNewSaga` as a proposed option, but the implementation comment lists only `Ignore()` and `MoveToDeadLetterAsync()` as available actions in `SagaNotFoundContext`. The `StartNewSaga` feature is not mentioned in the implementation details or the `SagaNotFoundAction` enum, implying it was not implemented in this change (source: issue body vs comment by dlrivada).

## Rules and lessons
- Internal dispatchers for saga infrastructure components should be automatically registered when the main saga feature flag (`UseSagas`) is enabled (source: comment by dlrivada).
- Error handling for saga not found scenarios requires distinct error codes for cancellation and failure (source: comment by dlrivada).

## Candidate destinations
- docs: Document the new `IHandleSagaNotFound` interface and `SagaNotFoundContext` usage (source: issue body "Add documentation").
- regression-test: Ensure the 19 unit tests for `SagaNotFoundContext` and `SagaNotFoundDispatcher` are included in the test suite (source: comment by dlrivada).
