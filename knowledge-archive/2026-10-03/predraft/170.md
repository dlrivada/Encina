## Decisions
- Extend `EitherAssertions` in `Encina.Testing` with expressive assertions, specifically adding `AndConstraint`, Collection, and Streaming assertions (Source: Issue body; Comment by dlrivada).
- Use Shouldly as a free alternative to FluentAssertions for fluent, readable tests due to MIT licensing and expressiveness (Source: Issue body).
- Implement support for streaming assertions for `IAsyncEnumerable` results (Source: Issue body; Comment by dlrivada).
- The feature is part of the v0.11.0 Testing Infrastructure milestone (Source: Comment by dlrivada).

## Rejected alternatives
- FluentAssertions: Rejected due to licensing costs in v8+ and preference for MIT-licensed Shouldly (Source: Issue body).
- xUnit Assert only: Rejected due to lower readability, higher verbosity, and lack of chaining support (Source: Issue body).
- Custom assertion library: Rejected as unnecessary effort when Shouldly exists and is well-maintained (Source: Issue body).

## Rules and lessons
- Prefer MIT-licensed assertion libraries (like Shouldly) over proprietary ones (like FluentAssertions 8+) when expressiveness is comparable (Source: Issue body).
- Implement fluent/chaining assertions to improve test readability and reduce verbosity (Source: Issue body).

- spec-invariant: The acceptance criteria require unit tests with >=90% coverage and XML documentation on all public APIs, which can be used to validate future changes to `Encina.Testing` (Source: Issue body).
