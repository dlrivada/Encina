## Decisions
- Create a new package for test data generation using Bogus and AutoBogus (source: issue body)
- Implement base `EncinaFaker<T>` class inheriting from `AutoFaker<T>` with specific rules for `CorrelationId` and `CreatedAtUtc` (source: issue body)
- Implement specific fakers for messaging entities: `OutboxMessageFaker`, `InboxMessageFaker`, `SagaStateFaker`, `ScheduledMessageFaker` (source: issue body)
- Implement `RequestFaker<TRequest>` for IRequest types (source: issue body)
- Support seed-based reproducibility (source: issue body)
- The first foundational package for the v0.11.0 Testing Infrastructure milestone is being analyzed (source: comment by dlrivada)

## Rejected alternatives
- AutoFixture only: Less realistic data, harder to customize specific fields (source: issue body)
- Manual builders only: More boilerplate, less realistic data (source: issue body)
- Static test data: Inflexible, hard to generate variations (source: issue body)

## Rules and lessons
- Test data generation should support seed-based reproducibility for deterministic tests (source: issue body)
- Encina-specific conventions (CorrelationId, CreatedAtUtc) should be auto-configured in the base faker (source: issue body)
- Acceptance criteria require >90% coverage and XML documentation on all public APIs (source: issue body)
