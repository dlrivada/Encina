## Decisions
- Create a test base class for testing event-sourced aggregates using the Given/When/Then pattern to standardize boilerplate (source: issue body)
- Implement `AggregateTestBase<TAggregate, TId>` with `Given`, `GivenEmpty`, `When`, `WhenAsync`, `Then<TEvent>`, `ThenEvents`, `ThenNoEvents`, `ThenState`, `ThenThrows`, and `GetUncommittedEvents` methods (source: comment by dlrivada)
- Use `ThenThrows` for exception assertions instead of the initially proposed `ThenError<T>` (source: comment by dlrivada)
- Add 75 total tests including 30 unit, 12 property (FsCheck), 15 contract, and 18 guard clause tests (source: comment by dlrivada)

## Rejected alternatives
- none

## Rules and lessons
- The `ThenError` method proposed in the issue was renamed to `ThenThrows` in the implementation (source: issue body vs comment by dlrivada)
- Event sourcing test bases should support both synchronous and asynchronous command execution (`When`/`WhenAsync`) (source: comment by dlrivada)
- Guard clause tests are required for test infrastructure components (source: comment by dlrivada)
