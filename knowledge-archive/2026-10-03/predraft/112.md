## Decisions
- Migrate existing tests to use fluent ROP assertion extensions from `Encina.TestInfrastructure` to apply a design pattern and simplify complex code. (Source: issue body)
- No behavioral changes are expected; only assertion style changes are made. (Source: issue body)
- Migration targets specific test projects including `Encina.Caching.Tests`, `Encina.AspNetCore.Tests`, and `Encina.Dapper.Sqlite.PropertyTests`. (Source: issue body)
- The migration is considered low risk as it involves assertion-only changes with no production code modification. (Source: issue body)

## Rejected alternatives
- None

## Rules and lessons
- Test refactoring for assertion style changes should maintain strict behavioral guarantees by relying on existing tests as the safety net. (Source: issue body)
- Consistent assertion style across tests improves readability and error messages. (Source: issue body)

## Candidate destinations

- reviewer-checklist: Verify that ROP assertions use the fluent extensions rather than verbose `IsRight`/`IsLeft` patterns.
