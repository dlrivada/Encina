## Summary

Oracle and SQLite ADO.NET SQL scripts had been copy-pasted from the SQL Server dialect (wrong parameter markers, `TOP` instead of `LIMIT`/`ROWNUM`, etc.). Fixed by a direct commit with no PR trail. Both providers were later dropped from Encina's supported matrix entirely (ADR-009 for Oracle, ADR-024 for SQLite), so the fix is now historical: the code it touched has since been deleted or moved to `.backup/`.
