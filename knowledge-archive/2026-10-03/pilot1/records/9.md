## Summary

Two Dapper.Sqlite contract tests failed because the `IScheduledMessage` contract test built a message with a future timestamp where the contract expected a past one; one further test was permanently skipped for a SQLite-specific datetime-format incompatibility, with the justification left only in the closing comment rather than a `.md` file (the justification-document convention didn't exist yet). SQLite has since been dropped from the supported provider matrix (ADR-024), so this record is now purely historical.
