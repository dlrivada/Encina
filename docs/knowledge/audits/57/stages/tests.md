## Lessons for the pipeline
- A manifest entry whose guard flag is assigned while the guard project has no class for the file produces 0%; the stage should compare the guard assignment with the guard folder listing before measuring, and the null-check tests in the unit project (`ModuleRegistryTests.cs:38`) should not be read as guard coverage.
- A "called only by X and Y" claim needs a case-insensitive Select-String over all of `tests\` with the hit lines listed; the first version counted a file that only has `AddEncinaModuleHealthChecks` tests. Cite a test by its method declaration line (`:127`, not the `[Fact]` line `:126`).
- A record destination marked `regression-test done` must be checked for what the target asserts; a discovery contract with no behavioural test belongs in the registration-test finding.
- Feature-name filter `Core.Modules` also selects the `Isolation` namespace (260 tests); say so next to the figure.
