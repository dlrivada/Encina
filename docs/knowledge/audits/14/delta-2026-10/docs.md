## Lessons for the pipeline

- A "combine two packages" defect found in one sibling README (here DataAnnotations, #10) should be searched for in the other siblings by the phrase ("Mix and Match", "work together"); the MiniValidator copy was outside the earlier finding's scope.
- When a sample parses a formatted message (`error.Message.Split(...)`), read the method that builds the message (`ToErrorMessage`) and run the parse by hand on its output; symbol-existence checks pass it.
- Search for a registration name in a comparison table (`AddFluentValidation`) across `src/`, not only in the README's own section: tables repeat identifiers no sample uses.
