## Lessons for the pipeline
- A scoped file with a high unit figure can hide a whole missing behaviour: `EventPublishingPipelineBehavior.cs` is 93.75% unit while the single success path of its purpose (publish every pending event) is run by no test; read the missed-line list of each tracked file against the test method list before confirming that an open issue's "no new test is needed" holds.
- When the umbrella issues already hold a file's numbers, a per-file tracker table (file, issue, what it holds, confirmed or not) answers the duplicate question in one place and keeps the findings list to the genuinely untracked files; the delta brief can ask for that table in this shape.
- Docker was not running for this delta, so the integration flag could be neither measured nor assumed; the brief for a rule (b) delta of a Marten package should say whether Docker is expected to be up, since the package-level integration key and three of the per-file integration targets depend on that measurement.
