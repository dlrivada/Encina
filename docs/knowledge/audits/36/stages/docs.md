## Findings

1. **Major** — There is no projections-specific concept content or rebuild how-to for projections and read models. Evidence: `src/Encina.Marten/` contains no `.md` file; `docs/features/` has no projections page; `docs/tutorials/` is `index.md` and `quickstart.md` only; `docs/index.md:69` ("Event Sourcing ... Marten event store with projections, snapshots, GDPR crypto-shredding") links nothing. The only teaching text is a release-history section (`docs/releases/pre-v0.10.0/README.md:1429-1560`) and an ADR sample (`docs/architecture/adr/019-compliance-event-sourcing-marten.md:199-220`); six compliance READMEs use `IReadModelRepository<T>` without saying where it comes from. Fails rule (a) point 5 and point 1 (no diagram of the event to handler to read model flow, no table of the interfaces). Overlap with open #1894 (verified `gh issue view 1894`, OPEN): its item "No concept or how-to page, package README or tutorial entry for event sourcing on Encina.Marten" already holds, in its Proposed Fix, a feature page for "aggregates, `IAggregateRepository`, snapshots, projections", a how-to under `docs/guides/` for registering `Encina.Marten`, links from `docs/tutorials/index.md`, `docs/features/index.md` and `docs/index.md:69`, and `src/Encina.Marten/README.md`. Those parts (package README, tutorial entry, index link, general feature page) are held by #1894 and are not repeated here. This finding is narrowed to what #1894 does not hold: (a) projections-specific concept content with a Mermaid flow (event, `ProjectionRegistry`, inline dispatcher or rebuild, `IReadModelRepository<T>`) and a table of the read-side interfaces; (b) a how-to for rebuilding a projection. The rebuild how-to must wait for #1906 (rebuild is broken today, code finding 1) or say so.

## Lessons for the pipeline

- When an issue shipped no page and its only text is release history, still diff every option and property table in it against the options class: all five names in the `ProjectionOptions` table were invented and one real default was inverted, which a type-name search passes.
- A tutorial/learning-path check needs the directory listing (`docs/tutorials/` has two files) before saying the feature is missing; the listing is one command and makes the finding checkable.
- Read an open umbrella issue's item list for the package (#1894 for `Encina.Marten`) before writing a "no page" finding, and state that the finding extends that item with the feature name.
