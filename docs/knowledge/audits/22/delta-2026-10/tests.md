## Lessons for the pipeline

- A throwaway console app that references `src/` through `#:project` is blocked for the test stage by `guard-orchestrator-writes` even when the file lives under the session scratchpad; an end-to-end hypothesis (finding 9: lambda versus class upcaster type names) can therefore only be settled by an `issue-worker` test.
