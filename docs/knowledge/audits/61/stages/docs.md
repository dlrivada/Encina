## Lessons for the pipeline

- A configuration block whose options compile and exist can still be dead: search `src/` for the readers of each option property, not for the property names, and expect the health check to be the only reader (it copies options into health data and range-checks them).
- A saga builder that takes activity names as strings hides a typing contract (`TData` in, `ActivityResult<TData>` out); read the call that executes the name, not the builder signature, before judging a sample.
- Two helper families in one static class (`CallEncinaActivityAsync` and `CallEncinaActivityWithResultAsync`, `FanOutAsync` and `FanOutWithResultAsync`) differ only by wire shape; check that each README sample pairs the helper with the activity shape the same page teaches.
