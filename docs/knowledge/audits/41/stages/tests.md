## Lessons for the pipeline
- A consolidation commit (`65826302`) that deletes a per-flag test project removes the contract and property tests of a delivered feature without trace; the test stage should run `git log --diff-filter=D -- <path>` for each test file named in the closing comment and then search the consolidated projects for the symbols (the archivist already lists the paths, so the check is two calls).
- An open delta umbrella (#1886) written before a feature's last fix can carry numbers that no longer hold: the umbrella proposed guard 14 for a file that grew from 97 to 119 lines, and said the manifest had no targets for a file whose targets #2185 had added. Compare an umbrella's coverable-line counts with the new measurement before confirming its numbers.
- A guard figure for a type that has no guard class of its own (here `SagaDefinition.cs`, `SagaStepBuilder.cs`) is incidental: running the one guard class that touches the type alone and getting the same figures is the one-call proof, and it shows which argument checks have no guard test even when the figure looks acceptable.
