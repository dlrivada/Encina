## Lessons for the pipeline

- For a closed-in-error issue whose only related page is an ADR that rejects the feature, run the rule (a) visual and figure checks on the ADR (emoji range count, Mermaid count, hand-typed performance literals) and map the decision conflict to the open issue that already covers it, instead of writing "no page, no finding".
- Before writing "open #N" for a backlog issue, check its state with `gh issue view`; #50 and #51 were closed as not planned, and the conflict that remained was inside the ADR. Scope a "only X does Y" claim about `src/` to the directory actually searched, and name every document that repeats the claim (ADR-003 repeats ADR-005's expression-tree claim).
- When a finding says a second document "repeats the claim", open each cited line and keep only those that make the same claim in the same scope; ADR-003 mixes a request-path claim (`:41`, `:46`, `:370-372`) with a notification-invoker section (`:69`, `:82`, `:98`, `:291`) where the claim is true (audit #27 verifier pass 3 correction 1).
