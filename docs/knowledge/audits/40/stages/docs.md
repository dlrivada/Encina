## Lessons for the pipeline

- When an issue shipped no page and the package README is 12 lines, the README itself is the main rule (a) target: count its lines, fenced blocks and Mermaid blocks, then check the package's umbrella documentation issue (#904 here) for the feature name in its outline before writing a "no page" finding.
- An empty `docref-table` marker pair is invisible to a symbol search; check which roots the renderer scans (`perf-docs-render.cs:72`, `docs.yml:192-194`) before treating a Performance section in a `src/` README as populated or as waiting for the index.
- An INVENTORY status word ("Completo") and a ROADMAP check mark are claims the code stage can falsify; read the code stage before accepting them.
