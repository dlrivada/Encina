## Lessons for the pipeline

- The `enforce-path-ownership` hook rejects `New-Item -ItemType Directory` on `artifacts\audit\logs`; only `artifacts\audit\coverage` and `artifacts\knowledge\stages` are writable for this stage, so run logs go to the session scratchpad instead.
- The delta brief should say how to treat a file that has package-level targets but no per-file `targets`/`justifications`: since #1762 landed (the manifest and `AGENTS.md` section 9 now have per-file `targets` and `justifications`), the prompt's wording "no per-file targets" (file without an entry or with empty `defaultTests`) no longer matches the policy; this stage reported the missing per-file fields as the finding and used the severity rule (Major when the effective target is unreachable by any test, Minor when only too low).
