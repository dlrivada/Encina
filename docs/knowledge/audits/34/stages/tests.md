## Lessons for the pipeline

- A "no test located by name" note from the archivist is answered by reading the failing-branch tests of the neighbours of the symbol: the empty-details regression tests exist but call the internal alias, so a name search for the public method reports none; search for the alias names too before writing that a regression test is missing.
