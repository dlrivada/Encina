## Lessons for the pipeline
- The `Null|Throws` filter on the guard project (191 tests, under a minute) separated 7 argument-check lines from 49 behaviour lines of `ServiceCollectionExtensions.cs` and exposed an argument check with no guard test (`AddEncinaMartenStoreOptionsBridge`, `:125`) that the whole-project 71.79% hides; run it for every registration file whose guard target is above its `ThrowIfNull` share.
- A fix PR (#2238) can write per-file targets into the manifest while the open umbrella (#2024) still says there are none and proposes a different value; compare each umbrella's number with the manifest entry and the file's current coverable-line count (71 became 78) before confirming it.
- A code-stage replica built on a stand-in base class can contradict the real base: `AggregateBase.Id` has `[JsonInclude]` (`AggregateBase.cs:72`), so the claim "empty Id" needs the real type; the test stage should read the real base class before writing which assertion discriminates, and the verifier's PostgreSQL round trip should name the real aggregate. The code stage finding 1 has since been restated (`Id` has `[JsonInclude]`; the derived `private set` state is the defect) and finding 1 here follows it.
- Read the live body of an open issue and quote its scenario list before writing what it "does not hold": #1976 scenarios 1, 2 and 6 already run through `AddEncinaMarten` plus `AddSnapshotableAggregate<T>` (scenario 6 is the `private set` round trip), so the first version's "loads state only through the store" was false (verifier correction 7).
- Before proposing a test type for a file, read the open issue's applicability judgment for it (#1975: property "not applicable" for `SnapshotOptions`, "optional" for `SnapshotEnvelope`) and state any override; and list a folder in the same call before writing what it "holds" (`tests\Encina.PropertyTests\Marten\` has six files).
- The coverage-report file matching for the contract flag needs `Encina.Marten\<file>` (no `src\` prefix and no leading backslash) for root-level files; the first run reported "0/0" for `EncinaMartenOptions.cs` and `ServiceCollectionExtensions.cs` until the pattern allowed an exact `Encina.Marten\` prefix.
- A hook-safe helper script has to be written with the Write tool in one call and run by literal absolute path in the next; creating it with `Set-Content` from a file read in the same command is blocked.
- A test oracle written as a count formula ("snapshots equal multiples crossed") needs the number of times the code path runs per call checked first: `TryCreateSnapshotAsync` runs once per `SaveAsync` (`:183`) and stores at most one snapshot, so the oracle is per save; verify it by tracing a small series (`SnapshotEvery = 3`, 2 events per save) before writing it (verifier correction 1, pass 2).
- State the base of an audit branch from `git reflog show audit/<n>` and the parent of the first audit commit, never from `git merge-base HEAD main` when the local `main` can be stale (here `main` was `cb7dacdef`, an ancestor of the real base `2307a5db9`).
