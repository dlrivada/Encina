# Audit — issue #3 ([DEBT] Implement LoggerMessage source generators (CA1848))

Checklist version: 1 (SPEC-003 §5.2). Date: 2026-09-25. Scope: the 21 packages issue #3's closing commits touched that still exist today (see `artifacts/knowledge/issues/3.md` front matter `audit.unit`). `Encina.Wolverine`, `Encina.NServiceBus`, `Encina.MassTransit`, `Encina.EventStoreDB` are `code-removed` (deprecated by commit `87d92a39`, `Closes #17`; moved to `.backup/deprecated-packages/`) and are not audited further. `Encina.ADO.Oracle`, `Encina.ADO.Sqlite`, `Encina.Dapper.Oracle`, `Encina.Dapper.Sqlite` are `code-removed` per ADR-009 and ADR-024.

Issue #3's own concern is structured logging (CA1848 → `[LoggerMessage]`), so this audit goes in depth on that concern across every surviving package, with a dedicated `adversarial-reviewer` pass (below) checking: `Log.cs` presence and use, EventIds inside registered ranges, no `EncinaError.Message`/`ex.Message` in log templates, no personal data in log templates, sensible log levels, consistent per-package logging categories, and logging tests. Checklist items unrelated to that concern (AUD-04/05 general test-type coverage, AUD-09–AUD-11 PublicAPI/docs/README, AUD-14 `TimeProvider` outside logging, AUD-16 async DB calls, AUD-17 DI registration completeness) belong to the packages' own histories, not to #3's change — they are marked **out of #3's scope** below rather than "not measured", since #3 never touched those concerns and later issues (own audits, when scheduled) own them.
