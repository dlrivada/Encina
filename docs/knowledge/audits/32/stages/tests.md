## Lessons for the pipeline
- For a badge or status scope the test stage has no coverage flag; the measurable work is a comparison of what each badge claims against its source (API, trigger block, last run) with a control input, and the stage definition could say so next to the "no src/ scope" wording of the #19 lesson.
- A `Select-String -Path "tests\**\*.cs"` does not recurse in PowerShell; use Grep (or `Get-ChildItem -Recurse`) for a "no test references X" claim.
- SonarCloud's `api/qualitygates/project_status` accepts `pullRequest=<n>` without a token for this public project, which turns "PR gates are not enforced" into a measurement.
