## Lessons for the pipeline

- A package whose manifest has 69 files with per-file `targets` and `justifications` but 7 entries (a whole feature folder) with `defaultTests` and `reason` only is a quick rule (b) pointer: list `files` entries that lack `targets` per folder before measuring; this audit and #62/#63 each found a feature folder skipped by the per-file migration.
- A parallel-execution test named "ExecutesRoutesInParallel" that asserts only a count cannot fail on order or on concurrency defects; when the code stage reports a nondeterminism finding, check that the one existing test uses delays and asserts order.
- The unit-missed list (`ContentRouter.cs:90-98`) pointed directly at the throw source the code stage derived but could not run (an invalid `MaxDegreeOfParallelism`): when a code finding is "derived, unrun" because a replica was blocked, the unit-missed lines of the owning catch block say whether any existing test can have exercised it.
