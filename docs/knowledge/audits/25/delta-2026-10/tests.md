## Lessons for the pipeline

- A feature-name filter and a namespace filter gave the same per-file figures here except for an options class that other tests construct incidentally (`SnapshotOptions.cs` guard 35 against 40); running both and proposing from the lower one is cheap and avoids a target that fails when the incidental tests move.
- A test named for a failure path (`SaveAsync_SnapshotCreationFails_DoesNotFailSave`) can pin a failure shape the real collaborator never produces (the store returns `Left`, it does not throw): when a unit test makes a substituted ROP store throw, check what the real store does with the same fault before accepting the test as proof; the discarded `Left` it hides (finding 11) would not show in any coverage number.
- A fix that touched a class (`6796fcb1`, projections after save) can leave its sibling class without a regression test: `git show --stat <fix>` lists the test files, and a Grep of the sibling's tests for the fix's new parameter (`projectionDispatcher`) answers it in one call.
- A manifest entry for a file that declares both an interface and a class (`ISnapshot.cs` declares `Snapshot<TAggregate>`) gets the interface-rule reason and `defaultTests: []` from its file name; the manifest generator should read the declarations, not the file name (also seen in #21 and #22).
- Before saying a constant's value is unasserted (or asserted by a given class), Grep `tests\` for the constant's name across all test classes (`MartenErrorCodesTests.cs:142-186` already pinned every `SnapshotErrorCodes` value), and before describing another issue's content ("no scenarios") read that issue's Test Plan (#1894 listed four of the six scenarios of finding 8); count a file's constants from its declarations (nine, not eight).
- Delta rule (b) for a package whose manifest has no per-file `targets` (Encina.Marten, fourth audit in a row: #17, #21, #22, #25) turns every file into a finding; the brief could say "one finding per file, proposals for every applicable flag" and name the open umbrella that already holds some of them (#1894 here) so the stage states which numbers it confirms.
