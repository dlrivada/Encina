## Lessons for the pipeline

- A commit message claiming a deprecated package was "moved to `.backup/`" should not be read as "the code still exists somewhere in the repo" — `.backup/` is gitignored (`.gitignore:16`) and absent from this checkout; verify with `Test-Path`/`git show --stat` rather than trusting the commit prose. The ADR itself (027) repeats this same inaccurate claim ("remains in the repository as deprecated code"), so an ADR is not automatically a reliable source for what is physically present in `src/` today — verify against the filesystem directly.
- A destination that was correct when the original decision landed (`.claude/CLAUDE.md`, `docs/history/2025-12.md`) can cease to exist entirely after later restructuring, without anyone porting its content forward; check whether the *current* equivalent file (here, `AGENTS.md`) still carries the decision, not just whether the file the original commit touched still exists.
- Two independent, still-current docs (`AGENTS.md:70`, `docs/INVENTORY.md:89`) both say "EventStoreDB (future)", while a third (`ROADMAP.md:803`) correctly says "Deprecated" — a decision reaching one destination doesn't mean it reached all of them; check every doc that mentions the same fact, not just the first one found.
