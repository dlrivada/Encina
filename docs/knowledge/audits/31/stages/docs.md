Load metrics within thresholds.`), the database file is referenced by no workflow, and the tests stage (R1) reproduces a 5 ops/sec result passing the caching file. ## Lessons for the pipeline
- For a CI-workflow issue that confirmed nothing, the docs stage finds its work in the pages that restate the workflow's triggers and matrices; compare each "schedule" or "matrix" table with the workflow's `on:` block and `options:` lists, because a scheduled run falls back to defaults and the tables read as if all providers ran.
- A page that says "threshold configuration files" asserts a gate; the docs stage should read the code and tests stages first and mark any threshold, schedule or enforcement claim they proved hollow.
- Search a mangled-token pattern (here `.github/ci/CD`) repo-wide when a heading looks odd: four hits in two files point to a bulk replacement, a cheap finding with an exact list.
