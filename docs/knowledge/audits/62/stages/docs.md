## Lessons for the pipeline

- For a feature whose record says "no dedicated documentation page", the docs stage's value is the placement and adequacy audit (point 5) plus the pages that over-claim the feature (here the inventory row), not a symbol-by-symbol check; run the feature-name search over `src/**/*.md` as well as `docs/`, because the only teaching text was in a sibling provider README.
- A repo-wide inventory page can contradict an ADR about the same abstraction (INVENTORY says the store is complete, ADR-050 says no implementation exists); compare the two before accepting either.
- A wide `Select-String` for a feature name returns release history, plans and knowledge records; classify and exclude them explicitly so the "pages reviewed" list is the teaching pages only.
