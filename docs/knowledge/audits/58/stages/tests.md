## Lessons for the pipeline
- A closing commit that names "N unit tests" and a later consolidation that deletes them leave a feature whose only remaining tests stub its collaborator; for every adapter-style class check which test runs it against the real collaborator, not only the line figure (here 21/21 with a substituted registry).
- (verifier correction 2) A guard target must be computed from the set of coverable lines after the proposed tests (lines already covered incidentally plus the new checks), and slack as covered minus ceil(target x coverable); a unit target must match the lines its own justification leaves unreachable.
- Three of the five scoped implementation files had package-level targets only; the delta/rule (b) brief for a closed feature that lost its test files to `658263027` can say up front "one finding per file with no per-file targets, proposals for every applicable flag".
