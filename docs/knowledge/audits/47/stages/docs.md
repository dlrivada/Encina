## Lessons for the pipeline

- For a tool package that shipped no README, check what the csproj packs as the tool's page (`Encina.Cli.csproj:20` packs the root README, which never mentions the tool): the package's NuGet page is then wrong by construction.
- A "done" mark in ROADMAP/INVENTORY for an issue the record marks `partial` is a docs finding of its own; compare the record's `outcome` with the status words of every destination page.
- A giant non-English inventory page needs its finding scoped to the section tied to the issue, with the file-wide size stated, so the drafted issue stays single-page.
