## Lessons for the pipeline
- For a CI-configuration issue, check not only that the test command has no exclusion filter but also under which change-detection condition the job runs: a job gated by a path filter that omits build props, test infrastructure and the workflow file is skipped, and a skipped job counts as success in an aggregate gate.
- When a finding states what a CI run executes or skips, derive it per changed-file class from the filter block AND the `needs`/`if` of every job (a skipped `build` also skips the jobs that need it) before writing it; the first draft said "build runs, every test skipped" for all classes and was wrong for two of them.
