## Lessons for the pipeline

- A package README for one provider often has a sibling in another database family that was fixed or reported for one family only (#1323 covers ADO.PostgreSQL, not ADO.MySQL); search each registration name across all six README siblings, not only the one already reported.
- Module-isolation and tenancy helper names in READMEs are easy to invent by analogy (`AddEncinaDapperSqlServerWithModuleIsolation`); search declarations (`IServiceCollection <name>`) for each, not the name inside comments (MongoDB's name appears only in XML docs).
- When an issue shipped no page and its record points the docs destination at an open issue, read that issue's Expected Behavior (#1336 delivers an ADR and an `AGENTS.md` bullet); the reader-facing page is still missing.
