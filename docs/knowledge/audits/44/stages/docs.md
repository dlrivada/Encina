## Lessons for the pipeline
- A bullet that names an issue's headline type inside a list about another feature (`Integración con EncinaFixture`) is easy to miss because the type is otherwise absent from the page; search the page for the headline type first (1 hit here) and read that one line against the class.
- A section heading that carries a count ("6 paquetes") should be compared with the table under it and with the section index on the same page (`docs/INVENTORY.md:91`) before the stage reports the section as accurate.
- A heading with two counts needs both compared: the first pass checked "6 paquetes" and skipped "22 mejoras" (13 table rows), and compared the package table's row count without comparing its members against the section's own "implemented" list (`Encina.Testing.Testcontainers` missing, audit #44 verifier correction 4).
- Cite a declaration line, not the line of its body: `WithFakeTimeProvider()` is declared at `EncinaTestFixture.cs:308`, and `:310` is its body (audit #44 verifier correction 4).
- For an issue whose package has an open README issue (#1689), check the sibling package named in the same issue (`Encina.Testing.Fakes`) for the same gap; the umbrella title covered only one of the two.
