## Lessons for the pipeline

- When the archivist says contract and property replacements were not located, the quick proof is `git show --stat --diff-filter=D <consolidation commit> | Select-String <Package>` plus a Grep of `tests\` for the deleted tests' subject types, and a check that the contract project references the package at all (a missing project reference makes the flag unmeasurable, "package absent from the report", not 0%).
- A test that sets a context key by hand (`UserIdKey`) and then asserts the reader returns it passes while no producer exists; when the code stage reports a key with a reader and no writer, list the tests that write the key themselves as masking tests.
- An open [TEST] issue for a coverage gap (#2787) can hold the generic builder tests and still miss the cases that guard the code stage's defects; the tests stage should compare its test list with the code findings and file the delta (finding 2) rather than mark the area duplicate.
- A guard target on a file with no `ThrowIfNull` (options POCO) is met incidentally and has slack 0; print `ceil(target x coverable)` next to every guard figure in the coverage table.
