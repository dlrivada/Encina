TESTING.md:111 says "Monitor the tightened 15%/25% benchmark guardrails and load throughput limits"; REQUIREMENTS.md:54 repeats "≤15% latency regression, ≤25% allocation regression" (`:27` states it again as `REQ-PERF-BASELINE`), and `docs/en/guides/PERFORMANCE_TESTING.md:38-41` states the same 15%/25% windows as baseline x1.15 / x1.25. Fix direction: cite the figures once (the script or the thresholds file) and link to that single citation from the other pages, or drop the figures.
