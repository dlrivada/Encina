## Asked

Make `HMACSigner.cs` build without CS0419 on SDK 11 (net11.0) and keep zero warnings on SDK 10, so the net11.0 migration does not have to carry the fix.

## Outcome

The `<see cref="CryptographicOperations.FixedTimeEquals"/>` in the type's XML documentation now names the `ReadOnlySpan<byte>` overload that `HMACSigner` calls. Documentation only; no code change and no suppression.

## Where the knowledge lives

- `src/Encina.Security.AntiTampering/HMAC/HMACSigner.cs` — the cref with the explicit overload signature.
