## Asked

Add a handler interface for messages whose saga cannot be correlated (completed, timed out or never started), with logging, optional requeue or dead letter, and a context offering several handling strategies.

## Outcome

Created 2025-12-24T13:25:42Z, closed 2025-12-25T09:13:31Z by the owner with a comment; no PR. Commit ea980e755 (authored 2025-12-25T23:50Z, after the close) added the interface, context, action enum, dispatcher, two error codes and unit tests. Partial: nothing in the saga pipeline calls the dispatcher, StartNewSaga, integration and contract tests were not delivered.

## Where the knowledge lives

The behaviour is documented in docs/features/dead-letter-queue.md and ADR-046 (decision 15). The missing saga-pipeline call is not tracked by any open issue yet (remediation draft 43-code-1); #1480, #1481 and #1886 are test trackers whose descriptions of the dispatcher are stale.
