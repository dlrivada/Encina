## Asked

Make `PIIHashKeyTests` build without SYSLIB0066 on SDK 11 / net11.0 and with zero warnings on SDK 10, without a .NET 11-only API.

## Outcome

The six `IStartupValidator.Validate()` calls were replaced by the host start path through one `BuildHost` helper: an invalid option set fails `StartAsync` with `OptionsValidationException`, and valid ones start, resolve `IPIIMasker` and stop.

## Where the knowledge lives

- `tests/Encina.UnitTests/Security/PII/PIIHashKeyTests.cs` — the host-start tests and the `BuildHost` helper comment naming why no validator type appears.
