## Asked

Register `EventPublishingPipelineBehavior<,>` in `AddEncinaMarten` so the domain events of event-sourced aggregates are published after a successful command, as the compliance aggregates and ADR-019 promise, with a DI test and a Marten/PostgreSQL integration test.

## Outcome

`AddEncinaMarten` now registers the behavior when `AutoPublishDomainEvents` is on. The behavior collects the events of every commit made during the command through a Marten session listener (the aggregate repository saves the session itself), publishes each once after the handler succeeds, fails the command when a publication returns `Left`, and logs only error codes.

## Where the knowledge lives

- `src/Encina.Marten/ServiceCollectionExtensions.cs` — the conditional open-generic registration.
- `src/Encina.Marten/EventPublishingPipelineBehavior.cs` — the committed-event collector and the publication semantics.
- `tests/Encina.UnitTests/Marten/EventPublishingRegistrationTests.cs` — the `ValidateOnBuild` and `ValidateScopes` pipeline test, option on and off.
- `tests/Encina.IntegrationTests/Infrastructure/Marten/Core/EventPublishingPipelineBehaviorIntegrationTests.cs` — events published exactly once against PostgreSQL.
