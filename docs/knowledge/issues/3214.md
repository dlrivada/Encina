## Asked

Stop the fan-out helpers from reading an `ActivityResult<T>` as the plain result type, which reported a failed activity as a success with a default value.

## Outcome

Delivered with #3216 and #3114 in one pull request: all fan-out methods unwrap `ActivityResult<T>`, `FanOutWithResultAsync` is removed, and a plain-value activity becomes `Left durable.activity_failed`.

## Where the knowledge lives

- `src/Encina.AzureFunctions/Durable/FanOutFanInExtensions.cs` and its README section state that fan-out activities return `ActivityResult<T>`.
- `tests/Encina.UnitTests/AzureFunctions/Durable/FanOutFanInExtensionsTests.cs` and `tests/Encina.IntegrationTests/Cloud/AzureFunctions/FanOutFanInOnTestHostIntegrationTests.cs` pin the behaviour.
