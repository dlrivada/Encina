## Asked

Make regenerating a coverage manifest safe: never lose package-level data the generator does not own (the `targets` block), and offer a mode that only adds missing file entries.

## Outcome

Delivered in `.github/scripts/generate-coverage-manifest.cs`: preservation of unowned keys at package and file level, `--append-only`, `--self-test`, and a writer aligned with the committed manifests. `docs/testing/coverage-measurement-methodology.md` describes the new behaviour.

## Where the knowledge lives

- `.github/scripts/generate-coverage-manifest.cs` — ownership rules, modes and self-test, described in its header comment.
- `docs/testing/coverage-measurement-methodology.md` — overrides section and the manifest-drift limitation.
