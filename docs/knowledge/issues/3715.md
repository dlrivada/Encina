## Asked

Stop presenting `HashChainOptions.StoragePath` as working persistence in the XML summary, the package README and the attestation feature page, because the hash chain is held in memory and nothing reads the property.

## Outcome

The XML summary, the README (sample and options table) and `docs/features/audit-attestation.md` now state that the property is reserved, that persistence is not implemented and that the chain is in memory. No sample sets `StoragePath`. The property and the PublicAPI files are unchanged.

- `src/Encina.Compliance.Attestation/HashChainOptions.cs` — XML summary of `StoragePath`.
- `src/Encina.Compliance.Attestation/README.md` — hash chain sample and options table.
- `docs/features/audit-attestation.md` — the production hash chain sample.
