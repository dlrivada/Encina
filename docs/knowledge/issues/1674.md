## Asked

Decide on the names and structure of the three audit stores (operation, entity-change, read-access) before 1.0, create the ADR, and sequence the implementation work so each store follows a coherent design.

## Outcome

Decision delivered: three stores, named by purpose (operation, entity-change, read-access), with entity-change audit moved to Encina.Security.Audit and expanded to include TimeProvider, TenantId, ModuleId, purge, and redaction. ADR 036 documents the decision, and implementation follows the order #1674 → #1633 → #751.
