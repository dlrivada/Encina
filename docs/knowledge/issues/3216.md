## Asked

Make `FanOutFirstSuccessAsync` return as soon as an activity succeeds and give `FanOutAllAsync` one error shape whatever the number of failures.

## Outcome

Delivered with #3214 and #3114 in one pull request: `Task.WhenAny` semantics for first success, and one `durable.fanout_failed` aggregate error whose `details` carry the failure codes and input indexes.

## Where the knowledge lives

- `src/Encina.AzureFunctions/Durable/FanOutFanInExtensions.cs` documents the aggregate error and its `details` keys.
- `tests/Encina.UnitTests/AzureFunctions/Durable/FanOutFanInExtensionsTests.cs` has the controlled-order tests (fast failure, fast success, slow success, all fail).
