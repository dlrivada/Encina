## Asked

Remove `ABACDecisionAuditOptions.AllowCrossTenantQueries`, so that the ABAC decision audit reader can never be switched into a cross-tenant mode, and make the reader fail closed with `DecisionAuditTenantRequired` when a multi-tenant application has no ambient tenant (part 1; the audited platform-operator path is #3748).

## Outcome

The option, its PublicAPI lines and the EventId 9090 warning are removed; `ABACDecisionAuditReader.WithoutAmbientTenant` denies in a multi-tenant application and passes the requested filter in a single-tenant one; the reader no longer takes `IOptions<ABACOptions>`. Documentation follows in #3753.

## Where the knowledge lives

- `src/Encina.Security.ABAC/DecisionAudit/ABACDecisionAuditReader.cs` — the fail-closed tenant gate.
- `tests/Encina.UnitTests/Security/ABAC/DecisionAudit/ABACDecisionAuditReaderTests.cs` — denial for query and export, ambient tenant filtering, single-tenant behaviour.
- `src/Encina/Diagnostics/EventIdRanges.cs` — 9090 listed as free to reuse.
