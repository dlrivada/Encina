## Asked

Stop denying a relative write path only because it contains a `src` segment (`artifacts\src\x.md`); resolve it against the working directory first.

## Outcome

Delivered together with #3600: `Test-ScriptWritesAreSafe` resolves a relative target when the base is known and keeps the textual `src`/`tests` rule only as the fail-closed fallback when it is not. Cases are in `Test-Hooks.ps1` (#3600 block).

- `.claude/hooks/_write-targets.ps1` — the target judging in `Test-ScriptWritesAreSafe`.
- `.claude/hooks/tests/Test-Hooks.ps1` — the #3242 cases.
