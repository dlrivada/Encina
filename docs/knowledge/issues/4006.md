## Asked

Stop the 1-9999 EventId space from running out: define a 10000+ zone with one base per area, fix the stale free-range list, and make the block registry a tracked file that a test keeps in agreement with `EventIdRanges.cs`.

## Outcome

ADR-021 has a "10000+ zone" amendment with the per-area table and the pick rule. `docs/engineering/eventid-block-registry.md` replaces the git-ignored `artifacts/decisions/plan-batch/eventid-blocks.md` as the registry. `EventIdRegistryAgreementTests` enforces five agreement rules in CI and shows an id above 9999 is accepted by `EventIdUniquenessRule`.

## Where the knowledge lives

- `docs/architecture/adr/021-eventid-uniqueness-enforcement.md` — the zone, the area table and the rule.
- `docs/engineering/eventid-block-registry.md` — registered ranges and reserved blocks.
- `tests/Encina.UnitTests/Testing/Architecture/EventIdRegistryAgreementTests.cs` — the agreement test.
