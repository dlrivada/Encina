## Asked

`remediation-drafter` (#1572) was told in prose never to run the audit scripts, but it had the PowerShell tool,
so nothing stopped it from running `audit-draft-remediation.ps1 -Prepare` and wiping the open audit's drafts.

## Outcome

Delivered by removing the capability rather than guarding it: the agent's tools are Read, Write, Edit, Grep and
Glob. It needs nothing else, because the orchestrator runs Prepare, Finalize, the stage commit and every `gh`
call. Its shell-only hooks were dropped from its frontmatter, and the Test-Hooks frontmatter check now fails if
a shell tool is added back.

## Where the knowledge lives

- `.claude/agents/remediation-drafter.md` -- the tool list and the "you have no shell" note.
- `.claude/hooks/tests/Test-Hooks.ps1` -- the frontmatter check for remediation-drafter's tools and maxTurns.
- `.claude/agents/README.md` -- the agent row and the no-background-specialists wiring note.
