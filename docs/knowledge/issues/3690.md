## Asked

Make `Encina.AwsLambda` read the `ErrorCategory` and the core HTTP table (#3683) instead of parsing error codes, with the same choices as the AspNetCore and Azure Functions hosts, and stop writing `EncinaError.Message` in the response body.

## Outcome

The mapper, predicates and `GetTitle` are gone; both response shapes share one builder that writes status, title, `Retry-After` and `WWW-Authenticate`; the host's own errors are categorized and the pending-file line `src/Encina.AwsLambda/ => H3` is deleted.

- `src/Encina.AwsLambda/ApiGatewayResponseExtensions.cs` - the single builder.
- `src/Encina.AwsLambda/README.md` - the category table and the body shape.
- `docs/architecture/adr/062-error-category-contract.md` - the contract.
