## Asked

Stop `ShardInfo` (primary and replica connection strings) and `ShardTierInfo` from writing their database connection strings through the compiler-generated record `ToString()`, string interpolation and System.Text.Json serialization, as `AGENTS.md` section 3 requires for any type that carries a connection string (#851). Found while reviewing #3618.

## Outcome

The connection-string properties are marked `[JsonIgnore]` on their explicit declarations and both records have a hand-written `ToString()` that prints `ConnectionString = ***` (and, for `ShardInfo`, `ReplicaConnectionStrings = [N masked]`). The records cannot be rebuilt from their own JSON (documented); configuration binding is unaffected.
