## Asked

Make the solution build with SDK 10.0.404 without the CA1877, CA2026 and CA1830 errors.

## Outcome

Three one-line rewrites with unchanged behavior: `Path.Combine([root, .. parts])` in `CodeGenerator`, `JsonElement.Parse(body)` in `DebeziumHttpListener`, and `StringBuilder.Append(char, int)` in `DateOfBirthMaskingStrategy`.

## Where the knowledge lives

- `src/Encina.Cli/Services/CodeGenerator.cs` — test project path for the Stryker config.
- `src/Encina.Cdc.Debezium/DebeziumHttpListener.cs` — event parsing.
- `src/Encina.Security.PII/Strategies/DateOfBirthMaskingStrategy.cs` — partial masking.
