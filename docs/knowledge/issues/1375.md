## Asked

Fix the SPEC-003 audit pipeline's remediation stage (`tools/ai/audit/audit-draft-remediation.ps1`), which drafted exactly one fixed `[DEBT]` issue per stage artifact regardless of how many findings the stage reported, always ticked a non-existent `Code smell` checkbox, never deduplicated against open issues, and never set a milestone — so `audit-verifier`'s FAIL loop for the pipeline's own remediation stage could never converge.

## Outcome

Delivered: `Split-Findings` (`tools/ai/audit/_audit-lib.ps1`) splits each stage's `## Findings` section into individual findings; `audit-draft-remediation.ps1` classifies and deduplicates each one against the open issues, routes it to the matching issue template with that template's real headers embedded verbatim, and lists every finding in `stages/remediation.md` as a draft, a duplicate, or a flagged parsing gap. `-DryRun`/`-NoGh` let the new `Test-Hooks.ps1` cases exercise the real routing offline.

## Where the knowledge lives

- `tools/ai/audit/_audit-lib.ps1` — `Split-Findings`, the per-finding parser.
- `tools/ai/audit/audit-draft-remediation.ps1` — classification, deduplication, template routing, `-DryRun`/`-NoGh`.
- `.claude/hooks/tests/Test-Hooks.ps1` — the offline regression cases for the per-finding routing.
- `.claude/skills/issue-audit/SKILL.md`, `.claude/agents/audit-verifier.md` — the updated pipeline description and the verifier's expanded per-draft checks.
