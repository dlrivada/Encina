## Asked

Make the five defect classes of audit #18's remediation drafts (dropped packages, wrong test category, invented coverage figures, "throws" for a `Left`-returning method, pipeline meta-text) deterministic in `audit-draft-remediation.ps1`'s post-processing, so a draft matches its finding without re-rolling the local model and the verifier loop can converge.

## Outcome

Each class is a pure function in `tools/ai/audit/_remediation-checks.ps1` with passing and failing fixture tests in `.claude/hooks/tests/Test-Hooks.ps1`; `audit-draft-remediation.ps1` applies the package and test-category repairs inside `Repair-Draft`, makes one combined extra model call per draft for the remaining violations, marks what survives in `stages/remediation.md` and exits 1. The `issue-audit` skill describes the behavior.

## Where the knowledge lives

- `tools/ai/audit/_remediation-checks.ps1` — `Get-FindingPackages`, `Set-PackageLine`, `Set-TestCategory`, `Get-UnsupportedFigures`, `Get-EitherSemanticsViolations`, `Get-MetaTextLines` and `Get-DraftViolations`.
- `tools/ai/audit/audit-draft-remediation.ps1` — the single combined re-ask and the surviving-violation marks.
- `.claude/skills/issue-audit/SKILL.md` — the orchestrator-facing description of the marks.
