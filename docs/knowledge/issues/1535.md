## Asked

`Limit-RelatedIssues` (`tools/ai/audit/_remediation-checks.ps1`) strips an unverified `#n` reference from a
remediation draft, but when that reference was the leading or sole number of a Related Issues list item (e.g.
`- #910 - [TEST] Increase coverage ...`), it removed only the `#n` token and left the rest of the bullet behind.
This produced three broken Markdown shapes, all found in audit #18's live drafts under
`artifacts/knowledge/remediation/`: a doubled list marker with no link (`- - [TEST] title`, 18-tests-1 through
18-tests-4), a dangling colon (`-: [DEBT] title`, 18-docs-13 and 18-docs-14), and a bare `-` line with no content
(18-docs-5). Published as-is, these lines would be broken Markdown with related-issue titles carrying no link to
their issue number.

## Outcome

Delivered: `Limit-RelatedIssues` now drops the whole bullet line when the stripped reference is the bullet's own
leading token (with or without bold wrapping, followed by `-`, `:`, or nothing at all); a reference elsewhere in a
bullet's own prose still gets only the token removed, unchanged from before. A `## Related Issues` section left
with no bullets at all after this gets the line `None.` under its still-present header. Each of the three broken
shapes was confirmed to reproduce against origin/main's unmodified script before the fix, and a new Test-Hooks.ps1
block covers all three shapes, a bold-bullet variant, the unchanged prose case, and the empty-section case. A
companion case was added to the existing `#1534` `-DuplicateOf` block proving that naming a non-primary member of
a same-location group records the whole group as duplicate, the same as naming the primary -- confirming existing
behavior rather than changing it.

## Where the knowledge lives

- `tools/ai/audit/_remediation-checks.ps1` -- `Limit-RelatedIssues`'s whole-bullet detection (the bullet-leading-
  reference regex) and the empty-section `None.` insertion, both added at the end of its per-line loop.
- `.claude/hooks/tests/Test-Hooks.ps1` -- the `#1535` block (the three shapes, the bold-bullet variant, the prose
  case, and the empty-section case) and the new non-primary-member case in the existing `#1534` block.
