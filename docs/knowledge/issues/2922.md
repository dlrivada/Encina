## Asked

The Copy to Excel control of the coverage dashboard threw `ReferenceError: effectiveTarget is not defined` because the handler used a variable that exists only inside `renderPackages`.

## Outcome

Delivered: `docs/coverage/app.js` has one shared `effectiveTargetOf(pkg)` helper that the table and the handler both call. The per-flag percentage cells of the export, which were always `-` because applicability ignored the manifest targets, now use the same rule as the table. The fix was checked with a throwaway node run against a DOM stub (not committed); the click was not exercised in a real browser.

## Where the knowledge lives

- `docs/coverage/app.js` — `effectiveTargetOf`, `renderPackages` and the `copy-table` click handler.
