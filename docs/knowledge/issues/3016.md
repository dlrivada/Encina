## Asked

Stop the MongoDB inbox TTL index from deleting rows behind the inbox purge service (#3013, parent #1969), and document the automatic inbox purge where users configure the inbox.

## Outcome

Delivered: `MongoDbIndexCreator` no longer creates a TTL index on the inbox collection; it creates an ordinary `IX_Inbox_Expires` index on `ExpiresAtUtc`, which the expired-message query uses. The purge options and semantics are documented in the `Encina.Messaging` README, `docs/messaging/inbox.md` and the provider READMEs.

## Where the knowledge lives

- `src/Encina.MongoDB/MongoDbIndexCreator.cs` - the inbox indexes.
- `tests/Encina.UnitTests/MongoDB/MongoDbIndexCreatorTests.cs` - asserts no index with `ExpireAfter` is created for the inbox.
- `src/Encina.Messaging/README.md` and `docs/messaging/inbox.md` - the purge options and behaviour.
- `src/Encina.MongoDB/README.md` - the manual `dropIndex` step for older databases.
