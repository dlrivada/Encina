## Asked

Issue #6 asked to fix 7 tests in `Encina.Quartz.Tests` (`QuartzRequestJobTests`, `QuartzNotificationJobTests`) that were skipped because `NSubstitute.Received()` cannot intercept the static `[LoggerMessage]` delegate calls the production jobs use.

## Outcome

Delivered the same day (2025-12-23) through a direct commit (b7f1057a, no separate PR): NSubstitute `ILogger` mocks were replaced with `Microsoft.Extensions.Diagnostics.Testing`'s `FakeLogger<T>`. All 7 tests were unskipped and pass; the pattern has since become the codebase convention (74 files) but is not written down in `AGENTS.md` or the testing guide.

## Where the knowledge lives

- `tests/Encina.UnitTests/Quartz/QuartzRequestJobTests.cs`, `QuartzNotificationJobTests.cs`: the fix itself, still current.
- No rule documents the `FakeLogger<T>` pattern despite the widespread use (destination planned, tracked by #1331, open).

## Audit

`findings-tracked` (the audit's result was conforms-with-na): code and tests today fully satisfy the issue's original intent with materially expanded coverage (guard/property/integration tests, PII-redaction tests for #1173). Two minor, non-blocking test-hygiene findings were folded into one remediation issue, #1331, rather than fixed inline (see [docs/knowledge/audits/issue-6.md](../audits/issue-6.md)).
