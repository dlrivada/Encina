**Asked.** Issue #6 asked to fix 7 tests in `Encina.Quartz.Tests` (`QuartzRequestJobTests`, `QuartzNotificationJobTests`) that were skipped because `NSubstitute.Received()` cannot intercept the static `[LoggerMessage]` delegate calls the production jobs use.

**Outcome.** Delivered the same day (2025-12-23) through a direct commit (b7f1057a, no separate PR): NSubstitute `ILogger` mocks were replaced with `Microsoft.Extensions.Diagnostics.Testing`'s `FakeLogger<T>`. All 7 tests were unskipped and pass; the pattern has since become the codebase convention (14+ files) but is not written down anywhere.

**Where the knowledge lives.**
- `tests/Encina.UnitTests/Quartz/QuartzRequestJobTests.cs`, `QuartzNotificationJobTests.cs` — the fix itself, still current.
- No CLAUDE.md rule documents the FakeLogger<T> pattern despite 14+ files using it (destination planned, see remediation).

**Audit.** `conforms-with-na` — code and tests today fully satisfy the issue's original intent with materially expanded coverage (guard/property/integration tests, PII-redaction tests for #1173). Two minor, non-blocking test-hygiene findings were folded into one remediation draft rather than fixed inline (see `artifacts/knowledge/audits/issue-6.md`).
