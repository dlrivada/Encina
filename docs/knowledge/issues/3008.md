## Asked

Make the three ADO.NET inbox stores (SqlServer, PostgreSQL, MySQL) pass message ids to `RemoveExpiredMessagesAsync` as command parameters, never concatenated into the SQL, so the inbox purge service (#3013, parent #1969) can call them safely. On MySQL a backslash in an id escaped the doubled quote.

## Outcome

Delivered: each store builds one parameter per id (`@p0` to `@pn`) and executes the `DELETE` in chunks of 1000 ids, in order (SQL Server allows 2100 parameters per request). An empty list is a no-op, and `InboxOptions.PurgeBatchSize` has no ceiling.
