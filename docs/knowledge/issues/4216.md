## Asked

Make the publish, sbom, sonar and dogfooding workflows and the user-facing CI templates install .NET SDK 10.0.x and 11.0.x, so the later move of `global.json` to SDK 11 does not have to touch them.

## Outcome

Ten workflow files install both SDKs through a multi-line `dotnet-version` value, the template cache keys use a fixed single-line SDK segment, and the template documentation states the new default.

## Where the knowledge lives

- `.github/workflows/templates/encina-test.yml`, `encina-matrix.yml`, `encina-full-ci.yml` and `templates/.github/workflows/mutation-tests.yml` - the two-SDK defaults and the single-line cache keys.
- `docs/ci-cd-templates.md` - the documented `dotnet-version` default.
