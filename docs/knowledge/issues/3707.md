## Asked

Correct the NuGet Description of the three publish-only transport packages so that each sentence matches what the publisher does today.

## Outcome

The three `Description` elements say what each publisher does: Kafka produces with keys, headers and batches; Azure Service Bus sends to queues, publishes to topics and schedules messages; NATS publishes on core and on JetStream with message-id de-duplication. No consumer, subscription, dead-letter or exactly-once wording remains.

## Where the knowledge lives

- `src/Encina.Kafka/Encina.Kafka.csproj`, `src/Encina.AzureServiceBus/Encina.AzureServiceBus.csproj`, `src/Encina.NATS/Encina.NATS.csproj` — the corrected descriptions.
- `src/Encina.NATS/NATSMessagePublisher.cs` — the de-duplication limit that rules out an exactly-once claim.
