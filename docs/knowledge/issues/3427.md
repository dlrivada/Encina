## Asked

Make the `correlationId` in the Problem Details body equal the `Correlation-Id` response header, taken from the ambient request context and never from the raw client header (unbounded length, control characters).

## Outcome

`ProblemDetailsExtensions.AddCorrelationExtensions` reads `IRequestContextAccessor.RequestContext.CorrelationId` from `httpContext.RequestServices`; without a context the field is omitted. Unit tests run `EncinaContextMiddleware` and compare body and header for valid, oversized, control-character and absent client ids.

## Where the knowledge lives

- `src/Encina.AspNetCore/ProblemDetailsExtensions.cs` — `AddCorrelationExtensions`.
- `tests/Encina.UnitTests/AspNetCore/ProblemDetailsExtensionsTests.cs` — the correlation tests.
- `src/Encina.AspNetCore/README.md` — Problem Details section.

## Known limits

- A response built outside the context middleware (no request context) carries no `correlationId`.
