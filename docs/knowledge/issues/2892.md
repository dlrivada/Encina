## Asked

Stop `.claude/hooks/guard-orchestrator-writes.ps1` from denying `pwsh -File <script>` merely because the script contains a file-write API and its text mentions `src/` or `tests/` (an issue-draft generator whose here-strings name source paths while it writes only under `artifacts/`). Judge the resolved write targets, deny when one resolves under the checkout's `src/` or `tests/` or cannot be resolved.

## Outcome

Fixed for PowerShell scripts. `Test-ScriptWritesAreSafe` (`.claude/hooks/_write-targets.ps1`) classifies a script as Guarded (a target under `src/` or `tests/`), Safe (every write site understood and resolved elsewhere) or Unknown (anything else). An Unknown script is denied only when its text names `src/` or `tests/` (for an unresolved target also when the launching command, script path removed, names them or the launching cwd is under them); an Unknown script with no such mention is allowed. Other scripts (`dotnet run <file>.cs`) keep the text rule. Regression cases are in `.claude/hooks/tests/Test-Hooks.ps1`, including a timed 26-level doubling chain through `-f`, `Join-Path`, `[IO.Path]::Combine` and `.Replace` (every resolved value over 8192 characters is unresolved).

Evasions that remain open under follow-up B1 (reproduced by the delta reviews, none caused by this change): a wildcard in a parent segment (`[s]rc\Encina\Foo.cs`; `Set-Content -Path '.\wcdir\[s]rx\a.txt'` overwrote an existing file), targets built in the launching command from `'s'+'rc'`, splatting, an environment variable, and a cwd that is a junction to `src` (`GetFullPath` does not resolve reparse points); plus Invoke-Expression, computed command names, nested launches and native copiers. The seven real parameter-driven repository scripts below are exercised against the real hook by seven cases of `Test-Hooks.ps1` (all allowed): tools/ai/priority/collect-issues.ps1, tools/ai/board/build-board-stats.ps1, tools/ai/board/reconcile-board.ps1, .github/scripts/link-health-report.ps1, .github/scripts/sonar-issues.ps1, .github/scripts/crap-gate-selftest.ps1, tools/ai/priority/Test-Priority.ps1 (all allowed).

Two other symptoms in the issue comments are not fixed here and have their own follow-up issues: running an existing repository script in a read-only check mode is blocked, and `block-main-checkout-writes` does not recognise worktrees outside `.claude\worktrees`.
