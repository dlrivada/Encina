## Asked

Make `Encina.AzureFunctions` read the `ErrorCategory` and the core HTTP table (`ErrorCategoryHttp`, #3683) instead of parsing error code text, categorize the host's own producers, and write the headers and titles the table defines (#3419 slice H2).

## Outcome

`HttpResponseDataExtensions` takes the status, the title and the headers from the category; the mapper, its predicates and `GetTitle` are gone. The tenancy, Durable and saga producers pass a category, `ActivityResult<T>` carries it across the Durable boundary, the pending-file line of the package is deleted, and the saga execution is split into small methods so every touched method stays under CRAP 10.

## Where the knowledge lives

- `src/Encina.AzureFunctions/HttpResponseDataExtensions.cs` - status, title and headers.
- `src/Encina.AzureFunctions/Durable/ActivityResult.cs` - the category across the Durable boundary.
- `docs/architecture/adr/062-error-category-contract.md` - the contract and the staged migration.
- `src/Encina.AzureFunctions/README.md` - the category-to-status table.
