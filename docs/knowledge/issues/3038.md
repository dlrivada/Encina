## Asked

Let `pr-reviewer` create its own `artifacts/pr-review` folder in a fresh worktree, so it can save `artifacts/pr-review/<pr>.md`, without allowing any write outside that tree.

## Outcome

The `pr-reviewer` rule of `enforce-path-ownership.ps1` now matches `^artifacts/pr-review(/|$)`. `Test-Hooks.ps1` gained cases for the folder (shell and Write), a subfolder, a sibling prefix, `artifacts` itself, another artifacts folder and `site-steward`.

## Where the knowledge lives

- `.claude/hooks/enforce-path-ownership.ps1` — the `pr-reviewer` branch.
- `.claude/hooks/tests/Test-Hooks.ps1` — the `#3038` cases.

The `site-steward`, `local-ai-standin` and `decision-extractor` rules have the same shape (they accept the files under their folder, not the folder itself) and were checked and deliberately left unchanged, so that no other agent's ownership is widened by this fix.
