## Summary

Issue #9 fixed two failing `Encina.Dapper.Sqlite.ContractTests` for `IScheduledMessage`: one by rebuilding the test message with past timestamps so it appears in `GetDueMessagesAsync`, the other by permanently skipping `RescheduleRecurringMessageAsync_Contract_ResetsRetryFields` for a SQLite datetime-format incompatibility, justified only in the closing GitHub comment. Delivered directly on `main` via commit 3f20fec (no pull request), closed manually. The entire `Encina.Dapper.Sqlite` package, along with every other SQLite provider, was deleted three months later by [ADR-024](../../architecture/adr/024-remove-sqlite-provider-pre-1.0.md); the exact "datetime('now') incompatible with ISO 8601" limitation this issue hit is one of ADR-024's stated reasons for the removal, so the lesson is captured, and the affected files no longer exist to audit (`code-removed`, SPEC-003 §5.1/§5.3). See [docs/knowledge/audits/issue-9.md](../audits/issue-9.md).
