## Asked

Stop `DomainEventDispatchException` from building its text out of `EncinaError.Message` when a failed `IEncina.Publish` is turned into an exception with `StopOnFirstError = true`.

## Outcome

The exception now takes `(IDomainEvent, EncinaError)` or `(IDomainEvent, Exception)`. Message and Data carry the event type name and the error code only; a cause becomes a sanitized `InvalidOperationException("Cause type: ...")`. A sentinel regression test, the shape tests and the corrected EF Core README section ship with it.

## Where the knowledge lives

- `src/Encina.EntityFrameworkCore/DomainEvents/DomainEventDispatcherInterceptor.cs` — the interceptor and the exception.
- `tests/Encina.UnitTests/EntityFrameworkCore/DomainEvents/DomainEventDispatcherInterceptorTests.cs` — the sentinel regression and shape tests.
