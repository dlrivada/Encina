## Asked

Stop the `Issue hygiene` workflow from failing with 403 when a pull request receives a milestone without a priority label.

## Outcome

`handleIssue` in `.github/workflows/issue-hygiene.yml` returns when `issue.pull_request` is set. The job keeps `issues: write` and `contents: read`; `pull-requests: write` is not added because the completeness rule applies to issues only.

## Where the knowledge lives

- `.github/workflows/issue-hygiene.yml` — the guard after `issues.get`.
