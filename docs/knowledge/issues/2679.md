## Asked

Bring the contract and guard flags of `Encina.Security.Encryption` to their manifest targets (contract 15, guard 20, unit 70) with tests that execute the real package code.

## Outcome

Two new test classes run the real encryptor, key provider, orchestrator, pipeline behavior, health check and DI registration. Measured locally, the package reached unit 93%, guard 86% and contract 77%, and the manifest gained per-file targets with justifications. An empty string encrypts but cannot be decrypted, which was reported to the orchestrator as a separate production defect (follow-up issue #2682).

## Where the knowledge lives

- `tests/Encina.ContractTests/Security/Encryption/EncryptionBehaviorContractTests.cs` — behavioral contract of the encryptor, key provider, orchestrator, pipeline behavior and health check.
- `tests/Encina.GuardTests/Security/Encryption/EncryptionGuardBehaviorTests.cs` — argument rejection and fail-closed paths on the real implementations.
- `.github/coverage-manifest/Encina.Security.Encryption.json` — the per-file targets and justifications.
