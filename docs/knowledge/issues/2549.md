## Asked

Remove every wall-clock wait from the Polly and Bulkhead pipeline-behavior unit tests so they pass deterministically under CPU load.

## Outcome

The circuit breaker tests use a `FakeTimeProvider` fed through a new optional `TimeProvider` constructor parameter; the bulkhead concurrency test blocks handlers on a `TaskCompletionSource` gate and waits on an observable condition with a deadline.

## Where the knowledge lives

- `src/Encina.Polly/Behaviors/CircuitBreakerPipelineBehavior.cs` — the `TimeProvider` seam.
- `tests/Encina.UnitTests/Polly/CircuitBreakerPipelineBehaviorTests.cs` — fake-clock tests.
- `tests/Encina.UnitTests/Polly/BulkheadPipelineBehaviorTests.cs` — gate-based concurrency test.
