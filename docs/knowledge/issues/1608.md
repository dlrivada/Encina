## Asked

Stop the five scoped transport publishers (NATS, RabbitMQ, MQTT, Azure Service Bus, Kafka) from closing, disposing or flushing the DI-singleton connection, channel, client or producer when the scope that resolved them ends.

## Outcome

The publishers no longer implement `IDisposable` or `IAsyncDisposable`; `RabbitMQMessagePublisher` no longer takes the unused `IConnection`; `NATSMessagePublisher` gained a constructor without JetStream so it resolves when JetStream is off. Each package has a lifetime test and a `ValidateOnBuild` plus `ValidateScopes` DI test. Amazon SQS, Redis Pub/Sub, InMemory, gRPC and GraphQL were checked and are clean.

## Where the knowledge lives

- `tests/Encina.UnitTests/Kafka/Publishing/KafkaPublisherLifetimeTests.cs` and its siblings for NATS, RabbitMQ, MQTT and Azure Service Bus — scope-end behavior of each publisher.
- `src/Encina.NATS/NATSMessagePublisher.cs` — the constructor pair for the optional JetStream context.
