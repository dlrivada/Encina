Implement the Routing Slip pattern in `Encina.Messaging`: a builder, step execution with compensation, mid-flight route modification and completion tracking, with unit, contract and guard tests and 85%+ coverage. The 137 tests of the close comment were consolidated by 658263027; the property tests and the old guard file no longer exist.
