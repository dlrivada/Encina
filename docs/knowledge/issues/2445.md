## Asked

Remove `ex.Message` from the MySQL processing activity registries' `EncinaError` and diagnostics, as AGENTS.md section 3 forbids exception messages in errors that reach logs, tags or storage.

## Outcome

Fixed in the same PR as #1322 for the ADO.NET, Dapper, EF Core and MongoDB registries of every provider. `GDPRErrors.ProcessingActivityStoreError` now takes the exception and writes only its type name.

## Where the knowledge lives

- `src/Encina.Compliance.GDPR/GDPRErrors.cs` — the factory.
- `tests/Encina.UnitTests/OpenTelemetry/ProcessingActivityRegistryActivityStatusTests.cs` — asserts the secret reaches neither the error message nor the activity.
