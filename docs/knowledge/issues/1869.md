## Asked

Stop `AuditPipelineBehavior` from detaching its audit write with `_ = RecordAuditEntryAsync(...)`: the write raced the request's scoped store and a `Left` or exception from the store was logged and lost, so a failed audit write reported success.

## Outcome

Delivered: the write is awaited in a child scope, `OperationAuditOptions.FailureMode` (`FailClosed` default, `BestEffort` opt-out) decides what a failed write does, and the behavior takes an `IServiceScopeFactory` instead of the store. Tests cover unit, guard, contract, a DI build with validation, and integration on ADO SqlServer, EF Core SqlServer and MongoDB.

## Where the knowledge lives
