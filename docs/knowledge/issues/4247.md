## Asked

Make a replayed cached inbox error keep the category (and so the HTTP status) of the original failure instead of always answering `Internal` (500).

## Outcome

`InboxOrchestrator` writes `error.GetCategory()` into the response envelope and `inbox.cached_error` reads it back. Old rows without the field and unknown values read `Internal`. No provider package, schema or public API changed.

- `src/Encina.Messaging/Inbox/InboxOrchestrator.cs` - envelope write and read.
- `tests/Encina.UnitTests/Messaging/Inbox/InboxOrchestratorRetryTests.cs` - round trip, missing field, unknown value.
