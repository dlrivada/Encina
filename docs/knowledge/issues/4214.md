## Asked

Remove the CA2026 and CA2027 warnings that the SDK 11 analyzers report in six files of `tests/Encina.IntegrationTests`, with a change that also builds with zero warnings on SDK 10.

## Outcome

Every `JsonDocument.Parse(...).RootElement` site uses `JsonElement.Parse(...)`, and every `Task.WhenAny(task, Task.Delay(timeout))` site uses a private `CompletesWithinAsync` helper built on `Task.WaitAsync(timeout)`. Test intent and timeouts are unchanged.

## Where the knowledge lives

- `Directory.Build.props` — `TreatWarningsAsErrors` with the recommended analysis mode should turn the analyzers into build failures once the repository builds on SDK 11 (planned under #3667, the net11.0 flip); on SDK 10 nothing enforces these two rules yet.
