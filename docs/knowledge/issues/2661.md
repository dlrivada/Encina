## Asked

Move the remaining GraphQL-backed `gh pr`, `gh issue`, `gh label` and `gh project` callers of `tools/ai` to REST, or behind the shared quota helper where only GraphQL exists, so the scripts work while the shared GraphQL budget is exhausted.

## Outcome

The audit scripts, board scripts, project-membership check and priority-label script read and write over REST; the bulk and project GraphQL calls wait for the quota. The GraphQL-down selftest covers each converted script.

## Where the knowledge lives

- `docs/engineering/github-api-quota.md` — what uses which API and the callers behind the helper.
- `tools/ai/gh-graphql-down-selftest.ps1` — proof that the converted scripts work with GraphQL at 0.
- `tools/ai/gh-quota.ps1` — the helper every remaining GraphQL call goes through.
