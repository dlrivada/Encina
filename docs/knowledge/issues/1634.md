## Asked

`[RequirePolicy]` and `[RequireCondition]` were discovered on the request but never used: the PEP evaluated the whole policy store, so a request could pass while the policy it names denied it, and a false condition was never checked. `ObligationExecutor` let a throwing obligation or advice handler escape. Make the attributes decide requests exactly as their XML docs promise, fail closed on every path that cannot be evaluated, and turn handler exceptions into handled failures with no message text in logs or errors.

## Outcome

Delivered on branch fix/abac-require-policy-1634; closed is the expected merge date and the orchestrator corrects it if the PR merges later. The README and the docs pages, the PublicAPI lines, the coverage manifest entries and the changelog fragment are included. `DefaultNotApplicableEffect` was removed and resource attributes now come from the request. The PR #1650 review round limited `[RequirePolicy]` names to top-level policy sets and standalone policies, made Indeterminate deny in Warn mode, removed `FailOnMissingObligationHandler` and guarded `CanHandle`.
