## Asked

`[RequirePolicy]` and `[RequireCondition]` were discovered on the request but never used: the PEP evaluated the whole policy store, so a request could pass while the policy it names denied it, and a false condition was never checked. `ObligationExecutor` let a throwing obligation or advice handler escape. Make the attributes decide requests exactly as their XML docs promise, fail closed on every path that cannot be evaluated, and turn handler exceptions into handled failures with no message text in logs or errors.

## Outcome

Delivered on branch fix/abac-require-policy-1634; closed is the expected merge date and the orchestrator corrects it if the PR merges later. The README and docs pages that describe the attributes, the PublicAPI lines, the coverage manifest entries and the changelog fragment were not written by the worker (specialist spawns were unavailable) and are listed in the worker report.
