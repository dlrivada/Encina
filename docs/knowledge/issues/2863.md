## Asked

`DomainEventDispatcherInterceptor` was exercised only by unit tests with a mocked context. The issue asked for end-to-end tests on real SQL Server and PostgreSQL through the shared EF Core fixtures, and for the manifest integration target to reflect the measurement.

## Outcome

Delivered: an abstract scenario base, a test model (aggregate, events, recording handler, context) and one derived class per provider. The scenarios cover dispatch and clearing, a failed save, an explicit transaction that rolls back, a failing handler with and without `StopOnFirstError`, and several aggregates in one save. A failed asynchronous save leaks nothing into the next save; a failed synchronous `SaveChanges()` does (the interceptor does not override `SaveChangesFailed`), so that scenario is marked Skip until #3245 is fixed.

## Where the knowledge lives

- `tests/Encina.IntegrationTests/Infrastructure/EntityFrameworkCore/DomainEvents/` — the scenario base and the test model.
- `tests/Encina.IntegrationTests/Infrastructure/EntityFrameworkCore/SqlServer/DomainEvents/` and `.../PostgreSQL/DomainEvents/` — the provider classes.
- `.github/coverage-manifest/Encina.EntityFrameworkCore.json` — the integration target and justification.
