## Asked

With no tenant context and `ThrowOnMissingTenantContext = true`, every operation of the MongoDB tenant-aware repository must return `Left` with a stable error code instead of throwing `InvalidOperationException` (or returning `Repository.InvalidOperation`).

## Outcome

Delivered for `RepositoryErrors` and MongoDB: the new `Repository.TenantRequired` code, a non-throwing `TenantAwareSpecificationFilterBuilder`, and unit and integration tests per operation. The other providers follow in sibling issues.

## Where the knowledge lives

- `src/Encina.DomainModeling/RepositoryErrors.cs` and `src/Encina.MongoDB/Tenancy/` — the code and the `Left`.
