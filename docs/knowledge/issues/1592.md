## Asked

`audit-draft-remediation.ps1 -Prepare` labelled a candidate "partially related" when it matched only one anchor of the finding, a file or a symbol, and `-Finalize` re-inserted that line into the draft whatever the drafter decided. Audit #18 could not pass verification because five drafts carried a false line. Claim "partially related" only when the candidate covers part of the same defect, and never resurrect a rejected line from an old manifest.
