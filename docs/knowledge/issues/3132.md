## Asked

Make the MySQL default image of Encina.Testing.Testcontainers a supported line, the same for every entry point, after `EncinaContainers.MySql(configure)` still built `mysql:8.0` while the parameterless fixture used `mysql:9.1`.

## Outcome

Both overloads and `MySqlContainerFixture` read one internal constant, `ContainerDefaultImages.MySql = "mysql:8.4"`; a unit test proves it without Docker; the package README and the changelog state the new default. The per-provider sweep is tracked separately (#3334).

## Where the knowledge lives

- `src/Encina.Testing.Testcontainers/ContainerDefaultImages.cs` — the single default image.
- `tests/Encina.UnitTests/Testing/Testcontainers/ContainerDefaultImagesTests.cs` — the Docker-free proof.
