## Asked

Make the packability of the 107 `src/` projects a stated rule instead of an unstated SDK default, without changing the evaluated `IsPackable` of any src, test or tools project.

## Outcome

`Directory.Build.props` gains a `PropertyGroup` beside the `tests/` rule: under `/src/` it sets `IsPackable` to `true` when the csproj has not set it. No csproj is edited.

## Where the knowledge lives

- `Directory.Build.props` — the `/src/` rule and the comment naming the exception path.
- `docs/specifications/SPEC-000-encina-1.0-baseline-and-release-scope.md` — REQ-001/AC-001, the single authoritative list of what ships.
