## Asked

`_ProjectDirectoryNormalized` in `Directory.Build.props` kept backslashes on Windows, so every path-based rule (non-packable test projects, `xunit.analyzers`, the Sonar test flags and the `/src/` packable rule) was inert locally and active only on Linux CI.

## Outcome

Delivered: the `Replace` call now names a single backslash, so the property uses forward slashes on every operating system. The effect was measured on Windows with the full `Encina.slnx` build: 0 warnings and 0 errors before and after, all 107 `src/` projects packable, and test and benchmark projects flagged as Sonar test projects.

## Where the knowledge lives

- `Directory.Build.props` — the normalization property and the path rules that depend on it.
