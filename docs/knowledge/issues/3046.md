## Asked

Run the hosted `MessagePurgeService` end to end against all 10 database providers and prove that one purge cycle removes only processed, expired inbox rows.

## Outcome

One shared scenario and ten thin provider classes under the existing per-family folders (ADO.NET, Dapper and EF Core on SQL Server, PostgreSQL and MySQL, plus MongoDB). Nine run; EF Core MySQL is skipped citing #2086.
