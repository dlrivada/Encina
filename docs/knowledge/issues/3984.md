## Asked

Make `Split-CommandStatements` terminate on any input (a no-break space made it spin forever with growing memory), treat Unicode white space the way PowerShell does, and make a hook whose analysis cannot finish deny instead of allowing.

## Outcome

Cause: the outer loop skipped only a space and a tab while the token loop ended a token on a culture-insensitive `-in` test that also matches U+00A0, so no character was consumed. The tokenizer now classifies characters by code point (`Test-CommandWhitespace`, `Test-CommandSeparator`), guarantees progress on every pass and runs under a time budget; the nine tokenizing hooks catch the budget exception before their generic catch and exit 2 naming themselves, never printing the command.

## Where the knowledge lives

- `.claude/hooks/_command-text.ps1` — the character classes, the progress guarantee and the budget.
- `.claude/hooks/tests/Test-Hooks.ps1` — the termination, split and budget cases (#3984).
