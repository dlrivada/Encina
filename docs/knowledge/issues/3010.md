## Asked

Make the EF Core and MongoDB inbox stores expire only processed rows, like ADO.NET and Dapper.

## Outcome

Delivered in `Encina.EntityFrameworkCore` and `Encina.MongoDB`: the expiry predicate is aligned and the delete is guarded by the same predicate. The MongoDB TTL index still deletes unprocessed rows and is tracked in #3016.

## Where the knowledge lives

- `src/Encina.EntityFrameworkCore/Inbox/InboxStoreEF.cs` - the expiry query and the guarded delete.
- `src/Encina.MongoDB/Inbox/InboxStoreMongoDB.cs` - the shared expired-and-processed filter used by the query and the delete.
- `tests/Encina.IntegrationTests/Messaging/InboxExpiryScenario.cs` - the scenario run on SQL Server, PostgreSQL, MongoDB (and EF MySQL once enabled, #2086).
