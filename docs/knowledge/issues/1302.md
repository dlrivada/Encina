## Asked

Make the MySQL `ProcessingActivities` schema script install on MySQL with `utf8mb4` and prove that the MySQL providers round-trip it.

## Outcome

`RequestTypeName` is `VARCHAR(512)` in `011_CreateProcessingActivitiesTable.sql` and in the shared test schema, so the unique key is 2048 bytes. `MySqlSchemaScriptsIntegrationTests` now runs every script of both MySQL packages against a real MySQL container and round-trips a processing activity through the ADO.NET and Dapper registries on the script-created table. The EF Core MySQL registry shares the model configuration (512) but its fixture is disabled until Pomelo supports EF Core 10.

## Where the knowledge lives

- `src/Encina.ADO.MySQL/Scripts/011_CreateProcessingActivitiesTable.sql` — the corrected column.
- `tests/Encina.IntegrationTests/SchemaScripts/MySqlSchemaScriptsIntegrationTests.cs` — executes all scripts and the registry round trip.
