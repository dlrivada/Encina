## Asked

Detect downstream outages and throttle message processing automatically, then ramp back up on recovery, with circuit breaker integration, metrics and an `AddEncinaRateLimiting` configuration API (created 2025-12-24T13:24:46Z, closed 2025-12-26T14:42:46Z).

## Outcome

Closed by commit 750e82dd with the adaptive limiter in `Encina.Polly`, as an attribute-driven behavior registered by `AddEncinaPolly`. Partial: the configuration API, circuit breaker integration and metrics from the issue are absent.
