## Asked

Make `MartenOperationAuditStore.QueryAsync` and `GetByUserAsync` succeed and return the right entries when the query filters by a UTC `FromUtc` or `ToUtc`, and check the sibling Marten audit stores for the same defect.

## Outcome

`OperationAuditEntryReadModel.TimestampUtc` is now a `DateTimeOffset` (`timestamptz`); the projection and the filters convert the `DateTime` contract values through `AuditTimestamps.ToUtcOffset` (Local converted, Unspecified read as UTC), and the mapping back yields a UTC `DateTime`. `MartenReadAuditStore` already used `DateTimeOffset` and needed no change; the entity-change audit has no Marten store.

## Where the knowledge lives

- `src/Encina.Audit.Marten/Projections/AuditTimestamps.cs` — the conversion.
- `tests/Encina.IntegrationTests/Infrastructure/Marten/Audit/MartenOperationAuditStoreUtcFilterIntegrationTests.cs` — regression tests on real PostgreSQL.
