## Asked

Stop the four dashboard publishers from deploying a raw copy of `docs/` to GitHub Pages, which replaced the Jekyll documentation site and the DocFX API reference with unrendered Markdown and left the site root and `/api/` returning 404 after every dashboard publish.

## Outcome

Delivered together with #1361 in one pull request: `docs.yml` became the single Pages deployer, callable through `workflow_call` with an `overlay-artifact` input; the publishers compute their data, upload it as `pages-overlay-<domain>` and call `docs.yml`; citation rendering moved into `docs.yml`; the `pages` concurrency group sits on the deploy job only; a post-deploy smoke check fails the deploy when the root, the API reference or a dashboard is not served.

## Where the knowledge lives

- `.github/workflows/docs.yml` — the single deployer: live data staging, overlay, rendering, build, deploy and smoke check.
- `.github/workflows/publish-coverage.yml`, `publish-mutations.yml`, `publish-benchmarks.yml`, `publish-load-tests.yml` — overlay upload and the `deploy` job that calls `docs.yml`.
