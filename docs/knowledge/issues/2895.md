## Asked

A pull request could lower or drop a coverage target in `.github/coverage-manifest/*.json` and every dashboard improved; nothing compared a pull request's manifests with the base branch. The real case was the Cdc.PostgreSql unit target going from 50 to 41 (commit `1309055ef`), which nothing flagged.

## Outcome

Delivered: `.github/scripts/check-target-ratchet.cs` is a file-based C# 14 script that fails a pull request lowering (R-LOW) or dropping (R-DROP) a target unless the pull request carries the label `target-change-approved`, read at run time. It has a built-in `--self-test`. The `target-ratchet` job in `ci.yml` is applied by the orchestrator.

## Where the knowledge lives

- `.github/scripts/check-target-ratchet.cs` — the rules, the label exception and the self-test.
- `docs/testing/coverage-measurement-methodology.md` — the "Target ratchet" subsection.
