## Asked

Make `TenantResolutionMiddlewareClaimWinsTests` build without SYSLIB0066 on SDK 11 / net11.0 and with zero warnings on SDK 10, without a .NET 11-only API.

## Outcome

The test that resolved `IStartupValidator` now starts a real host: a header resolver enabled without `TrustedProxies` or `TrustAnyPeer` fails `StartAsync` with `OptionsValidationException`, and a trusted-proxy configuration starts and stops.
