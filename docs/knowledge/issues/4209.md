## Asked

Remove the CA1307 warnings that SDK 11 reports in `QuoteIdentifierIfNeeded` of `src/Encina.ADO.PostgreSQL/BulkOperations/BulkOperationsPostgreSQL.cs` when building for `net11.0`, with a change that also builds warning-free on SDK 10 and keeps the behavior.

## Outcome

`QuoteIdentifierIfNeeded` now checks `identifier.Length >= 2 && identifier[0] == '"' && identifier[^1] == '"'`, so an already quoted identifier is returned unchanged and a single `"` is still quoted, exactly as before. The bulk operations integration tests exercise the quoting path.

## Where the knowledge lives

- `src/Encina.ADO.PostgreSQL/BulkOperations/BulkOperationsPostgreSQL.cs` - the ordinal char check in `QuoteIdentifierIfNeeded`.
- `tests/Encina.IntegrationTests/Infrastructure/ADO/PostgreSQL/BulkOperations/BulkOperationsADOPostgreSQLIntegrationTests.cs` - runs the bulk operations against PostgreSQL.
