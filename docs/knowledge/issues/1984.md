## Asked

Make every definite ABAC authorization denial answer HTTP 403 in the ASP.NET Core, Azure Functions and AWS Lambda adapters, through the existing `encina.authorization.*` prefix rule and without an adapter-specific ABAC table.

## Outcome

`ABACErrors` renames the three definite denial codes, adds `RequiredPolicyNotFoundCode` for a request denied by a missing required policy, and keeps `abac.policy_not_found` for administrative lookups. Tests in the three adapters assert 403 for each code; the ABAC README and docs pages use the new codes.

## Where the knowledge lives

- `src/Encina.Security.ABAC/ABACErrors.cs` — the codes and the denial-versus-lookup split.
- `docs/features/abac/reference/errors.md` — the error reference with the HTTP mapping.
