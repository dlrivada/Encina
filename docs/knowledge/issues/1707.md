## Asked

Fix the persistent policy administration point so it no longer captures a scoped `IPolicyStore` in a singleton.

## Outcome

Delivered on branch `fix/pap-policy-store-scope-1707`: the PAP takes `IServiceScopeFactory` and opens an async scope per operation (reads and writes), resolving the store from that scope and the audit store from a separate scope. The store is wrapped with `CachingPolicyStoreDecorator` per scope while the cache stays shared.

## Where the knowledge lives

- `src/Encina.Security.ABAC/Administration/PersistentPolicyAdministrationPoint.cs` — scope opening, store resolution per operation, resolver delegate.
- `tests/Encina.UnitTests/Security/ABAC/Persistence/PersistentPolicyAdministrationPointScopeTests.cs` — regression tests for concurrent operations and scope disposal.
