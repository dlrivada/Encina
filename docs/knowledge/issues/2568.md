## Asked

Stop the maintainer tooling from exhausting the shared GraphQL quota: instrument the cost per caller, move hot polling and label listings to REST, add a shared back-off helper that reads the real quota, and record the measured cost and chosen polling intervals.

## Outcome

Delivered: `tools/ai/gh-quota.ps1` (quota reader, wait, usage log, REST label and check helpers), REST watchers (`watch-pr-events.ps1`, `watch-open-prs.ps1` with review threads gated on `updated_at` and on the quota), REST label listings and duplicate search, the REST issue read of the spawn gate, and the note `docs/engineering/github-api-quota.md`. The remaining GraphQL-backed callers are tracked in a follow-up issue.

## Where the knowledge lives

- `tools/ai/gh-quota.ps1` — the helper and its thresholds.
- `docs/engineering/github-api-quota.md` — what uses GraphQL, cost, intervals, how to read the quota.
- `.claude/hooks/check-target-issue-template.ps1` — REST issue read.
