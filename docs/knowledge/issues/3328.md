## Asked

Make a sub-issue, and a pull request that closes issues, get the milestone, area labels and priority they lack from their parent or closed issues automatically, and make the EPIC visible on such a pull request, without manual work.

## Outcome

Delivered: `issue-hygiene.yml` inherits from the direct parent before the completeness check; the new `inherit-metadata.yml` fills pull requests (same-repository ones at once, fork and Dependabot ones by a daily job) and posts the EPIC comment; `check-project-membership.ps1` adds open pull requests to project 1.

## Where the knowledge lives

- `.github/workflows/issue-hygiene.yml` — sub-issue inheritance on every issue event.
- `.github/workflows/inherit-metadata.yml` — pull request job, daily repair, EPIC comment.
- `tools/ai/issues/check-project-membership.ps1` — project 1 membership of issues and pull requests, with its self-test.
