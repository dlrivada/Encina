## Asked

Fix the CachingPolicyStoreDecorator so it stamps invalidation messages with TimeProvider instead of DateTime.UtcNow.

## Outcome

Delivered on branch `fix/pap-policy-store-scope-1707`: the CachingPolicyStoreDecorator constructor takes an optional TimeProvider parameter (default TimeProvider.System), and messages are stamped with `timeProvider.GetUtcNow().UtcDateTime`.
