## Asked

Make the dead letter health check report Unhealthy, with only the error code in its data, when the store fails, and register it so it coexists with other `IEncinaHealthCheck` implementations.

## Outcome

`DeadLetterHealthCheck` returns Unhealthy on a store `Left` (count or old-messages query) and `AddEncinaDeadLetterQueue` registers it with `TryAddEnumerable`.

## Where the knowledge lives

- `src/Encina.Messaging/Health/DeadLetterHealthCheck.cs` - fail-closed handling, error code only.
- `src/Encina.Messaging/DeadLetter/DeadLetterServiceCollectionExtensions.cs` - enumerable health-check registration.
