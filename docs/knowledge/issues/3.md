## Asked

A `[DEBT]` issue (milestone v0.09.0) asked to replace `#pragma warning disable CA1848` suppressions with `[LoggerMessage]` source-generator partial classes (`Log.cs`) across the messaging transport packages (RabbitMQ, Kafka, NATS, MQTT, AzureServiceBus, AmazonSQS, Redis.PubSub, InMemory, gRPC, GraphQL, plus Wolverine and NServiceBus).

## Outcome

Delivered by two direct commits to `main` (no PR; this predates the PR-based workflow): `eb88cd58` (2025-12-21) added `Log.cs` to 16+ packages — every package named in the issue plus ADO/Dapper providers, EntityFrameworkCore, Hangfire, Quartz, Marten, MongoDB, SignalR, MassTransit, Wolverine, NServiceBus and EventStoreDB — and `5b8872fe` (2025-12-23, `Fixes #3`) removed the now-obsolete `CA1848` `GlobalSuppressions.cs` entries and `NoWarn` properties. Wolverine, NServiceBus, MassTransit and EventStoreDB were deprecated four hours later (`87d92a39`, `Closes #17`) and moved to `.backup/deprecated-packages/`; their `Log.cs` work is moot.

## Where the knowledge lives

- Rule (no CA1848 suppressions without justification): `CLAUDE.md` "Structured Logging & EventId Allocation" and "Code Analysis" — present today.
- Executable rule (every `[LoggerMessage]` has a registered, non-overlapping EventId): `EventIdRanges.cs` + `EncinaEventIdAllocationTests.cs` — present today, added after #3 by later EventId work (#1050, #1120, #1125, #1126, #1137).
- The four deprecated packages: no destination needed (code removed, `#17`).

## Audit

Verdict `findings-tracked`. A dedicated `adversarial-reviewer` pass on issue #3's own concern (structured logging: `Log.cs` presence, EventIds, message leaks, personal data, log levels, categories, logging tests) across all 21 surviving units found: (1) `FunctionalShardedRepository*` (added later by feature #289) in 8 packages calls raw `ILogger` extension methods instead of `Log.cs`, regressing #3's own fix — new `[DEBT]` drafted; (2) `EncinaError.Message` is logged via `Log.cs` templates in `Encina.EntityFrameworkCore`, `Encina.Marten` and `Encina.GraphQL`, the same defect class as #1319/#1322 but in packages neither covers — new `[BUG]` drafted; (3) a pre-existing leak in `Encina.RabbitMQ/Health/RabbitMQHealthCheck.cs:48` is already tracked by open issue #1301, not re-flagged. EventIds, log levels and categories otherwise pass. Checklist items outside #3's own concern (general coverage, PublicAPI, docs, `TimeProvider`, async DB calls, DI registration completeness) are recorded as out of #3's scope, belonging to each package's own audit — see `artifacts/knowledge/audits/issue-3.md`.
