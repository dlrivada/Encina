## Asked

Make the ten core workflows (benchmarks, ci-full, ci, coverage-comment, dashboard-freshness, docs, honesty-audit, load-tests, mutation-tests, publish-benchmarks) install the .NET 10 and .NET 11 SDKs, keeping their NuGet and tool cache keys valid.

## Outcome

Every setup-dotnet step installs `10.0.x` and `11.0.x`. `DOTNET_SDK_VERSION` became a two-line block at all its definition sites, and the cache keys of load-tests and mutation-tests read the single-line `DOTNET_SDK_CACHE_KEY`.

## Where the knowledge lives

- `.github/workflows/ci.yml` and `.github/workflows/ci-full.yml` define the SDK block once per workflow.
- `.github/workflows/load-tests.yml` and `.github/workflows/mutation-tests.yml` also define the single-line cache key variable.
