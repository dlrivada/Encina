## Asked

Replace the SHA256(salt + value) construction in the PII `HashHelper` with HMAC-SHA256.

## Outcome

Delivered on branch `fix/pii-hash-hmac-858`: Hash mode is a keyed HMAC-SHA256 configured from `PIIOptions.HashKey`, validated fail-closed with the explicit `AllowUnkeyedHash` opt-out, with known-answer and key/value boundary tests.

## Where the knowledge lives

- `src/Encina.Security.PII/Strategies/HashHelper.cs` — the HMAC construction.
- `src/Encina.Security.PII/PIIOptionsValidator.cs` — the fail-closed rules.
- `tests/Encina.UnitTests/Security/PII/Strategies/HashHelperTests.cs` — RFC 4231 vectors and the boundary test.
- `docs/features/pii-masking.md` — the user-facing description of Hash mode and its key.
