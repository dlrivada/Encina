## Asked

Issue #3010 changes the EF Core and MongoDB inbox stores to treat a row as expired only when `ExpiresAtUtc` is in the past AND `ProcessedAtUtc` is set. Existing EF Core tests seed expired rows without `ProcessedAtUtc`, which would fail under the new predicate. Seeding `ProcessedAtUtc` is valid under both the old and new rules, so this test-only change lands first to keep the #3010 PR within size limits and to remove `tests/Encina.TestInfrastructure/EFCore/InboxStoreEFTestsBase.cs`, which is no longer used.

## Outcome

Updated test files to seed `ProcessedAtUtc` on expired rows:
- `tests/Encina.UnitTests/EntityFrameworkCore/Inbox/InboxStoreEFTests.cs`
- `tests/Encina.UnitTests/EntityFrameworkCore/Inbox/InboxStoreEFAdditionalTests.cs`
- `tests/Encina.UnitTests/EntityFrameworkCore/Inbox/InboxStoreEFTimeProviderTests.cs`
- `tests/Encina.GuardTests/EntityFrameworkCore/Stores/InboxStoreEFDeepGuardTests.cs`
- `tests/Encina.ContractTests/EntityFrameworkCore/StoreImplementationContractTests.cs`
- `tests/Encina.PropertyTests/Infrastructure/EntityFrameworkCore/InboxStoreEFPropertyTests.cs`
- `tests/Encina.IntegrationTests/Infrastructure/EntityFrameworkCore/Inbox/InboxStoreEFIntegrationTests.cs`
- `tests/Encina.BenchmarkTests/Encina.EntityFrameworkCore.Benchmarks/InboxStoreEFBenchmarks.cs`

No production code changed. `tests/Encina.TestInfrastructure/EFCore/InboxStoreEFTestsBase.cs` removed.
