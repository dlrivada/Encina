## Asked

Give the maintainer a way to mark one Claude Code session as the orchestrator, so that it gets a short delegation and budget-pace reminder on every prompt and its specialist-level Read, Edit, Write and command steps are denied with a message naming the specialist, while every other session and every subagent stays untouched.

## Outcome

Delivered by `tools/ai/orchestrator-mode.ps1` (`-On`, `-Off`, `-Status`), the shared helper `.claude/hooks/_orchestrator-state.ps1`, the `UserPromptSubmit` hook `orchestrator-prompt-reminder.ps1`, the `PreToolUse` hook `orchestrator-delegation-guard.ps1`, their registration in `.claude/settings.json`, the regression cases in `Test-Hooks.ps1` and one activation line in `CLAUDE.md`.

## Where the knowledge lives

- `tools/ai/orchestrator-mode.ps1` — marks, unmarks and reports the orchestrator session.
- `.claude/hooks/orchestrator-delegation-guard.ps1` — the deny rules and their messages.
- `.claude/hooks/orchestrator-prompt-reminder.ps1` — the per-prompt reminder.
- `.claude/agents/README.md` — the hooks table and the Orchestrator mode section, including the fail-open choice.
