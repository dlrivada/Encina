## Asked

The ABAC PEP recorded `ex.Message` as the activity status and returned `ABACErrors.EvaluationFailed`, whose message came from `exception.Message`; the PDP's `EvaluateAsync` put `Unexpected error: {ex.Message}` in the decision status. AGENTS.md section 3 forbids exception text in logs, activity tags and plaintext storage.

## Outcome

Fixed together with #1676 on branch fix/abac-pep-pdp-fail-closed-1676. The PEP's activity status holds the exception type name, `EvaluationFailed` has a fixed message and the type in its details, and the PDP status is fixed text, with the exception logged through `ForLogging()`. The sentinel tests cover the attribute-provider exception path, the PDP exception path and both store-retrieval sources. The sites outside the enforcement path moved to #1700.
