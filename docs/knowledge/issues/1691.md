## Asked

Make `CdcProcessorIntegrationTests` deterministic after `Processor_ExceedsBatchSize_ProcessesOnlyBatchSizeEvents` failed on main (CI run 37115785625) because a 200 ms token expired during the cold first batch.

## Outcome

`TestCdcConnector` counts stream calls and exposes `WaitForStreamCallsAsync`. The tests start the processor with `CancellationToken.None`, wait for the second stream call (the first batch is complete), then stop it. No `Thread.Sleep` and no fixed `Task.Delay` window remains. The processor in `src/` is unchanged.

## Where the knowledge lives

- `tests/Encina.IntegrationTests/Cdc/CdcProcessorIntegrationTests.cs` — `RunProcessorUntilStreamCallsAsync` and the 30-second hang guard.
- `tests/Encina.IntegrationTests/Cdc/Helpers/TestCdcConnector.cs` — `StreamCallCount` and `WaitForStreamCallsAsync`.
