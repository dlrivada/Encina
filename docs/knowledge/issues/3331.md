## Asked

Make `.github/scripts/perf-report.cs` assign each benchmark result the docRef of its own project's manifest, even when several projects share class and method names (`ConnectorBenchmarks.GetCurrentPositionAsync`, `PositionBenchmarks.FromBytes`, `PositionBenchmarks.ToBytes` in the CDC projects).

## Outcome

`InjectDocRefsFromManifests` now keys its lookup by the manifest class `fullName` plus the method name, and looks it up with the BenchmarkDotNet `Namespace` parsed into a new `BenchmarkEntry.Namespace` property (not persisted). `perf-report.cs --self-test` builds two manifests whose classes share name and method and checks each namespace gets its own docRef and an unknown namespace gets none.

## Where the knowledge lives

- `.github/scripts/perf-report.cs` — the namespace-qualified lookup and the `--self-test` mode.
