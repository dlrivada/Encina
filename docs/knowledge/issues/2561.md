## Asked

Remove the wall-clock wait from the delayed cache invalidation test so it passes deterministically under CPU load.

## Outcome

The behavior takes an optional `TimeProvider`; the test uses a `FakeTimeProvider`, asserts nothing is removed before the clock advances, advances it by the attribute delay and waits on the observable removal with a 30 s deadline. The `Caching/Base` copy of the test class was byte-identical apart from usings and was removed.

- `src/Encina.Caching/Behaviors/CacheInvalidationPipelineBehavior.cs` — the `TimeProvider` seam.
