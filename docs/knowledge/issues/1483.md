## Asked

Add regression tests proving that a saga step that throws does not leak its raw exception message into `EncinaError.Message` or the persisted saga `ErrorMessage` (found together with #1469).

## Outcome

Delivered with the #1469 fix: `ErrorMessageLeakTests` gained a `SagaRunnerHarness` and three tests (step throws, compensation throws, cancellation), and `SagaRunnerTests` asserts the returned message no longer carries the exception text. Run against the previous `SagaRunner`, the tests fail; with the fix they pass.

## Where the knowledge lives

- `tests/Encina.UnitTests/Messaging/Encryption/ErrorMessageLeakTests.cs` — the sentinel tests across every sink.
- `tests/Encina.UnitTests/Messaging/Sagas/SagaRunnerTests.cs` — the exception-path assertion on the returned message.
