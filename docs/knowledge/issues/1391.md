## Asked

The benchmark dashboard at `/Encina/benchmarks/dashboard/` returned 404 after PR #1387 made `docs.yml` the single GitHub Pages deployer, because `docs/_config.yml` had excluded the whole `benchmarks/` directory from the Jekyll build since #916. The static dashboard used to survive only because the old `publish-benchmarks.yml` deployed a raw directory copy that ignored Jekyll's `exclude` list; once `docs.yml` alone decides what is published, the dashboard disappeared along with the Markdown result pages it was meant to exclude.

## Outcome

Delivered: `docs/_config.yml`'s `exclude:` list now has `benchmarks/*.md` instead of `benchmarks/`, so Jekyll's `File.fnmatch?` matching keeps the Markdown result pages out of the build while letting `docs/benchmarks/dashboard/` (static HTML/JS/CSS) through.

## Where the knowledge lives

- `docs/_config.yml` — the narrowed `exclude` entry and the comment explaining why the glob replaces the directory exclusion.
