## Asked

On 2026-09-28 a full remediation run for audit #18 aborted because one `gh issue view` call hit a TLS
handshake timeout; the script treated every non-zero `gh` exit as fatal, and since it had already deleted
the previous drafts the stage was left half-generated.

## Outcome

Delivered by #1572: one retry helper with a 5/15/45-second backoff for transient failures and no retry for
permanent ones, and a `-Prepare` that finishes every `gh` call before touching any file. Test-Hooks stubs `gh`
with a PowerShell function to test the classifier, the retry counts and delays, and a failed run leaving the
previous manifest in place. `open-remediation.ps1` still calls `gh` directly (follow-up issue).

## Where the knowledge lives

- `tools/ai/audit/_remediation-checks.ps1` -- `Test-GhTransientFailure` and `Invoke-GhWithRetry`.
- `tools/ai/audit/audit-draft-remediation.ps1` -- every `gh` call through the helper, before the cleanup.
- `.claude/hooks/tests/Test-Hooks.ps1` -- the `#1548` cases.
