## Asked

Make a `score-issues.ps1 -All -Limit <k>` sample run unable to destroy the full priority results, keep a timestamped backup of the previous `scores.json` before a full write, and let `-Resume` reuse every model judgement already on disk.

## Outcome

Implemented in `tools/ai/priority/score-issues.ps1` with cases in `tools/ai/priority/Test-Priority.ps1`: sample files for `-Limit`, a `scores.<timestamp>.json` backup before a full write, a model-out cache keyed by a hash of the model input and the rubric, and a read-only `-DryRun` that counts what `-Resume` would reuse.
