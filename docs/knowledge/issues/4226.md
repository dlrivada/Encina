## Asked

Make `LateConfigureEndpointValidationTests` build without SYSLIB0066 on SDK 11 / net11.0 and with zero warnings on SDK 10, without a .NET 11-only API.

## Outcome

The startup-validation theory now builds a host from the registered descriptors and expects `StartAsync` to fail with an `OptionsValidationException` (directly on SDK 10, wrapped in an `AggregateException` on SDK 11) for each of the seven packages (the mutation check removed `ValidateOnStart` for NATS only), with a substitute `ICacheProvider` for the secrets packages' cache hosted service.

- `tests/Encina.UnitTests/Validation/Endpoints/LateConfigureEndpointValidationTests.cs` - the host-start theory.
