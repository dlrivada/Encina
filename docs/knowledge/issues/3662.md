## Asked

Evaluate with BenchmarkDotNet evidence whether an Encina-owned result type built on C# 15 unions should replace LanguageExt `Either<EncinaError, T>` in the ROP core, and present the options for Dilemma D1 to the maintainer.

## Outcome

The issue is open and waits for the maintainer's decision. The spike report is written with a net11.0 prototype: four carriers measured on the `IEncina.Send`-style path (success, failure, a three-step chain, async `ValueTask`), API shapes, System.Text.Json behaviour, migration counts (2568 public signatures with `Either<EncinaError`) and the interaction with #3419 and #3661. D1 is not decided.

## Where the knowledge lives

- `docs/engineering/rop-unions-spike-3662.md`: the options, numbers, winning scenarios and the recommendation pending the maintainer.
