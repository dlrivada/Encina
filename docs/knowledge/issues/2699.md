## Asked

Add integration tests that run against free local emulators (LocalStack, the Azure Service Bus emulator, Azurite) so the AWS and Azure transports and the Lambda and Functions hosts are verified against real behavior, with per-flag integration targets and justifications for what no emulator can reach.

## Outcome

Delivered in three pull requests: the shared LocalStack fixture with the AmazonSQS tests (#2802), the Service Bus emulator and Azurite fixtures with the licence section of the test docs (#2971), and the in-process Lambda and Functions tests with their manifests, justification pages and README testing sections.

## Where the knowledge lives

- `tests/Encina.IntegrationTests/Cloud/AwsLambda/` and `tests/Encina.IntegrationTests/Cloud/AzureFunctions/` hold the in-process tests and the justification pages for what is not tested.
- `.github/coverage-manifest/Encina.AwsLambda.json` and `Encina.AzureFunctions.json` hold the integration targets and their justifications; the figures come from the coverage report, not from this record.
- `src/Encina.AwsLambda/README.md` and `src/Encina.AzureFunctions/README.md` state the local-only testing policy.
