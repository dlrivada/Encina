## Asked

Stop the query-cache log messages (EventIds 3508, 3509, 3510 and the 3511 warning) from writing the full cache key, which carries the tenant id and, for a `VaryByUser` query, the user id.

## Outcome

`CacheKeyRedactor` in `Encina.Caching` masks the `t:` and `u:` segments; `QueryCachingPipelineBehavior`, `CacheInvalidationPipelineBehavior`, `CachedShardedQueryExecutor` and the Memory, Hybrid and Redis cache providers log redacted keys only.

## Where the knowledge lives

- `src/Encina.Caching/KeyGeneration/CacheKeyRedactor.cs` — the single redaction helper.
- `tests/Encina.UnitTests/Caching/CacheLogRedactionTests.cs` — captures log output through hit, miss, store, failure, invalidation and each provider and asserts the ids never appear.
