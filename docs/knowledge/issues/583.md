## Asked

Add persistent `IDeadLetterStore` implementations for the 10 providers of the database matrix (ADO.NET, Dapper and EF Core on SQL Server, PostgreSQL and MySQL, plus MongoDB), registered through `UseDeadLetterQueue`.

## Outcome

Implemented on the branch `feat/583-dlq-stores` together with #2012 (one PR, not merged when this record was written): the reshaped contract, the 10 stores, the 029 scripts, registration on every provider path, the instrumented store and `encina.dlq.*` counters, and the documentation.
