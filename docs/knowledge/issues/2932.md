## Asked

After #2920 showed that a flag's package row is computed only over the files whose manifest entry lists the flag, add a report mode that makes such assignment gaps visible before they show up as a 0 on the dashboard.

## Outcome

coverage-report.cs got the mode --check-flag-assignment [--min-lines n] [--input dir] [--output dir]. It lists per package and flag the source files whose lines the flag's Cobertura data executes but whose manifest entry (override, else defaultTests) does not list that flag, with the executed line count (a per-file target does not count as an assignment; the row carries a note instead); writes flag-assignment.json in the output directory; exits 1 when any file executes at least --min-lines lines (default 5). Skips generated files, files the manifest excludes and packages without a manifest. CI wiring is issue 2935 and running it over the candidate pairs and fixing them is issue 2936.
