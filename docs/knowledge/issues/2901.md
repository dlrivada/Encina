## Asked

Phase 4 of EPIC #2845: a check on the real pull request diff, because the spawn hook that checks the declared size cannot see the pull request a worker produces.

## Outcome

Delivered in part by the script `.github/scripts/check-pr-size.cs` (file-based C# 14 with `--self-test`): it measures files and changed lines, honours the `size-exception-approved` label read through `gh pr view`, and fails closed. The `pr-size` job in `ci.yml` and the label itself are applied by the orchestrator.

## Where the knowledge lives

- `.github/scripts/check-pr-size.cs` — the limits (15 files, 1500 lines), the shortstat parser, the label lookup and the self-test.
- `changelog.d/2901-pr-size-job.added.md` — the user-visible entry.
