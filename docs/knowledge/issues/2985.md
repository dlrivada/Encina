## Asked

Stop `RequestIdentityCircuitHandler` from running a Blazor circuit activity anonymously when the scope factory refuses an authenticated principal (missing, malformed, reserved or conflicting subject), keeping the mask-and-run only for host refusals.

## Outcome

The handler refuses every factory refusal except the host ones (`ScopeConflict`, `UnsupportedAccessor`): it does not call the next handler and throws an `InvalidOperationException` carrying only the error code. The class remarks and the Blazor README state the refusal and its Blazor consequence, and a unit test per cause runs through the real scope factory.
