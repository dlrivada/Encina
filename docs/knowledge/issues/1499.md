## Asked

`DPIAHealthCheck.CheckHealthAsync` was not updated when #1454 and #1488 closed the same defect class (EncinaError.Message leaking through diagnostics channels) for OpenTelemetry activity tags in the DPIA package. A health-check result's `warnings` list is a different, unaudited sink for the same `AGENTS.md` rule: "EncinaError.Message NEVER reaches logs, activity tags, health-check results or plaintext storage". The check method at lines 135 and 140 put both `error.Message` and caught `ex.Message` directly into the warnings, exposing sensitive information in health-check dashboards, `/health` endpoints and diagnostics exports.

## Outcome

Delivered: `DPIAHealthCheck.CheckHealthAsync` was refactored to replace both leaks with safe alternatives: `error.GetCode().IfNone("encina.unknown")` at line 135 and `ex.GetType().Name` at line 140. The refactoring also extracted three private methods (`TryResolveDependencies`, `CheckExpiredAssessmentsAsync`, `CheckDraftAssessmentsAsync`) from the original `CheckHealthAsync` method to reduce its cyclomatic complexity from the early threshold and clear the CRAP gate — this is purely a complexity reduction for gate compliance with no behavior changes, since all three methods are called unconditionally from a linear control flow in the entry point.

A new test file `tests/Encina.UnitTests/Compliance/DPIA/DPIAHealthCheckMessageLeakTests.cs` provides regression coverage: it constructs mock `IDPIAService` failures with sentinel messages (e.g., "SENTINEL-do-not-leak") and asserts they never appear in the `HealthCheckResult`'s `Description` or `Data` fields after the health check executes.

## Where the knowledge lives

- `src/Encina.Compliance.DPIA/Health/DPIAHealthCheck.cs` — lines 135 and 140 now record error code and exception type name instead of raw messages; the method was refactored into `TryResolveDependencies`, `CheckExpiredAssessmentsAsync` and `CheckDraftAssessmentsAsync` for complexity reduction.
- `tests/Encina.UnitTests/Compliance/DPIA/DPIAHealthCheckMessageLeakTests.cs` (new) — sentinel-message regression test asserting neither EncinaError.Message nor exception Message reach the health-check result.
- `changelog.d/1499-dpia-healthcheck-error-message.security.md` — user-visible changelog fragment.
