## Asked

Make `AddEncinaServiceGraphTests` build without SYSLIB0066 on SDK 11 / net11.0 and with zero warnings on SDK 10, without a .NET 11-only API.

## Outcome

The `typeof(IStartupValidator)` entry was removed from the named service types. Two host-start tests in the same class assert the guarantee the entry stood for: an invalid `RequestIdentityOptions` fails `StartAsync` with `OptionsValidationException`, and a valid configuration starts and stops.

## Where the knowledge lives

- `tests/Encina.UnitTests/Core/AddEncinaServiceGraphTests.cs` — the two host-start tests and the comment naming why no validator type appears.
