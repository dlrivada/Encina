## Asked

Let a read-only reviewer subagent run its own scratch scan script and the sanctioned gate scripts (`knowledge-records.cs --check`) without the guard denying the call because the script path resolved to `$null`.

## Outcome

Delivered: when the launching base is empty the hook resolves a relative script path against the checkout root it knows; a variable-prefixed path that cannot be resolved stays denied. Cases are in `Test-Hooks.ps1` next to the #3115 and #3281 probes.
