## Asked

About 30 health checks interpolated `ex.Message` (or `EncinaError.Message`) into their unhealthy results, bypassing the sanitized `EncinaHealthCheck` base class. Report only the exception type or error code, log the details, and add a scan that fails on a new leak.

## Outcome

Delivered in three slices on branch `fix/health-check-exception-messages-1301`: transports, caches, locks and schedulers; database providers, monitors and `DatabasePoolHealthCheck`; the Microsoft `IHealthCheck` classes, the endpoint adapters and the health-only static scan. The PR number is not known yet, so `prs` is empty.

## Where the knowledge lives

- `tests/Encina.UnitTests/Messaging/Health/HealthCheckExceptionMessageLeakStaticScanTests.cs` - fails on any `.Message`, `exception:` or positional exception in a `*HealthCheck*.cs` or `*HealthMonitor*.cs` file under `src/`.
- `src/Encina.Messaging/Health/EncinaHealthCheck.cs` - the sanitized catch-all that replaces the deleted specific catches.
