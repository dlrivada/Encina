## Asked

Raise the guard, contract and property flags of `Encina.Compliance.GDPR` to their manifest targets (guard 20, contract 15, property 15) with tests that execute real package code, without touching `src/`.

## Outcome

Tests only. A happy-path guard test class, a pipeline behavior contract test class and a validator property test class were added under `tests/**/Compliance/GDPR/`. The three flags were measured locally before and after with `coverage-report.cs`; the unit flag stayed above its target. The enforcement modes of the package are `Enforce` and `WarnOnly`; there is no `Disabled` mode, so the contract tests cover those two.

## Where the knowledge lives

- `tests/Encina.GuardTests/Compliance/GDPR/GDPRHappyPathGuardTests.cs` — argument rejection plus the body of the guarded members.
- `tests/Encina.ContractTests/Compliance/GDPR/GDPRPipelineBehaviorContractTests.cs` — the pipeline behavior contract.
- `tests/Encina.PropertyTests/Compliance/GDPR/GDPRValidatorPropertyTests.cs` — the validator properties (GDPR row of #2041).
