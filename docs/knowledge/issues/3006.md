## Asked

Rename the multi-tenancy option `ThrowOnMissingTenantContext` to `RequireTenantContext` in `Encina.MongoDB`, because MongoDB returns a `Left` with `Repository.TenantRequired` instead of throwing. The `Encina.Messaging` part of the issue moved to its own sub-issue.

## Outcome

Delivered in the rename; there is no changelog fragment here, because one fragment for all of #3005 is written by the last sub-issue.

## Where the knowledge lives

- `src/Encina.MongoDB/Tenancy/MongoDbTenancyOptions.cs` — the option is renamed to `RequireTenantContext` (default `true`) with XML docs that describe the refusal as a `Left`.
- `src/Encina.MongoDB/Tenancy/TenantAwareFunctionalRepositoryMongoDB.cs` — returns the `Left` when the option is `true` and no tenant is available.
- `docs/features/multi-tenancy.md` — names each provider's option and describes its real behaviour.
