## Asked

Stop `TenantInfo` from writing its database connection string through the compiler-generated record `ToString()`, string interpolation and System.Text.Json serialization, as `AGENTS.md` section 3 requires for any type that carries a connection string (#851). Found while planning #711, which caches `TenantInfo`.

## Outcome

`TenantInfo.ConnectionString` is marked `[property: JsonIgnore]` and the record has a hand-written `ToString()` that prints `ConnectionString = ***` when the value is set and omits it when null. A JSON round trip loses the connection string (documented); configuration binding is unaffected.

## Where the knowledge lives

- `src/Encina.Tenancy/Abstractions/TenantInfo.cs` — the attribute, the `ToString()` override and the remarks on the JSON round trip.
- `tests/Encina.UnitTests/Tenancy/TenantInfoTests.cs` — tests for `ToString()`, interpolation, serialization, the round trip and configuration binding.

## Audit

Not audited: the record was written with the fix.
