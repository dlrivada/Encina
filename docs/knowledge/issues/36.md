## Asked

Provide CQRS read-side abstractions (projection base classes, read model repositories, rebuild) for event-sourced applications, working with Marten first and EventStoreDB later, in a new `Encina.Projections` package.

## Outcome

Created 2025-12-24T13:23:34Z and closed 2025-12-26T19:47:21Z (about 54 hours) by commit 584a712b (`Fixes #36`, no PR; the timeline shows only that commit). It is the same-titled re-creation of #21, which was closed as "created in error" at 11:52Z the same day. The commit added `src/Encina.Marten/Projections/` (15 files), `ProjectionOptions` wiring in `EncinaMartenOptions`, DI registration and tests. The shipped design differs from the issue: no `Encina.Projections` package, `IProjection<TReadModel>` instead of `IProjection<TEvent, TReadModel>`, no EventStoreDB integration. The issue has no comments.

- Contract, unit, guard and integration tests exist under `tests/` for the registry, repository, manager and inline dispatcher.
- There is no current guide for projections; only release notes (`docs/releases/v0.11.0/CHANGELOG-DETAILS.md`, `docs/releases/pre-v0.10.0/README.md`) describe them.
