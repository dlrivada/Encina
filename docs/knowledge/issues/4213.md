## Asked

Remove the 11 CA2026 warnings that SDK 11 analyzers report in five test files of `Encina.UnitTests`, so the project builds with zero warnings on SDK 10 and without CA2026 on SDK 11 for net11.0.

## Outcome

Each flagged `JsonDocument.Parse(...).RootElement` became `JsonElement.Parse(...)` (the redundant `.Clone()` in `LambdaResolveTenantIdTests` went with it). Assertions are unchanged. The sibling CA2026 site in `src/Encina.Cdc.Debezium/DebeziumHttpListener.cs` is outside this issue.

## Where the knowledge lives

- `tests/Encina.UnitTests/AwsLambda/LambdaResolveTenantIdTests.cs` — the `JsonElement.Parse` spelling.
