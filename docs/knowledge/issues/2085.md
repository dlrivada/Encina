## Asked

Make a low-ceremony saga whose step fails end `Compensated` when every compensation succeeded and `Failed` with an error code when one failed, persisted through `ISagaStore` on all 10 providers, instead of staying `Compensating` forever.

## Outcome

`SagaRunner.HandleStepFailedAsync` now persists `Compensating` first, runs the compensations, and records the terminal state. Unit tests use a stateful in-memory store; integration scenarios run on ADO, Dapper and EF Core (SQL Server, PostgreSQL, MySQL) and MongoDB.
